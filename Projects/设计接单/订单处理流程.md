# 订单处理流程

## 完整流程

```
1. 截图识别 → 2. 需求分类 → 3. 自动报价 → 4. 创建项目 → 5. 设计执行 → 6. 质检 → 7. 交付
```

---

## 详细步骤

### Step 1: 截图识别
**工具**：RapidOCR（本地运行，零费用）

```bash
# 识别截图中的文字
python -c "from rapidocr import RapidOCR; ocr = RapidOCR(); result = ocr('截图.png')"
```

**输出**：结构化需求文本

---

### Step 2: 需求分类
**分类规则**：

| 关键词 | 类型 | 模板 |
|--------|------|------|
| 餐饮/烤肉/菜单/套餐 | 餐饮海报 | poster |
| 异形/卡片/纯色/红色 | 异形卡片 | shaped_card |
| 三折页/折页/英文/展览 | 三折页 | trifold |
| 朋友圈/宣传/推广 | 朋友圈海报 | moments |
| 海报/门头/开业 | 海报设计 | poster |
| 详情页/主图/电商 | 详情页 | detail |

---

### Step 3: 自动报价
**报价标准**：

| 类型 | 基础价 | 修改加价 | 急单加价 |
|------|--------|----------|----------|
| 单张海报 | 24元 | +10元/次 | +50% |
| 系列海报(9张) | 100元 | +15元/次 | +50% |
| 三折页 | 40元 | +10元/次 | +50% |
| 详情页 | 108元 | +15元/次 | +50% |
| 包装盒 | 80元/套 | +20元/次 | +50% |
| AI效果图 | 40元 | +5元/次 | +30% |

**阈值**：自动过滤 10元以下订单

---

### Step 4: 创建项目
**工具**：`order_manager.py`

```bash
# 创建新订单项目
python order_manager.py new --type poster --desc "需求描述" --price 24
```

**自动生成**：
- 订单号：`ORD-YYYYMMDD-NNN`
- 文件夹结构：`01_原始需求/` ~ `06_沟通记录/`
- 元数据：`order_meta.json`
- 说明文档：`README.md`

---

### Step 5: 设计执行
**分链路执行**：

| 需求类型 | 执行引擎 | 工具 |
|----------|----------|------|
| AI生图类 | MiMo图像生成 | Codex → MiMo Image |
| 图文排版类 | PIL模板套图 | design_templates.py |
| 复杂设计 | 人工队列 | Photoshop + 设计师 |

**自动化命令**：
```bash
# 自动生成设计稿
python auto_order.py --order "朋友圈餐饮海报，烤肉套餐198元"
```

---

### Step 6: 质检
**自动检查**：
- 尺寸：1080x1920（手机端）、1080x1080（卡片）
- 分辨率：72dpi（屏幕）、300dpi（印刷）
- 色彩模式：RGB（屏幕）、CMYK（印刷）
- 文件格式：PNG（透明）、JPG（不透明）

**人工抽检**：5分钟快速审核

---

### Step 7: 交付
**交付物**：
- 预览图：JPG/PNG
- 源文件：PSD/AI（如需要）
- 交付说明：尺寸、格式、注意事项

**交付方式**：私聊客服，附源文件+预览图

---

## 时间标准

| 需求类型 | 完成时间 | 修改时间 | 最长交付 |
|----------|----------|----------|----------|
| 单张海报 | 15分钟 | 5分钟/次 | 2小时 |
| 系列海报 | 45分钟 | 10分钟/次 | 4小时 |
| 三折页 | 20分钟 | 5分钟/次 | 3小时 |
| 详情页 | 40分钟 | 10分钟/次 | 6小时 |
| 包装盒 | 30分钟/套 | 10分钟/次 | 8小时 |

---

## 风险控制

1. **禁止私加客户**：群规严格，违者开除不结算
2. **确认素材再动手**：避免反复修改扯皮
3. **印刷类提前确认**：色彩模式CMYK、出血3mm、分辨率300dpi
4. **敏感类目合规**：成人用品等需评估平台规则
