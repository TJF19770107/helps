## 加价规则

### 修改加价
- 基础包含：2次修改
- 超出修改：+10元/次
- 大改（重做）：+50%基础价

### 急单加价
- 正常交付：按基础价
- 急单（2小时内）：+50%
- 特急（1小时内）：+100%

### 尺寸加价
- 标准尺寸（1080x1920）：按基础价
- 大尺寸（>2倍）：+30%
- 超大尺寸（>5倍）：+50%

## 自动报价公式

```python
def calculate_price(base_price, modifications=0, is_urgent=False, size_multiplier=1.0):
    """
    计算最终报价
    
    Args:
        base_price: 基础价
        modifications: 修改次数（超出2次的部分）
        is_urgent: 是否急单
        size_multiplier: 尺寸倍数
    """
    price = base_price
    
    # 修改加价
    if modifications > 2:
        price += (modifications - 2) * 10
    
    # 急单加价
    if is_urgent:
        price *= 1.5
    
    # 尺寸加价
    if size_multiplier > 2:
        price *= 1.3
    elif size_multiplier > 5:
        price *= 1.5
    
    return round(price)
```

## 报价示例

### 示例1：普通海报
- 类型：单张海报
- 基础价：24元
- 修改：1次（不加价）
- 急单：否
- **最终报价：24元**

### 示例2：急单详情页
- 类型：详情页
- 基础价：108元
- 修改：3次（+10元）
- 急单：是（+50%）
- **最终报价：(108+10) * 1.5 = 177元**

### 示例3：超大包装盒
- 类型：包装盒设计
- 基础价：80元
- 修改：2次（不加价）
- 尺寸：3倍（+30%）
- **最终报价：80 * 1.3 = 104元**

## 接单阈值

**自动接单**：≥18元
**人工审核**：10-18元
**不接**：<10元

---

## 竞争策略

1. **低价走量**：18-24元的订单优先接，快速出稿
2. **中价平衡**：40-100元的订单，自动化+人工微调
3. **高价精品**：100元以上订单，人工精修，保证质量
