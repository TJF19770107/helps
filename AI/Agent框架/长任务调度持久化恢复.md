## 三种调度模式

| 模式 | 触发 | 适用场景 |
|------|------|---------|
| 事件驱动 | Webhook/用户操作/队列消息 | 即时响应 |
| 定时调度 | Cron/云调度器 | 批处理/轮询 |
| 混合模式 | 事件+定时双触发 | 高可靠场景 |

## 三层持久化架构

### Layer 1: 检查点状态管理
- 执行状态（当前步骤、已做决策）
- 工具结果（避免重复API调用）
- Agent记忆（对话历史、提取数据）
- 时间戳（调试/SLA追踪）

### Layer 2: 幂等工具调用
- 幂等键（UUID）标识唯一操作
- 状态验证（执行前检查是否已完成）
- 结果缓存（相同key返回缓存结果）

### Layer 3: 优雅降级与升级
- 定义失败模式（关键/可选）
- 短超时（5-10s）+ 升级
- 备选方案（备份API/缓存结果）
- 全量日志（调试/合规）

## 三种恢复模式

| 模式 | 机制 | 参数 |
|------|------|------|
| 指数退避 | 1s→2s→4s→8s→16s | 5次上限, 总超时60s |
| 熔断器 | Closed→Open→Half-Open | 3次连续失败→熔断, 30s冷却→半开探测 |
| 死信队列 | 全量重试耗尽→入死信 | 修复后重放 |

## 生产环境核心组件

```
Agent Runtime + State Store (PostgreSQL/DynamoDB) 
+ Message Queue + Workflow Orchestrator 
+ Monitoring Stack
```
