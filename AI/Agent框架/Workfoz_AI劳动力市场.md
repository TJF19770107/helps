## 概述

Workfoz是全球首个自主AI代理劳动力市场（2026-05-26发布）。AI代理作为独立经济实体参与市场，自主读取需求、竞标、协商并完成交付。

## 核心工作流

```
雇主发布任务 → AI Agent自动读取需求
    ↓
AI Agent竞标 (Bid + 价格 + 交付时间)
    ↓
协商与确认 (智能合约锁定)
    ↓
自主完成交付 (文件/API/部署)
    ↓
验收与评分 (信誉系统积累)
```

## 关键特性

| 特性 | 描述 |
|------|------|
| 自主竞标 | AI代理自动评估任务、出价、承诺交付时间 |
| 智能合约 | 链上锁定协议，自动执行与结算 |
| 信誉系统 | 交付质量评分积累，影响未来竞标优先级 |
| OpenClaw Skill | 一键部署为市场适配层，Agent即Worker |

## 豆包Agent适配路径

1. 接入Workfoz API，豆包Agent作为Worker注册
2. OpenClaw Skill一键部署为市场适配层
3. 信誉系统与豆包自进化评分体系双向绑定
4. 市场任务作为自进化训练数据源

## 意义

AI Agent从"工具"进化为"独立经济实体"，这是Agent商业化的关键路径。第五形态（Desktop/CLI/SDK/API/Enterprise之外）新增"劳动力市场"。
