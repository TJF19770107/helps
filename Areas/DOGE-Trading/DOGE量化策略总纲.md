# DOGE量化策略总纲

> **版本**: v1.0 | **创建日期**: 2026-05-31

---

## 一、策略研发目标

1. **稳健收益**：年化收益率目标 >50%，最大回撤控制在 <20%
2. **策略多样性**：覆盖趋势跟踪、事件驱动、网格三种策略类型
3. **自动化执行**：通过 vn.py CTA 引擎实现全自动交易
4. **风险可控**：五级仓位体系 + 硬止损 + 动态风控

## 三、核心指标定义

| 指标 | 公式/定义 | 目标值 |
|------|-----------|--------|
| 夏普比率 | (Rp - Rf) / σp | > 1.0 |
| 最大回撤 (MDD) | max((峰值-谷值)/峰值) | < 20% |
| 胜率 | 盈利交易数 / 总交易数 | > 45% |
| 盈亏比 | 平均盈利 / 平均亏损 | > 1.5 |
| 卡玛比率 | 年化收益 / 最大回撤 | > 2.5 |
| 年化波动率 | σ_daily × √365 | < 50% |
| 索提诺比率 | (Rp - Rf) / σ_downside | > 1.5 |
