## 三、常见故障处理

### 3.1 OKX API 超时/无响应

**症状**: market_weather_query.py 返回超时
**处理**:
1. 检查网络连接 `ping api.okx.com`
2. 检查是否有代理/VPN干扰
3. 等待5分钟后重试
4. 若持续超时 >30分钟，切换到备用数据源

### 3.2 vn.py 引擎崩溃

**症状**: CTA策略停止执行
**处理**:
1. 检查日志 `核心程序\logs\vnpy_*.log`
2. 确认账户余额充足
3. 重启 vn.py 引擎: `python 龙虾AI一键启动.py --restart-cta`
4. 若数据损坏，回滚到最近快照

### 3.3 Obsidian 插件失效

**症状**: Dataview查询无结果 / Templater不触发
**处理**:
1. 检查 `.obsidian/plugins/` 目录完整性
2. 重新加载插件: Obsidian → 设置 → 社区插件 → 禁用 → 启用
3. 检查 `data.json` 配置是否正确
4. 若仍不恢复，从备份恢复 `.obsidian/` 目录

### 3.4 Hermes 同步失败

**症状**: `hermes_full_sync_repair.py` 报错
**处理**:
1. 检查源目录是否存在
2. 运行 `python hermes_full_sync_repair.py --dry-run` 预览变更
3. 确认无冲突后执行 `python hermes_full_sync_repair.py --force`
4. 若仍失败，检查文件权限和磁盘空间
