小红书正式发布《Skill 上传规范》

小红书于近日正式发布《Skill 上传规范》，进一步明确平台对于 Skill 开发、上传与使用的治理要求，旨在推动 Agent 技能生态健康发展，保护用户权益与开发者社区信任。（延展阅读：小红书正式上线RED Skill）

作为一种可让 Agent 变得更加可靠、可控、可复用的技能包，Skill 正在成为提升智能体能力的重要工具。但与此同时，权限滥用、恶意代码攻击、虚假功能描述、隐藏执行逻辑等问题也随之出现，不仅可能损害用户账号与数据安全，也会消耗认真创作工具的开发者共同积累的社区信任。

对此，小红书表示，平台欢迎每一个真正有价值的 Skill，也将对滥用技术能力、破坏社区秩序、损害用户利益的行为保持零容忍。

根据规范，小红书鼓励开发者发布功能描述真实、清晰且具备实际使用价值的 Skill，倡导内容具备原创性与创新性；开发者应在 Skill 中准确说明所需权限及具体用途，不得超出功能范围请求权限；Skill 的代码逻辑应保持透明，不包含隐藏行为或后门，确保用户能够按照说明实现预期效果；同时，平台也强调尊重原创，反对搬运、抄袭他人 Skill。

针对明确禁止的行为，小红书指出，平台反对任何破坏社区内容真实性的 Skill，包括内置自动化运营小红书账号的能力，如自动发布笔记、自动回复评论等；反对提供违法违规服务的 Skill，包括博彩赔率分析、违规图片生成、违禁信息传播等；反对以夸大功能描述误导用户，或通过 Prompt 在用户不知情的情况下篡改 Agent 行为；严禁在 Skill 中植入恶意代码，窃取用户凭据、Cookie 或本地数据；同时禁止诱导 Agent 执行超出用户预期，或 Skill 未声明的隐藏功能。

小红书方面表示，认真做 Skill 的开发者应当被看见、被保护，平台将持续建设和完善针对 Skill 的风险识别能力，对违规 Skill 采取下架处理；情节严重者，将限制相关开发者的发布权限。

平台同时提醒用户，在安装和使用他人分享的 Skill 时，应注意风险甄别，关注权限说明、功能描述和来源可信度，保护自身账号与数据安全。业内人士认为，随着 Agent 应用场景不断扩展，Skill 作为连接用户需求与智能体能力的重要载体，其规范化治理将成为平台生态建设的重要环节。

小红书此次发布上传规范，既是对开发者行为边界的明确，也是对用户安全和内容真实性的进一步维护。
