近日，名创优品发布了截至2023年12月31日的最新季度财报。
财报显示，在季度内，名创优品收入同比增长54%、环比增长1.3%至38.4亿元；毛利同比增长66.2%、环比增长4.7%至16.5亿元。名创优品整体的毛利率，在季度内上涨至43.1%。
名创优品创始人、主席兼首席执行官叶国富表示，该季度包括收入、毛利率和净利润在内的所有关键业绩指标再次创下历史新高，增速较2023年前三季度有所加快，主要得益于32%的中国名创优品同店销售增长和19%的海外名创优品同店销售增长。海外直营市场收入连续三个季度增长超过80%，并在12月季度首次贡献了半数以上的海外业务收入。
另外，2023年其全球门店网络净增超过1000家，这是他们有史以来最快的开店速度。未来还将继续专注于长期战略目标，通过为全球消费者创造开心，成为领先的 IP 设计零售集团。
值得一提的是，叶国富在此前给公司的2024新年寄语中就提到，要打造领先的 IP 设计零售集团，而 IP 化也是名创优品参与全球消费品零售角逐的核心竞争力。
过去七年多，他们与全球超过80个顶级 IP 版权方建立了合作，开发了上万款 IP 产品，这为其未来的竞争和发展打下了坚实基础。2024年也在一手拓宽 IP 版权合作，一手打造原创 IP，把以 IP 设计为特色的优势进一步激发，发挥到极致。
而为了实现“领先的 IP 设计零售集团”目标，他们则坚持全球化发展战略，坚持 IP 战略和设计创新等战略。
第一，在全球化发展战略上，名创优品在创立两年时就开始了出海探索。财报显示，截至2023年12月31日，名创优品全球门店数已达6413家，其中国内门店数3926家，2023年净增601家国内门店；海外门店数2487家，2023年净增372家海外门店。
去年，名创优品还成为首个进驻纽约时代广场的中国品牌。2024 年会继续围绕超级符号、超级品类、超级 IP、超级门店、超级用户，构建独特竞争力，进驻更多核心商圈，开拓更大的海外市场，提升全球化发展势能。
第二，在坚持 IP 战略和设计创新上，名创优品继续加大了对 IP 设计创新、IP 孵化的投入，将 IP 的价值和潜力释放到极致，持续加强名创优品在 IP 领域的话语权。
该季度内，名创优品多个超级门店落地，如以迪士尼经典IP“草莓熊”为核心的上海旗舰店等，名创优品不断以“超级门店”作为关键驱动因素，为消费者打造出沉浸式的购物体验。而 IP 和设计正是打造“超级门店”的核心武器。
值得一提的是，2020年叶国富就提出兴趣消费将成为全球化消费趋势，消费者不再只关注产品本身，更关心消费所带来的情绪价值和情感满足。
而“IP 战略和设计创新 ”正是这一趋势下应对竞争的最佳解法。依托IP，名创优品要打造一个独特的潮流零售集团！
