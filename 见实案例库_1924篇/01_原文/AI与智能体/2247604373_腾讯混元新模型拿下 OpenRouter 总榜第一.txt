# 腾讯混元新模型拿下 OpenRouter 总榜第一

4月29日，全球最大的大模型 API 分发平台 OpenRouter 发布最新全球大模型 API 调用量排行榜。




腾讯混元新模型 Hy3 preview 一举登顶总榜第一，成为当前调用量最高的模型之一。与此同时，在分场景榜单中，Hy3 preview 还拿下工具调用排名第一、编程排名第二，展现出强劲的综合竞争力与落地应用价值。







作为连接全球 300 余个主流模型的 API 分发市场，OpenRouter 被业内视为大模型调用的“总路由”，其榜单被广泛看作观察模型真实使用热度和开发者偏好的重要窗口。




此次 Hy3 preview 登顶，不仅意味着腾讯混元在全球开发者生态中的影响力持续提升，也显示出国产大模型在高频、真实场景中的加速突破。




据介绍，Hy3 preview 是腾讯混元重建后训练的首个模型，也是迄今最智能的混元模型。在复杂推理、指令遵循、上下文学习、代码生成、智能体协作等关键能力上，Hy3 preview 均实现显著提升。前期在腾讯内部及产品侧测试中，该模型已在智能体与代码、对话意图理解、文本创作、长文处理以及 AI PPT 制作等场景中表现亮眼，展现出较强实用性。




值得关注的是，Hy3 preview 在性能提升的同时，也进一步优化了成本结构。依托模型能力与推理框架的深度协同，以及推理技术的系统性优化，其推理效率提升 40%，成本较上一代模型大幅下降，整体性价比进一步增强。




目前，Hy3 preview 已接入元宝、WorkBuddy 等多个腾讯核心产品，并支持接入 OpenClaw、OpenCode、KiloCode 等主流开源智能体平台。同时，该模型也已上线腾讯云大模型服务平台 TokenHub，并推出 Hy3 preview Token Plan 套餐，个人版最低仅 28 元/月。
