一个月时间迭代20多版并不是腾讯某个团队的状态，而是共同状态。比如企点营销云产品总经理曾炜这样说道：



“除夕晚上连春晚都没看，直接沉迷在写相关代码的状态中。9天假期中至少写了8天代码，一直都保持着兴奋感”。




他说的兴奋感其实是OpenClaw（龙虾）带来的冲击波，从春节至今，大厂们都在疯狂追进这个热点，甚至到了传统摆摊帮助大家装机的程度，热度一直持续到现在。就在3月27日时，企点营销云发布新版本，兴奋感就换成曾炜的同事喻帅，也就是企点营销云商业化总经理这样的表达：




团队疯狂接到很多客户诉求说想要接入，以至于不得不上了排队机制。




就在这些天，见实和企点的核心团队坐在一起长聊，聊他们的新版本，聊不同品牌商家需求的变化，但更重要的是，企点毫不避讳聊到，营销行业生产方式正在发生根本改变：




过去，是运营经验和平台规则驱动，现在则直接进入了 “AI 智能体自主驱动” 时代，AI 可以自己理解数据、自己挖机会、自己拆任务、自己执行、自己复盘，员工只负责目标、审核、安全约束。







01 
九大迭代



生产方式的改变是最值得聊的事情，这几乎意味着一个大时代的开启，和无数从业者、无数品牌商家的喜怒哀乐。不过，在这之前，我们需要先看看变化建立在什么基础之上。




曾经上个版本时覆盖营销工作流五个环节：人群圈选、活动编排、内容素材生成、人商品权益匹配、活动复盘。但不管如何，还是以人制定规则、AI 辅助执行为主。




新版本呢？企点在3月27日时发布的MAGIC Agent 2.0版本，稍加归纳，会发现至少有九大方向的迭代。




一是在原来 Agent 基础上，2.0融入个人智能体（龙虾）技能，包括 skill 化、自动执行、记忆能力等。系统可自主拆解任务、自主规划营销活动、自主串接执行、自主迭代经验。




运营人员只需要提出营销目标，AI 即可完成全链路闭环，人仅做关键审核与干预。一下子，AI从辅助执行升级为自主推进，Agent 发挥关键作用，人更多做约束和确认。这就是第一个迭代的方向，即智能体核心迭代。




第二个是数据能力迭代。在MAGIC Agent 2.0中，实现了AI自动挖掘人群、自动提取标签、自动人群分层与聚类。可感知外部的天气、节假日、热点、会员生日、场景变化等业务信号，并结合外部信息自动圈选人群、自动分类、自动生成营销活动建议。这意味着，从 “人找机会” 转变为机会主动涌现，为业务挖掘增长新空间。




第三是架构的迭代。在曾经版本中，系统能力封闭，企业自有工具与经验难以接入复用，外部伙伴定制开发 Agent 门槛高、效率低。




MAGIC Agent 2.0推出了营销 Skill 体系，平台预制全栈营销 Skill，包括数据引擎、标签引擎、分析引擎、触达引擎。支持一键安装行业精选 Skill、生态伙伴 Skill 接入以及企业自有工具、经验、策略封装为 Skill等。让企业内部经验与外部伙伴能力在同一平台融合执行。实现开放连接、开箱即用、能力自由组合。




第四个迭代方向是经验沉淀。过去优秀运营经验都依赖传帮带，但人员一变动就导致经验流失，成功打法无法复制，系统更无法学习和记忆、无法持续进化。





MAGIC Agent 2.0改成系统自动沉淀企业营销策略库、品牌规范库、员工偏好记忆。记录员工使用习惯，把经验和成功活动打法，转化为企业组织级资产，便于被 AI 理解和使用，最终实现系统持续进化、能力越用越强。




顺着这个往下，分别是执行链路（第五），入口与交互（第六）、营销与交易一体化（第七）、安全（第八）、海外（第九）等方向的迭代。




执行上，现在运营人员只需提出营销目标，AI就能精准识别意图、匹配策略，自主调度多 Agent 完成人群圈选 → 人货匹配 → 权益匹配 → 内容生成 → 旅程生成等过程，自动执行触达、自动复盘、自动迭代策略，仅在关键环节由员工审核确认，实现长链路营销任务端到端全自动闭环。




从过去只能在电脑后台操作，扩展到企业微信、QQ 等多渠道接入，跨设备使用更灵活。安全层面实现了企业级权限隔离、品牌内容严格审核、AI 决策过程透明化，每一步使用了哪些数据、调用了哪些技能、如何做出决策，全都可以查看、追溯、管控。




与此同时，营销云与云 mall 实现底层打通，营销策略可以实时同步到交易端，交易数据又能毫秒级回流到营销系统，真正让 “营销” 和 “交易” 形成闭环。同步推出的海外版，则深度适配东南亚、港澳当地社交工具，支持多时区、多语种、本地部署，帮助企业出海更合规、更顺畅。




这一轮迭代，可以说完成了从工具到智能体、从人工主导到 AI 自主驱动的关键转变。




02 
现在 AI 智能体自主驱动时代了



客户在大排队的是什么？从这些迭代中，能感受到的对品牌商家们的增长，到底意味着什么？这才是我们展开迭代细节后想了解的信息。




永联实业集团CIO曲振涛提到这样的变化，过去几年行业困境一直是流量越来越贵、用户越来越难留、数据越来越多却越来越没用。系统性重构后，行业从比拼买流量、抢公域、拉新。到了转向用户终身价值、私域深耕、生态协同。这意味着行业增长逻辑从 “拉更多人” 变成了 “服务好现有用户，让价值最大化”。




企点营销云的感受是：行业过去做营销，主要靠运营经验、人工规则、流程配置，AI 只是局部提效。这次迭代后，行业正式进入智能体自主驱动阶段。AI 可以自己理解数据、自己挖掘增长机会、自己拆解任务、自己执行、自己复盘，运营人员只负责目标、审核、安全约束。这背后是营销行业生产方式的根本改变。




紧随而至的是营和销的一体化闭环形成。发布 MAGIC Agent 2.0时，腾讯云副总裁、腾讯营销与交易产品负责人李学朝在现场提到，过去营销系统跟交易两张皮，营销人发了券，核销情况、购买数据是断裂的。到了新版中，一体化数据埋点与用户行为贯穿分析，营销与交易形成有机联动。实现从营销获客→交易转化→数据沉淀→AI 能力提升→反哺营销的数据飞轮。




员工呢？过去行业中依赖经验丰富的老员工，不过离职后经验就丢失。到了现在，营销成功活动的打法不再停留在项目里。企业真正把人脑当中的经验，转化成企业的组织级资产，被 AI 真正理解和使用。迭代后，优秀员工的经验不再只属于个体，行业进入经验可沉淀、可复用、可迭代的阶段。从“个人能力依赖” 进入 “组织经验资产化” 的阶段。




所有这些变化，让每个员工都获得一个具备专业深度、能够自主迭代的超级营销团队赋能。也让品牌商家沉淀的数据，变成AI自动发现增长机会的基础。




如果2.0再跑起来，这些乃至更多品牌商家们的增长又会达到多少？




对行业来说，下一代 AI 智能体驱动的营销与交易融合时代正在开启。对于从业者们来说，则是在实现公私域一体化经营，让营销更懂用户，让交易更顺其自然，把数据变成资产，把经验变成能力，实现可量化、可复制、可持续的真实增长。




回到开始，曾炜聊到那个持续了很久的兴奋感：“很多年没有这么兴奋地写代码了，这次 Agent 带来的变化是颠覆性的，我们有机会做出全球范围内有技术先进性的企业级营销平台。”




对，他说的是：颠覆性！
