## 一、跨线元方法论（在多条业务线反复复现的 6 条铁律）

这 6 条不是某一篇的观点，是 4 类业务线、上百个案例里**反复出现**的底层规律，属于"知道了就能少踩三年坑"的那种。

### 1. 复购是利润发动机，不是增长附属品
- **核心**：拉新是成本，复购才是利润。私域的一切最终都为"复购率"服务。
- **量化论据**：一款 59 元产品活动中，**复购人群占比仅 3.39%，却贡献 75.88% 销售额** `(id=2247522286)`；宠物品牌靠分层运营**复购升至 75%** `(id=2247522286)`；米欧米美瞳用"信任公式"做到**百万超级用户 / 65% 复购** `(id=2247541781)`。
- **落地**：先建标签体系（否则"数据缺失"是最大难点）→ 再做分层 → 最后才谈自动化。

### 2. 信任是转化的前置条件，不是结果
- **核心**：没有信任的流量是"一次性流量"。所有高转化的案例，本质都在解决"信任"。
- **论据**：99 严选用"关系"把转化率**从 3% 提到 15%**，创始人原话"信任是所有中老年商业化最大的问题" `(id=2247484913)`；"成交一定要有流量，流量背后一定要有信任" `(id=2247522107)`。
- **落地**：KOC/熟人推荐 > 广告投放；线下真实关系 > 线上投放关系。

### 3. 分层运营是所有精细化的第一性原理
- **核心**：不做分层，所有运营动作都是"平均用力"，等于没运营。
- **论据**：分层运营是复购第一杠杆（案例 3.39%→75.88%）`(id=2247522286)`；用户分层的标准维度 = ①购买记录 ②八大客户群体 ③ RFM 模型 `(id=2247540830)`。
- **落地**：见「二·框架 A：RFM + 八大客群分层」。

### 4. 工具要"服务流程"，不是"替代流程"
- **核心**：先有跑通的流程，再上工具；先上工具不梳理流程 = 数据缺失 + 无效自动化。
- **论据**：AI/Agent 落地最大坑是"每次都在重新理解你"——经验停在聊天窗口就一次性 `(id=2247604515)`；人的经验必须被系统接住。

### 5. 人机分工是 AI 落地成败的关键
- **核心**：不是"AI 替代人"，是"AI 负责理解/判断，工具负责执行，知识库负责沉淀，权限负责边界"。
- **论据（原文分工模型）**：**模型**负责理解、判断、排序、筛选；**工具**负责写入、裁剪、提醒、发布、同步；**表格和知识库**负责承接结构化结果；**权限系统**负责控制边界 `(id=2247604515)`。
- **落地**：这条直接搬到 AI 分身/Skill 体系设计上（见第四节）。

### 6. 所有增长最终要"闭环 + 可迭代"，否则是流量赌博
- **核心**：增长 = 链路闭环 × 持续迭代。单点爆量不可复制，闭环才可复制。
- **论据**：车企传统表单链路转化 **1%~2%**，改多链路投放 + 精细化运营的增长飞轮后"至少提升几个百分点" `(id=2247573809)`；花点时间私域做到 **40% 转化率**，靠"闭环链接的持续迭代" `(id=2247546827)`。

## 二、分线可复用框架（可直接执行）

### 框架 A · RFM + 八大客群分层（私域运营 · 最高复用）
**出处** `(id=2247540830)`｜**适用**：任何要做复购/会员的品牌

**分组三件事**：
1. 按「会员过往购买记录 + 参与活动」打底；
2. 套「八大客户群体」：重要价值 / 一般价值 / 重要发展 / 一般发展 / 重要保持 / 一般保持 / 重要挽留 / 一般挽留；
3. 用 RFM 模型量化：**R**ecency 最近消费时间 · **F**requency 消费频次 · **M**onetary 消费金额。

**落地顺序**：先补齐交易数据（数据缺失是最大难点）→ RFM 打分 → 落八大客群 → 对不同客群配不同动作（重要价值做维护、重要挽留做激活动、一般发展做培育）。

### 框架 B · 包裹卡「五支柱 + 五部曲 + 四步法 + 三要素」（私域拉新 · 最可量化）
**出处** `(id=2247596271)`｜**适用**：电商/快消/服饰/宠物/护肤的"包裹里那张卡"加粉

- **五大设计支柱**：用户需求 · 视觉 · 钩子 · 路径 · 承接
- **落地五部曲**：定目标 → 文案与设计 → AB 测试 → 打印入仓 → 投放监测
- **加粉路径四步法**：看见 → 兴趣 → 扫码 → 添加（逐步拆转化链路）
- **高转化三要素**：长期价值 × 精准匹配 × 清晰表达
- **五步设计思考模型**：需求分析 · 功能设计 · 风险控制 · 数据监测 · ROI 优化
- **三类卡片对比**：传统卡 / 互动卡 / 盲盒卡（效率·成本·适配场景各不同）
- **量化基准**：普通卡加粉率 **3%**，靠 A/B 测试迭代到 **23%**；整体从 **1% → 20%+**；盲盒型可做到 **80% 导粉率**。

**关键动作**：不要一次定稿，用「AB 测试」把普通卡迭代成高转化卡——这是整条线唯一被反复验证的提效杠杆。

### 框架 C · 五步成交法则（销售/导购话术 · 直接照读）
**出处** `(id=2247587473)`｜**适用**：企微/导购/客服的一对一成交

1. **赞美讨喜** —— 先建立情绪安全
2. **挖掘需求** —— 问出真实场景
3. **描述愿景** —— 让他"看见"用后的样子
4. **重点阐述** —— 只讲 1~2 个最打动他的点
5. **分解价格** —— 把总价拆成"每天几块钱"

**配套硬规则（同一语料）**：导购接到问询，**20~60 秒内回复**；模板消息占比 **≤10%**；单条文字 **≤40 字**；连续发送 **≤3 条** `(id=2247576573)`。

### 框架 D · 私域节奏「3 个 7 天」（私域运营 · 养成购买习惯）
**出处** `(id=2247597264)`｜**核心**：用户沉淀到企微后，按 **3 个 7 天**的节奏推进（欢迎期→激活期→转化期），把一次性用户养成习惯性复购。
**量化论据**：该打法下用户两年增至 **45 万**，仅私域销售额破 **10 亿** `(id=2247597264)`。

### 框架 E · 会员裂变「1 带 10」
**出处** `(id=2247532171)`｜**核心**：会员体系的核心指标不是"总会员数"，而是**"1 个会员能带动几个会员"**。设计一切会员权益时，先问：这条权益能不能触发"1 带 10"。

### 框架 G · Agent 四层记忆 + Skill 八要素（AI 分身 · 本轮迭代核心）
**出处** `(id=2247604515)`（见实 AI 主题私享会 · 陈一铭实录）｜**适用**：任何 Agent / AI 分身 / 技能体系建设

**四层记忆（信息该停在哪一层）**：
| 层 | 放什么 | 对应到你（汤小龙） |
|---|---|---|
| ① 身份规则层（最稳） | 我是谁、服务谁、价值观、风格、禁忌 | **SOUL.md** |
| ② Skill 层（动态调度） | 反复出现的、已跑通的流程 | **技能库 / SKILL.md** |
| ③ 长期记忆层 | 名字、偏好、常用工具、关键项目、长期业务规则（**不能当垃圾桶**） | **MEMORY.md / 工作空间记忆** |
| ④ 临时会话层（最灵活最不稳） | 本次任务限定、临时判断 | 当前对话 |

**归位判断标准（照做）**：
- 只对当前任务有效 → 留会话
- 反复出现的偏好/背景 → 进长期记忆
- 已跑通的处理流程 → 封装成 Skill
- 需协作/追踪的结果 → 表格 / 知识库 / 业务系统

**Skill 必须写清 8 要素**（少一个就"半失效"）：适用场景 · **触发条件** · 输入字段 · 执行步骤 · 调用工具 · 输出格式 · 质量约束 · 异常反馈。
- **触发条件最易被忽略**：叫"客户处理"太泛；叫"客户优先级分析 / 当判断成交概率、跟进顺序、丢单风险时使用"才可被可靠调用。
- **渐进披露**：Agent 先读 Skill 的标题/摘要/描述（元数据）再决定加载正文 → **标题、摘要、触发条件不是装饰，是调用依据**。
- **优先级**：项目级 > 全局 > 默认层；同名取高优先级。

## 四、避坑清单（从 434 条踩坑里提炼的高频项）

1. **数据缺失**是私域运营最大难点——不做标签体系就上自动化，必翻车 `(id=2247522286)`。
2. **私域团队必须全职**，千万别从其他部门抽调/兼职，效率极低、成本极高 `(id=2247544818)`。
3. **导购消息过量**：模板消息 >10%、单条 >40 字、连发 >3 条，转化反降 `(id=2247576573)`。
4. **推广素材无明确感知**：单纯推"××定制服务"，素材点击率只有 5%~7%——要说清"用户能得到什么" `(id=2247586971)`。
5. **小红书只做引流加微**：不符合用户习惯、发挥不了平台优势、数据无法闭环 `(id=2247587473)`。
6. **直播只做品宣不转化**：直播流量很贵，不转化就是烧钱 `(id=2247524288)`。
7. **包裹卡不定稿**：一次定稿必平庸，必须 AB 测试迭代 `(id=2247596271)`。
8. **Agent 经验停在聊天窗口**：不封装成 Skill，换个窗口就重新理解你 = 一次性能力 `(id=2247604515)`。
9. **Skill 触发条件模糊**：叫"客户处理"太泛，Agent 判断不了该不该加载 `(id=2247604515)`。
10. **长期记忆当垃圾桶**：把一次性临时判断写进长期记忆，会污染后续所有判断 `(id=2247604515)`。
