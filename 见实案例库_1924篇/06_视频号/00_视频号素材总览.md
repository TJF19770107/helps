## 二、打法（技术路径）

```
公众号文章 HTML
  └─ <mp-common-videosnap data-type=video|live
        data-id=视频ID  data-desc=文案  data-username=视频号ID
        data-nickname=账号名  data-url=封面/视频地址  data-nonceid=唯一标识>
```

**零成本**：纯 HTTP 抓文章 HTML + 正则提取，不调任何模型、不需要登录态。

## 三、能力边界（实事求是）

| 项 | 状态 | 说明 |
|---|---|---|
| 视频文案 | ✅ 已打通 | 文案 + 话题标签 + 视频ID，永久有效 |
| 视频号账号 | ✅ 已打通 | username(`v2_...@finder`) + 昵称 + 头像 |
| 直播记录 | ✅ 已打通 | 直播预告文案 + noticeid |
| 视频封面 | ⚠️ 部分 | 老文章 `data-url` token 已过期(HTTP 400)，需 CDP 实浏览器换新 token |
| **视频 mp4 本体** | ❌ 未打通 | 点击播放需真实用户手势，播放器在 channels.weixin.qq.com 需扫码登录态 |
