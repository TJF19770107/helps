## 一、核心知识框架

### 1.1 Codex代码生成与自动化

**核心能力**：
- 终端原生Agent-first范式，支持非交互模式（CI/CD流水线）
- 6角色Agent Plugins（110+技能，62+企业应用）
- Annotations批注系统：人-Agent实时协作编辑
- Sites功能：自然语言 → 可交互Web应用
- Windows桌面接管（GitHub Copilot Desktop原生体验）

**关键参数**：
- `codex exec`：非交互模式入口
- `--full-auto`：CI自动化场景
- `--output-schema`：结构化输出验证
- `--json`：机器可读JSONL事件流
- `resume`：会话恢复（支持--last或指定会话ID）

### 1.2 飞书CLI自动化

**核心能力**：
- 200+命令，覆盖11-18个业务域
- 26个AI Agent Skills内置
- MIT开源协议
- 支持消息、文档、多维表格、日历、视频会议、邮箱、任务、知识库、通讯录

**接入流程**：
1. `npx @larksuite/cli@latest install`：安装CLI
2. `lark config init` 或 `lark auth login`：认证配置
3. Skills安装 → 应用配置 → 用户授权
4. 调用对应子命令执行业务操作

## 二、可复用SOP模板

### 2.1 自动化日报生成SOP

```
1. Codex采集指定数据源（Git/Database/API）
2. 生成结构化日报内容
3. 调用 lark base record-upsert 写入多维表格
4. 调用 lark im messages-send 推送通知
5. 记录执行日志备查
```

### 2.2 CI通知与文档归档SOP

```
1. CI流水线触发 codex exec（代码审查/测试总结）
2. Codex生成结构化审查报告
3. 调用 lark im messages-send 发送CI结果通知
4. 调用 lark docs create 创建会议纪要/审查文档
5. 调用 lark drive upload 上传产物文件
```

### 2.3 任务自动分派SOP

```
1. Codex分析需求描述 → 拆解子任务
2. 调用 lark task create 创建飞书任务
3. 调用 lark task assign 分配给对应成员
4. 调用 lark task set-deadline 设置截止日期
5. 调用 lark im reply 发送任务通知消息
```

## 五、学习结论

1. **Codex+飞书CLI已具备完整自动化能力**：codex exec提供CI/CD级非交互模式，飞书CLI提供200+业务命令，两者结合可覆盖从代码审查→文档归档→消息通知→任务分派的完整自动化闭环。

2. **权限配置是核心门槛**：飞书CLI的三级认证模式（config/auth/多应用）需要提前规划应用权限矩阵，建议使用"仅申请最小必要权限"原则。

3. **安全存储凭证是关键**：CLI使用OS原生密钥链，不存储明文；Codex CI环境通过环境变量传递API Key。

4. **SOP模板可复用性强**：日报生成、CI通知、任务分派三大SOP可直接应用于后续任务，减少重复配置。
