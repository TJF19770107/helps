## 二、权限模型

### 2.1 安全层次

| 优先级 | 级别 | 配置位置 | 说明 |
|--------|------|---------|------|
| 1（最高） | 组织策略 | managed-settings.json | 不可推翻 |
| 2 | Deny 规则 | settings.json | 强制拦截 |
| 3 | Hook 拦截 | .claude/hooks/ | 确定性执行 |
| 4 | Ask 询问 | settings.json | 弹窗确认 |
| 5 | Allow 允许 | settings.json | 默认允许 |
| 6 | Auto Mode | 运行时切换 | 智能分类 |

### 2.2 工具权限配置

```json
{
  "permissions": {
    "bash": {
      "allow": ["npm run *", "git *", "pytest *"],
      "deny": [
        "rm -rf *",
        "DROP TABLE *",
        "git push --force *",
        "shutdown *",
        "format *"
      ]
    },
    "edit": {
      "allow": ["/docs/**", "/src/**", "/tests/**"],
      "deny": ["/config/**", "/secrets/**", ".env"]
    }
  }
}
```

## 六、自动化调度策略

### 6.1 定时任务配置

| 任务名 | 周期 | 触发动作 |
|--------|------|---------|
| Anthropic课程学习 | 每2小时 | 爬取→整理→写入→同步 |
| 豆包App迭代 | 每2小时 | 搜索→对比→升级方案 |
| SOUL/USER/AGENTS同步 | 每次迭代后 | 写入→全分身重载 |
| 量化策略分析 | 每日 | 策略评估→迭代建议 |

### 6.2 调度优先级

```
1. 用户主动指令（最高优先级，立即响应）
2. 定时任务（按周期自动执行）
3. 系统监控（后台静默运行）
```

### 6.3 并发控制

- 同类型 Agent 最多同时运行 2 个
- 跨类型 Agent 可全部并行
- 等待队列按优先级排序

