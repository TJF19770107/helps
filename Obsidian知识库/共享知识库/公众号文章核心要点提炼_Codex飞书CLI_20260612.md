## 二、四步接入流程（标准化 SOP）

### 第1步：安装飞书 CLI
- 方式：在 Codex 对话中描述需求，Codex 自动执行安装
- 耗时：4～5 分钟
- 关键：`npm install -g @larksuite/cli` 或 `brew install lark-cli`

### 第2步：配置飞书应用
- Codex 输出浏览器配置链接
- 在飞书开放平台创建应用，获取 **App ID** 和 **App Secret**
- 将凭据交回 Codex 完成配置

### 第3步：登录授权（OAuth）
- Codex 输出浏览器授权链接
- 用户确认授权
- 建议权限范围：日历读写、文档创建编辑、Base 读写、消息发送、通讯录读取

### 第4步：验证接入
- 低风险验证命令：创建飞书日历事件
- 成功标准：日历中出现测试事件
