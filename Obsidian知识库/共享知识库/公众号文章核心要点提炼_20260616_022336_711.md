## 核心要点

### 1. 飞书 CLI 的战略意义
- 2026年3月底飞书正式开源 CLI，将飞书从"手动点按工具"升级为"可编程工作系统"
- 最革命性突破：无缝连接 AI Agent 生态（Codex、Claude Code、Cursor）
- AI Agent 零配置即可直接操控飞书知识库——文档创建、搜索、批量更新一句话完成

### 2. 安装即用，零门槛
- 一条命令全局安装：`npm install -g @larksuite/cli`
- 官方推荐权限集：`lark-cli auth login --recommend`
- Skills 安装自动化：直接将飞书 CLI 安装指南链接丢给 Codex
- **关键约束：安装 Skills 后必须重启 Codex**

### 3. 八大实战场景全覆盖
- 创建知识库文章 / 发布本地 Markdown / 搜索文档 / 基于评论修改
- 批量发布 / 内容目录维护 / 会议自动化 / 内容运营仪表盘

### 4. 双向桥接方案丰富
- Codex → 飞书（官方 CLI 直连）
- 飞书 → Codex（feishu-codex-bridge / agent-gateway）
- 支持长连接、进度心跳、多 Agent 切换、Hermes 式状态反馈

### 5. 内容生产流水线
```
写作 → AI 修改 → 质检 → CLI 发布 → 飞书知识库沉淀
```

### 6. AI 协同新模式
- AI 起草 + 人把关
- 人起草 + AI 审稿（评论形式）
- Markdown ↔ 飞书文档双向转换
- Wake Word 指令（"龙虾龙虾"）+ 妙记逐字稿识别

### 7. 为 AI 而设计的 CLI

- 缺权限自动引导补授权

- AI 用 CLI 成功率远高于直接调 API
