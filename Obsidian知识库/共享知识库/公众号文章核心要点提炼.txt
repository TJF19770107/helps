五、常见问题与解决方案
================================================================================

Q1：安装失败怎么办？
  A：确保Node.js >= 18.0.0，尝试使用 npx @larksuite/cli@latest install

Q2：授权后Token无法刷新？
  A：执行 lark-cli auth login --recommend 重新授权

Q3：操作提示权限不足（403）？
  A：在飞书开发者后台检查应用权限scope，添加必要权限后重新授权

Q4：如何查看CLI支持的所有命令？
  A：执行 lark-cli --help 或 lark-cli skills list

Q5：如何开启调试模式定位问题？
  A：在命令前加 --debug，如 lark-cli --debug doc list

Q6：Token存储在哪里？安全吗？
  A：Token加密存储在本地凭证文件中，不会明文输出到控制台

Q7：多Agent同时操作会冲突吗？
  A：飞书原生权限体系保证数据一致性，建议不同Agent操作不同资源
