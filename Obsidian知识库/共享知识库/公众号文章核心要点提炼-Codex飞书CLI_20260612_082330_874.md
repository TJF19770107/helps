## 一、核心要点提炼

### 1.1 飞书CLI本质定位
- **飞书官方开源**CLI工具（MIT协议），专门为AI Agent设计
- 让Codex、Claude Code、Cursor等AI编程工具直接操作飞书办公能力
- 覆盖即时通讯、云文档、多维表格、日历、邮件、任务等11大业务域
- 提供200+命令和19个Agent Skills

### 1.2 技术架构亮点
- **三层命令架构**：Shortcuts（带+前缀高频封装）→ API Commands（标准端点映射）→ Raw API（底层直接调用）
- **两种权限模式**：不授权模式（基础操作） + 用户身份模式（个人数据访问）
- **企业级管控**：应用权限由企业管理员在飞书开放平台后台统一管理

### 1.3 Codex对接要点
- Codex可自动完成CLI安装全流程
- 关键参数：`--new`（自动创建应用）、`--recommend`（推荐权限自动审批）
- AI Agent环境需特殊处理：授权链接由Agent转发用户，用户在浏览器扫码授权
- 安装后必须重启AI工具加载Skills

## 二、可复用SOP模板

### SOP-1：Codex+飞书CLI一键部署（5步）

```
Step 1: 确认环境（Node.js >= 16, Codex已安装）
Step 2: npm install -g @larksuite/cli
Step 3: npx skills add larksuite/cli -y -g
Step 4: lark-cli config init --new（获取授权链接）
Step 5: lark-cli auth login --recommend（扫码授权）
验证: lark-cli --version && lark-cli auth status
重启AI工具
```

### SOP-2：每日工作摘要自动化

```
触发条件：定时任务 / 手动触发
执行步骤：
1. lark-cli calendar +agenda → 获取日程
2. lark-cli task +list --status incomplete → 获取待办
3. lark-cli im +messages-search → 获取未读消息
4. AI汇总分析
5. lark-cli docs +create → 创建飞书文档
6. lark-cli im +messages-send → 发送摘要到群聊
```

### SOP-3：会议纪要全链路自动化

```
触发条件：会议结束后自动触发
执行步骤：
1. lark-cli minutes +get → 读取妙记
2. AI提取关键决策和待办
3. lark-cli docs +create → 创建纪要文档
4. lark-cli task +create → 创建待办任务
5. lark-cli im +messages-send → 发送通知
```

### SOP-4：多维表格数据分析流程

```
触发条件：定时 / 事件驱动
执行步骤：
1. lark-cli base records list → 读取数据
2. AI分析并生成见解
3. lark-cli base records update → 回写结果
4. lark-cli docs +create → 生成分析报告
```

### SOP-5：跨Agent协作工作流

```
角色分配：
- 主Agent（Codex/Claude Code）：任务编排与调度
- 飞书Agent（lark-cli）：飞书办公操作
- 知识Agent（Obsidian）：知识库管理

流程：
1. 主Agent识别用户需求
2. 拆解为飞书操作子任务
3. 通过lark-cli执行具体操作
4. 结果汇总到Obsidian知识库
5. 同步到飞书文档/多维表格
```

## 三、权限配置速查

| 模式 | 命令 | 适用场景 |
|------|------|---------|
| 基础操作（无需授权） | 直接使用 | 发消息、建文档（不读个人数据） |
| 推荐权限 | `lark-cli auth login --recommend` | 通用场景，自动审批 |
| 精确权限 | `lark-cli auth login --scope "calendar:calendar:readonly"` | 仅需特定权限 |
| 按域授权 | `lark-cli auth login --domain calendar,task` | 按业务域授权 |
| 追加权限 | `lark-cli auth login --scope "search:message"` | 补充新权限 |

---

## 四、安全注意事项

1. 最小权限原则：只给AI实际需要的权限
2. 重要操作加 `--dry-run` 预览
3. 企业管理员定期审查CLI应用权限
4. 定期刷新授权：`lark-cli auth login`
5. 飞书开放平台后台查看操作日志
