## 二、关键知识点提炼

### 2.1 安装即用（10分钟跑通）
- 一行 `npm install -g @larksuite/cli` 完成安装
- `npx skills add larksuite/cli -y -g` 安装Agent Skills
- `lark-cli config init --new` 初始化（扫码授权）
- `lark-cli auth login --recommend` 用户授权
- 配置后重启AI工具即可用

### 2.2 三层命令体系
- Shortcuts层（+前缀）：日常高频操作，智能默认值
- API Commands层：200+命令，对标飞书平台API
- Raw API层：2500+ OpenAPI全覆盖

### 2.3 双Agent生态核心机制
- 共享目录 `~/.agent-ecosystem/` 存放操作指令集
- 飞书多维表格做统一任务追踪面板
- 飞书文档做Agent间异步交接
- Claude Code白天设计 → 写入交接文档 → Codex夜间执行 → 写回结果
- 全过程零手工中转

### 2.4 三大自动化场景
- 会后待办一键处理（妙记→待办提取→文档发送→会议创建）
- 人机共创文档迭代（AI建初稿→用户评论→AI读取更新→无限迭代）
- 每日AI汇总（30秒拉齐日程/未读邮件/待办任务）

### 2.5 安全性设计
- `--dry-run` 预览机制：所有操作前可预览不执行
- 两种授权模式：不授权（基础操作）/ 用户身份（个人数据访问）
- 企业账号建议使用测试企业避开管理员审批

## 三、可复用SOP模板

### SOP-1：飞书CLI安装部署SOP
1. 确认 Node.js >= 16
2. `npm install -g @larksuite/cli`
3. `npx skills add larksuite/cli -y -g`
4. `lark-cli config init --new`（扫码授权）
5. `lark-cli auth login --recommend`（可选）
6. `lark-cli auth status` 验证
7. 重启AI工具

### SOP-2：双Agent生态搭建SOP
1. `mkdir -p ~/.agent-ecosystem`
2. 创建飞书操作指令集 feishu-ops.md
3. 手动创建飞书多维表格（任务追踪）
4. 创建飞书文档「Agent 交接记录」
5. 配置 CLAUDE.md（Session Start/飞书操作/Session End）
6. 配置 CODEX.md（Session Start/Goals执行/Session End）
7. 启动Claude Code验证：查日程+查任务+读交接文档

### SOP-3：每日AI汇总SOP
1. `lark-cli calendar +agenda --format pretty`
2. `lark-cli mail +search --unread --format pretty`
3. `lark-cli task +list --status incomplete --format pretty`
4. 汇总输出，标注紧急事项
