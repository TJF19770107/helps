# AI Agent 智能体核心逻辑

## 核心定义

```
Agent = AI大模型（大脑） + 工具调用（手脚） + 自主行动（执行力）
```

> AI Agent 能自主拆解任务、调用工具、多步骤执行，最终交付完整成果。

## AI Agent vs 普通大模型

| 维度 | AI Agent（智能体） | 普通大模型 |
|---|---|---|
| 行动能力 | ✅ 主动执行 | ❌ 仅回答 |
| 工具调用 | ✅ 支持搜索/API/办公软件 | ❌ 无法直接调用 |
| 自动化流程 | ✅ 完整业务闭环 | ❌ 单次对话结束 |
| 多步骤任务 | ✅ 拆解分步完成 | ❌ 容易中断遗漏 |

## Agent 三大核心组件

### 1. 大脑（AI大模型）
- 负责理解、推理、决策
- 核心能力：自然语言理解、任务分解、逻辑推理

### 2. 手脚（工具调用）
- 负责与外部世界交互
- 工具类型：搜索引擎、API接口、数据库、办公软件、文件系统
- 调用方式：Function Calling / MCP协议

### 3. 执行力（自主行动）
- 负责多步骤任务的自动推进
- 关键机制：
  - 任务拆解（Planning）
  - 循环执行（ReAct Loop）
  - 错误自愈（Self-healing）
  - 检查点恢复（Checkpoint）

## 关键概念速查

- **ReAct**：Reasoning + Acting 循环，Agent 的核心执行模式

- **Multi-Agent**：多智能体协同，任务分工+结果汇总
