# 模型通道配置（可切换 / 自定义 / 备份 · v1，持续迭代）

> 设计原则（沿用 MEMORY #8：环境变量 > 配置文件）：
> - 通道切换 **不碰代码**，只改本文件或命令注册表的「模型通道」栏。
> - 所有 API Key 走**环境变量**，绝不写进本文件或 git。
> - 每个通道支持 `主用 + 备用` 故障转移；自定义通道 = 复制一段改名字。
> - 本配置是 v1，后续按订单新增/特殊情况（如某模型限流、本地新下载模型）随时追加。

## 通道清单（命令注册表「模型通道」栏填这里的大写键名）

| 通道键 | 类型 | 用途 | 默认指向 | 备注 |
|---|---|---|---|---|
| `FREE_POOL` | 云端中转 | 生文主用 | 15740 转移代理(deepseek-v4-flash-free → glm → pro → gpt-5.6-luna-fast兜底) | 免费池+0.01折兜底 |
| `HY3` | 本地中转 | 生文备用 | 15731 HY3混元代理(CloudBase hy3-relay-proxy 免费Token桥接) | 免费池拥堵时的第一备胎 |
| `CNB_GPU` | 云端GPU | 生图/生视频 | CNB GPU(Flux / Wan2.2) | ¥0.5/核时，CPU 1600核时/月免费打底 |
| `LOCAL_OLLAMA` | 本地 | 生文离线 | 本机 Ollama(Qwen / Llama3) | 无网也能跑，零成本 |
| `SELF_API` | 自建API | 任意 | 用户自有 OpenAI 兼容 endpoint | env 注入 BASE_URL+KEY |
| `BODY_OWN` | 本地私有 | 生文/生图 | 你自有模型(本地 ComfyUI/Ollama 加载) | "bodydy 自有的模型"落地处 |
| `CUSTOM_*` | 自定义 | 任意 | 任意第三方 OpenAI 兼容 | 见下方模板 |

## 切换方式（三层优先级，高者覆盖低者）

1. **命令级**：下令时带通道，如「写剧本 @CNB_GPU」或「生漫剧图 @LOCAL_OLLAMA」→ 仅本次生效。
2. **注册表级**：命令注册表「模型通道」栏填通道键 → 该命令永久走此通道。
3. **全局默认**：下方 `DEFAULT_CHANNEL` → 未指定的命令都走它。

> 优先级：命令级 > 注册表级 > 全局默认。

## 故障转移（主用挂了自动切备用）
通道定义里写 `backup:`，如 `FREE_POOL` 的 backup 指向 `LOCAL_OLLAMA`：
生文若 18091 免费池超时/限流 → 自动切本机 Ollama，不中断任务。

## 各通道定义（env 注入，勿硬编码 Key）

```yaml
DEFAULT_CHANNEL: FREE_POOL

channels:
  FREE_POOL:
    type: cloud_relay
    base_url: http://127.0.0.1:15740/v1     # 故障转移代理（18091 同源；key 从 HKCU 注册表内存注入）
    models: [deepseek-v4-flash-free, glm-5.3-flash-free, deepseek-v4-pro-free, gpt-5.6-luna-fast]
    api_key_env: TEAMOROUTER_API_KEY
    backup: HY3
    note: "实测约束(2026-09-29)：源站Cloudflare 100s网关超时→单次生成>100s必524，长文必须分步调用(生文流水线.py已内置)；GLM免费额度会402人满，链内自动转移"

  HY3:
    type: local_relay
    base_url: http://127.0.0.1:15731/v1     # HY3混元代理(拉起脚本见 MCP服务；CloudBase hy3-relay-proxy 桥接免费Token)
    models_env: HY3_MODELS                  # env 注入可用模型名
    api_key_env: HY3_KEY
    backup: LOCAL_OLLAMA
    note: "免费Token桥接；15731未监听时先拉代理再用"

  CNB_GPU:
    type: cloud_gpu
    runtime: CNB 免费 GPU 节点
    image_models: [Flux, Qwen-Image]
    video_models: [Wan2.2, H3]
    entry: scripts/gateway_service/         # 复用出片网关 v1.0
    backup: BODY_OWN
    note: "Wan2.2 五铁律：4n+1帧/32倍数/HF镜像"

  LOCAL_OLLAMA:
    type: local
    base_url: http://127.0.0.1:11434        # 本机 Ollama
    models: [qwen2.5:14b, llama3.1:8b]
    backup: none
    note: "完全离线零成本，质量低于云端"

  SELF_API:
    type: openai_compatible
    base_url_env: SELF_API_BASE_URL         # 你的自有 endpoint
    api_key_env: SELF_API_KEY
    models_env: SELF_API_MODELS             # 逗号分隔模型名
    backup: FREE_POOL
    note: "对接任何 OpenAI 兼容服务"

  BODY_OWN:
    type: local_private
    base_url_env: BODY_OWN_BASE_URL         # 你本地/私有部署的模型服务
    api_key_env: BODY_OWN_KEY
    models_env: BODY_OWN_MODELS
    backup: LOCAL_OLLAMA
    note: "bodydy 自有的模型落地处，本地 ComfyUI/Ollama 加载"

  # CUSTOM_XXX: 复制上面任一段，改名即可，例如接即梦/可灵官方免费额度：
  CUSTOM_JIMENG:
    type: openai_compatible
    base_url_env: JIMENG_BASE_URL
    api_key_env: JIMENG_KEY
    models: [jimeng-video-pro]
    backup: CNB_GPU
    note: "官方免费额度打底，耗尽切 CNB"
```

## 怎么加一个自定义通道（示例：接可灵）
1. 复制 `CUSTOM_JIMENG` 段，改名 `CUSTOM_KLING`，填 env 变量名。
2. 在系统/`.env` 里设 `KLING_BASE_URL` / `KLING_KEY`（不写进本文件）。
3. 命令注册表「模型通道」栏填 `CUSTOM_KLING` 即可。
**全程不碰核心代码，符合 v1 可迭代要求。**
