# AI 多模态产品工作台（本地私有版 · 对标直播间 29.9 聚合台）

## 0. 它是什么
本地私有版的「AI 多模态接单工作台」：
- **不是**直播间那个 API 中转倒卖套餐（29.9 额度制、版权模糊、平台跑路丢素材）。
- **是**跑在你本机 WorkBuddy + CNB 云端 GPU 上的 Agent 工作台，密钥/素材/知识库全自有。
- 三层核心（生文 / 生图 / 生视频）+ 文档 + 网页，**全部靠「命令注册表」扩展**：你往 `AI 多模态产品工作台 · 命令注册表（2026年9月29日）.md` 里加一行，工作台就多接一种活儿。

## 1. 调用约定（1234 + 四化）
- **标准化**：每个订单先建任务卡 `01_正在执行实单/{日期}_{客户}_{需求}/需求确认文档/任务卡.md`（五段结构见 AGENTS.md）。
- **模块化**：命令 → 命中 `AI 多模态产品工作台 · 命令注册表（2026年9月29日）.md` 的模块 → 调对应 `prompts/` 模板 → 走对应模型通道。
- **自动化**：WorkBuddy 主控编排（一键生成），产物自动进目录 + 六端归档（Obsidian/IMA/乐享/CNB/GitHub/WorkBuddy；保密单按 MEMORY #11 降级本地 Priv 库）。
- **智能化**：稳定后仿截图做「三层卡片」网页界面，发布为在线链接当接单演示作品。

## 2. 模型通道（可切换 / 自定义 / 备份 · 详见 `AI 多模态产品工作台 · 模型通道配置（2026年9月29日）.md`）
> v1 即可灵活切换，后续按订单持续迭代。通道不写死代码，只配不编。

- **切换方式**：命令级(`写剧本 @CNB_GPU`) > 注册表级(命令行填通道键) > 全局默认(`DEFAULT_CHANNEL`)。
- **故障转移**：每通道可设 `backup`，主用挂了自动切备用，不中断任务。
- **内置通道**：`FREE_POOL`(18091免费池) / `CNB_GPU`(Flux·Wan2.2) / `LOCAL_OLLAMA`(本机离线) / `SELF_API`(自建OpenAI兼容) / `BODY_OWN`(你自有模型) / `CUSTOM_*`(任意自定义)。
- **自定义**：复制一段改名字+env 变量即可接任何模型（含本地新下载的、即梦/可灵官方免费额度、Body 自有模型），Key 全走环境变量不落文件。
- **当前主用**：生文→FREE_POOL(可挂忘语风格库)；生图/视频→CNB_GPU(复用 comfyui-manju-zero-cost v1.2)；文档/网页→WorkBuddy 原生。

**一致性铁律（2026-09-29 汤哥指正入册）**：
- 续写**自有 IP 小说必须走 `小说续写流水线.py`**，它强制吃作品档案（人物档案/世界观/细纲/最新摘要/上一章尾部）+ 强制角色名白名单校验。
- 人名必须与作品档案**一字不差**；出现「同姓异名」变体（如林凡/林尘冒充林小默）→ 直接 FAIL 阻断落盘，违规草稿存证。
- 违规样本须留档（`违规草稿_第N节.txt`），用于反向校准提示词，禁静默放过。

**免费池韧性（实测约束，务必遵守）**：
- 源站 Cloudflare 约 100s 网关上限 → 单次生成超时必 524；**大任务必须拆小步**（细纲/逐节/逐镜），单步 max_tokens ≤3000、输入 ≤3000 字。
- 免费池拥堵是**瞬态**的 → 用轮次重试（默认 4 轮 × 25s）抗抖动，禁一次失败即判死。
- 上游代理：`teamorouter_failover_proxy.py`（15740），Key 从 HKCU 注册表内存注入（沙箱 shell 不继承用户级 env）；**分离 detached 进程会被拦网**，须用受管后台任务方式常驻。

## 6. 边界与合规
- 第 38 形态：LLM 响应必须过 L4 内容校验（落盘前查正文非空、未截断、model 未漂移），禁信 HTTP 200。
- 保密单（如「邮政色系贴纸表情包」）：六端归档降级为本地 Priv 库 + WorkBuddy，禁进 CNB/GitHub/IMA/乐享。
- 不替客户做违法/侵权内容；商用版权以开源模型/自有 GPU 产出为准，边界清晰。
