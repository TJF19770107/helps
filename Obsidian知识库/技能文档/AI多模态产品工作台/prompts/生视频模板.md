# 生视频提示词模板（生视频模块 · CNB GPU Wan2.2 / H3）

> 复用 comfyui-manju-zero-cost v1.2 的 Wan2.2 五铁律：ComfyUI 原生 / Repackaged 16.89GB / HF_ENDPOINT=https://hf-mirror.com / Wan22ImageToVideoLatent + ModelSamplingSD3(shift=8) / 帧数 4n+1、宽高 32 倍数。

## #漫剧
输入：分镜图序列 + 每镜台词/时长。
生成：连贯漫剧片段，角色人脸与服装跨镜一致。
参数：帧数 4n+1，分辨率 832x480 或 1280x720，FPS 16。
音频：可选 TTS 配音(Edge-TTS 免费)。

## #口播
输入：口播稿 + 主播参考图/数字人。
生成：真人/数字人出镜口播，口型对齐。
结构：开头钩子(3s) + 主体 + 结尾引导。

## #带货
输入：带货稿 + 产品图。
生成：产品展示快剪 + 卖点字幕 + 背景音乐。
节奏：每 2-3 秒一切，强节奏卡点。

## #短片
输入：单张概念图 / 简短描述。
生成：5-15 秒氛围短片(CNB-Issue 类)。
参数：最低算力，快速出片验证。
