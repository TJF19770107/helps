# 九本互证：新旧两套典籍对照

> **新 4 本**（本轮入库）：黄庭经 / 清静经 / 阴符经 / 太上感应篇
> **旧 5 本**（2026-10-29 识神层双仓）：周易参同契 / 悟真篇 / 钟吕传道集 / 太乙金华宗旨 / 性命圭旨
> 参同契两边都有，去重后**共 9 本**。

## 一 · 一个意外发现：两套本就是一条血脉

这是本轮对照最要紧的收获，先说结论：

> **《太乙金华宗旨》正文里，直接引用了《黄庭经》。**

原文（旧仓 `01_原典/太乙金华宗旨.md`，回光章）：

> 「回光之功，全用逆法，注想天心，天心居曰月中。**《黄庭经》云："寸田尺宅可治生，尺宅面也，面上寸田，非天心而……"**」

→ 而「寸田尺宅可治生」出自**《黄庭外景经》第八章**（本轮新入库，`01_原典/02_黄庭外景经.md`）。

**这意味着什么：**
- 这两套典籍不是"两套"——**后者是前者的注脚与延伸**。
- 用户提的"合并进同一个丹道知识库、相互对照相互印证"，不是我们的编辑选择，是**文本本身的关系**。
- 也印证了《参同契》「三道由一，俱出径路」——丹道文献本来就是一个互相引用的网络，不是九本独立的书。

### 1.1 引用链可以画出来

```
黄庭外景经（魏晋）
   │  「寸田尺宅可治生」
   ↓ 被直接引用
太乙金华宗旨（唐/宋）
   │  「回光之功，全用逆法…《黄庭经》云…」
   ↓ 概念延伸（回光 = 内视的另一种说法）
性命圭旨（明）
   │  性命双修、内景图
   ↓
清代内丹诸家
```

→ **"内视"这条线，从黄庭经到太乙金华，是一脉相承的。** 不是我们拼的。

## 二 · 核心概念互证表（9 本横穿）

### 2.1 内视 / 回光 / 存神 —— 同一个动作的六个名字

| 书 | 用词 | 原话 | 落点 |
|---|---|---|---|
| 黄庭经 | **存思 / 存神** | 「泥丸百节皆有神」 | 对象：遍身之觉 |
| 阴符经 | **机在目** | 「心生于物，死于物，机在目」 | 作业点：目 |
| 清静经 | **内观** | 「内观其心，心无其心」 | 结果：观到底无实体 |
| 太乙金华宗旨 | **回光** | 「回光之功，全用逆法，注想天心」 | 方法：逆（反向） |
| 太乙金华宗旨 | **天光寄目** | 「天光不可见，**寄之两目**」 | 通道：目 |
| 性命圭旨 | **内景 / 返观** | （内景图为全书骨架） | 载体：图 |
| 参同契 | **内照** | 「金入于猛火，色不夺精光」 | 验相：不变色 |

→ **六个名字，一个动作。** 最强的一对互证是：

| 阴符经 | 太乙金华宗旨 |
|---|---|
| 「机在目」 | 「天光不可见，寄之两目」 |

→ 一个说"机关在眼睛"，一个说"光通过眼睛走"——**两本书隔了近千年，说的是同一件事。**
→ 这就把「内视」的作业点彻底钉死在"目"上了，不是后人编的。

### 2.2 元神 / 识神 —— 太乙金华宗旨的独特贡献

《清静经》《黄庭经》都讲"神"，但**没有明确分元神与识神**。这个区分是《太乙金华宗旨》给出的：

> 「凡人投胎时，**元神居方寸，而识神则居下心。**」（第二章 元神、识神）

| 书 | 有没有"元神/识神"之分 |
|---|---|
| 黄庭经 | ❌ 只讲"身中诸神"，不分 |
| 清静经 | ❌ 只讲"神"，不分 |
| 阴符经 | ⚠️ 隐含（「不神而所以神」近之） |
| **太乙金华宗旨** | ✅ **明确提出，且给了位置（方寸 vs 下心）** |
| 性命圭旨 | ✅ 沿用此分 |
| 钟吕传道集 | ⚠️ 讲"阳神/阴神"，角度不同 |

→ **对本轮心法的意义极大**：
- 「觉其神」的那个"神"，是**元神**（居方寸），不是识神（居下心）。
- 识神是"分别、计较、造作"的那个——**"观其形"正是识神在干活**。
- 所以「不是观其形，而是觉其神」可以更精确地重述为：
  > **不是用识神去观一个形，而是让元神自己觉自己。**

→ 这是旧仓对本轮新建心法篇的**关键补正**。心法篇里没有这一层，是因为当时只读了新 4 本。**这条互证让心法更准了。**

### 2.3 以神驭炁 —— 五个比喻，一个道理

| 书 | 比喻 | 原话 |
|---|---|---|
| 太乙金华宗旨 | **主人与奴婢** | 「又如**主人精明，奴婢自然奉命**，各司其事」 |
| 太乙金华宗旨 | **圣王定都** | 「如圣王定都立极，执玉帛者万国」 |
| 参同契 | **轴与轮** | 「坎离匡郭，**运毂正轴**」 |
| 黄庭经 | **积累非神通** | 「仙人道士非有神，**积精累气以为真**」 |
| 阴符经 | **缰绳** | 「禽之制在**炁**」 |

→ 五个比喻，指向同一个结构：**主静、从动；主不驱、从自随。**
→ 太乙金华的"主人精明，奴婢自然奉命"是最白的一句：**神只要"精明"，炁自己会听令。**
→ 与本轮心法篇的「磁铁与铁屑」是同一层意思，只是我用的是现代比喻。

### 2.4 性命 —— 两套典籍的分工正好互补

| 书 | 性（心/神） | 命（身/炁） | 说明 |
|---|---|---|---|
| 清静经 | ●●● | ○ | 纯性功，通篇不谈气 |
| 太上感应篇 | ●●● | ○ | 纯性（伦理面） |
| 黄庭经 | ○ | ●●● | 偏命，讲脏腑诸神 |
| 参同契 | ●● | ●●● | 偏命，纳甲火候 |
| 太乙金华宗旨 | ●●● | ● | **名为"金华"，实以性摄命**（回光即性功） |
| 悟真篇 | ●● | ●●● | 偏命（金丹药物火候） |
| 钟吕传道集 | ●● | ●● | 性命各半，体系最完整 |
| **性命圭旨** | ●●● | ●●● | **书名即主张：性命必须双修** |

→ **九本合起来，性功四本半、命功四本半。** 这不是巧合，是完整的配平。
→ 用户选的新 4 本（黄庭/清静/阴符/感应），**恰好补上了旧 5 本最缺的部分：性功的"减法"与"德性"**。
  - 旧 5 本里没有一本讲"遣欲澄心"（清静经的独有贡献）
  - 旧 5 本里没有一本讲"德是准入条件"（感应篇的独有贡献）
  - 旧 5 本里没有一本讲"天人机制的极简表述"（阴符经 400 字的独有贡献）

→ **两套合并后，才第一次完整。**

### 2.5 果位 —— 钟吕五等仙 × 感应篇善数

这是最硬的一处互证，因为两本书**给了同一套果位的两个维度**：

**《钟吕传道集》**（旧仓）：
> 「仙有五等，法有三成。……**鬼仙、人仙、地仙、神仙、天仙**之不等，皆是仙也。」

**《太上感应篇》**（新仓）：
> 「欲求**天仙**者，当立一千三百善；欲求**地仙**者，当立三百善。」

| 果位 | 钟吕：修证维度 | 感应篇：德性维度 |
|---|---|---|
| 鬼仙 | 最下，不离于鬼 | （未列） |
| 人仙 | 不离于人 | （未列） |
| **地仙** | 不离于地 | **300 善** |
| 神仙 | 不离于神 | （未列） |
| **天仙** | 不离于天 | **1300 善** |

→ **两本书拼起来，果位变成了二维的：一边是修证（炼到什么程度），一边是德性（撑到多大）。**
→ 这正好印证了本轮《感应篇》解读里的判断：**德不是道德装饰，是容量条件。**
→ 而且钟吕传道集本身也讲"人仙"需忠孝——**两本在"德"这一维上完全一致。**

### 2.6 「静」—— 四本书四种说法

| 书 | 原话 | 静的定义 |
|---|---|---|
| 清静经 | 「静者动之基」 | 静是动的**底基** |
| 阴符经 | 「自然之道静，故天地万物生」 | 静是**生之母** |
| 阴符经 | 「至静之道，律历所不能契」 | 至静**不可量** |
| 参同契 | 「动静有常，奉其绳墨」 | 静是**合节度**（非不动） |
| 太乙金华宗旨 | 「回光之功，全用逆法」 | 静是**逆**（反向外驰） |

→ 五说并列，一句话统起来：**静不是"不动"，是"不逐"。**
→ 与心法篇「心神若静」的判据（需不需要忍）完全一致。

### 2.7 借象 —— 参同契与悟真篇共用一套密码

| 参同契 | 悟真篇 | 所指 |
|---|---|---|
| 龙虎 | 「庚虎甲龙」 | 阴阳二炁 |
| 铅汞 | 「水银丹砂」「白金黑锡」 | 先天/后天之炁 |
| 坎离 | 「离坎男女」 | 水火、神炁 |
| 金华 | 「金液还丹」 | 真阳 |

**悟真篇原话**（旧仓）：
> 「阅尽群经及诸家歌诗论契，皆云**日魂月魄，庚虎甲龙，水银丹砂，白金黑锡，离坎男女**，能成金液还丹。」

→ 张伯端自己列了这串名词，然后说这些东西"能成金液还丹"——**他是在总结前人的借象系统，而那个系统正是参同契建立的。**
→ **参同契 → 悟真篇，是同一套密码的两代传承。**
→ 所以本库《参同契》解读里说的"没有一个字是实指"，在悟真篇这里得到了证实：**它自己就把这些词当符号用。**

## 四 · 九本合读的三条主线

### 4.1 主线一：神从哪出去、怎么回来

```
出去：阴符经「机在目」→ 太乙金华「天光寄两目」
回来：太乙金华「回光，全用逆法」→ 黄庭经「精神还归老复壮」
```

→ **"逆"是这条主线的关键词。** 出去是顺，回来是逆。
→ 太乙金华「全用**逆**法」四个字，把内视的方向性说尽了。

### 4.2 主线二：什么在修、修到哪

```
什么在修：黄庭经（身中有神）→ 太乙金华（元神 vs 识神）
修到哪：  钟吕传道集（仙有五等）→ 感应篇（1300/300 善）
```

### 4.3 主线三：凭什么有效、什么时候做

```
凭什么：阴符经（三盗既宜，三才既安）
什么时候：参同契（月体纳甲）→ 悟真篇（药物火候）
收束：  性命圭旨（性命双修，缺一不可）
```
