# 《黄庭经》解读

> 本文件是**解读**，不是原文。凡引原文均标注出处章次；凡属我的推断一律写明「推论」。
> 原文见 `01_原典/01_黄庭内景经_三十六章.md`、`01_原典/02_黄庭外景经.md`。

## 一 · 它是什么

| 项 | 内容 |
|---|---|
| 脉系 | 上清派核心经典；《内景经》托名太上玉晨大道君传授、扶桑大帝君命旸谷神王景林真人传魏华存（魏夫人） |
| 别名 | 《太上黄庭内景玉经》《上清黄庭内景玉经》，通称《黄庭经》 |
| 结构 | 内景经 36 章；外景经 24 章，分上中下三卷，不分章（李西月本分为 24 章） |
| 底本 | 《正统道藏》洞玄部本文类 |
| 先后 | 外景经传世更早（王羲之曾书《黄庭外景经》），内景经为后世扩写深化 |
| 在五书中的位置 | **第一本 · 筑基** |

**一句话定位**：黄庭经不教你"想一个画面"，它教你**把身体读成一张有名字、有官职、有居所的图**——这张图就是内视的坐标系。没有这张图，"内视"就只能是空想。

## 二 · 三个必须先说清的名词

### 2.1 「黄庭」

不是某一个点，是**一个区间**。历代注家分歧，主要有三说（口径分歧，不替你选）：

| 说 | 位置 | 依据 |
|---|---|---|
| 中丹田说 | 心之下、脾之上，约当胃脘 | 「上有黄庭下关元」（外景经第一章）——黄庭在关元之上，故不在下丹田 |
| 三黄庭说 | 上黄庭（泥丸/脑）、中黄庭（心/绛宫）、下黄庭（脾/丹田） | 内景经分章讲上中下三部 |
| 脾土说 | 脾属土，土色黄，「庭」为中央 | 五行配属推演 |

→ **实用结论**：读经时遇到「黄庭」二字，先看上下文在哪一部。**内景经的默认语境是三黄庭**，外景经的默认语境偏中丹田。这不是含糊，是古人在不同层次用同一个词。

### 2.2 「内景」

「景」= 象、影。内景 = **身内之象**。
注意：内景≠解剖图。它把五脏六腑写成"宫室"，把神写成"衣朱衣的士人"，这是**象征层**，不是**解剖层**，也不是**让你照着想象的画面层**。

> 这三层必须分开，否则读黄庭经必然滑向"观想一个穿红衣服的小人坐在心脏里"——那是把象征当实体，正是后面「内视辨形神」要拆的东西。

### 2.3 「身神」

内景经通篇给身中诸神起名字：

| 神 | 名 | 字 | 居所 | 出处 |
|---|---|---|---|---|
| 心神 | 丹元 | 守灵 | 心 | 心神章第八 |
| 肺神 | 皓华 | 虚成 | 肺 | 肺部章第九 |
| 肝神 | 龙烟 | 含明 | 肝 | 肝部章第十一 |
| 肾神 | 玄冥 | 育婴 | 肾 | 肾部章第十二 |
| 脾神 | 常在 | 魂停 | 脾 | 脾部章第十三 |
| 胆神 | 龙曜 | 威明 | 胆 | 胆部章第十四 |

**为什么要有名字？** 这是黄庭经最关键的一个设计：
- 若只讲"你的心在那里"，你会去想它的**形状**；
- 讲了"名丹元、字守灵"，你唤的是**一个可指称的存在**，而不是一幅画。

→ 名字是**觉的锚点**，不是**形的描摹**。这一点与视频心法「内视，不是观其形，而是觉其神」是同构的——黄庭经用"命名"来强制你从形回到神。

## 三 · 内景三十六章的结构逻辑

不是杂乱罗列，有明确的推进次序：

```
① 立总纲      上清章第一 → 上有章第二 → 口为章第三 → 黄庭章第四
                （定坐标：上清/黄庭/关元/命门/口为门户）
② 立中轴      中池第五 → 天中第六 → 至道第七 → 心神第八
                （定枢机：泥丸百节皆有神，心神为君）
③ 铺脏腑      肺九 心十 肝十一 肾十二 脾十三 胆十四 脾长十五
                （把①的坐标落到具体器官，各配神名）
④ 讲用功      上睹十六 灵台十七 三关十八 若得十九 呼吸二十 琼室廿一
                （从"知道"到"用得上"：收视、返听、调息）
⑤ 讲火候与验证 常念廿二 治生廿三 隐景廿四 五行廿五 高奔廿六 玄元廿七
                （内在变化的次第与自验）
⑥ 讲果与戒    仙人廿八 紫清廿九 百榖三十 心典卅一 经历卅二
               肝气卅三 肺之卅四 隐藏卅五 沐浴卅六
                （效验、禁忌、收功）
```

### 3.1 开篇四章：先定坐标，再谈修行

- **上清章第一**：立"上清"之境为究竟位。
- **上有章第二**：立上下关系——上有黄庭、下有关元，**修行是从"知上下"开始的**。
- **口为章第三**：「口为玉池太和宫」——口是津液之门户。注意这里不是"咽口水养生"这么浅，它把口定为**内外交通的第一个关口**。
- **黄庭章第四**：「黄庭内人服锦衣，紫华飞裙云气罗」——注意"内人"的措辞：**黄庭里有"人"**。这个"人"不是肉身的你，是身中之神。

### 3.2 至道章第七：全经最要紧的一句方法论

> 「至道不烦诀存真，**泥丸百节皆有神**。」

- 「不烦」= 不复杂。丹道第一步不是加法（加姿势、加咒、加观想），是**减法到"存真"**。
- 「泥丸百节皆有神」= 神不是只有心肝脾肺肾那五个，**周身百节每一处都有神**。这句话把"内视"的对象从"几个器官"扩展到"整个身体的存在感"。

> **这一句就是"内视"的经证**：内视的对象不是器官形状，是"百节皆有神"——即**每一处都有觉知**。

### 3.3 心神章第八：为什么心是君

> 「心神丹元字守灵。」

「守灵」二字是全经的题眼之一：**心的职司是"守"，守的是"灵"**。
- 不是"心想事情"，是"心守灵明"。
- 反过来推：**心一散，灵就失守**。这解释了为什么后面《清静经》要用整整一卷讲"澄其心"。

### 3.4 呼吸章第二十与琼室章第二十一：炁的入口与器

> 「呼吸庐间入丹田，玉池清水灌灵根。」（外景经第一章，内景亦有同旨）

- 「庐间」= 鼻息出入之处；「丹田」= 炁所归。
- 这条链路是：**息（外）→ 庐（门户）→ 丹田（府库）→ 灵根（受用者）**。
- 「玉池清水」= 津液。古法把津液视为炁之载体之一，故"灌灵根"。

**必须标注的边界**：这里讲的是**生理层面的炁机描述**，不是让你去"用力咽口水"或"憋气下行"。任何带"引导炁走某条路线"的操作都属于实修范畴，本库不提供、也不建议自炼（见 `04_风险与边界/`）。

### 3.5 仙人章第二十八：全经最硬的一句反迷信

> 「**仙人道士非有神，积精累气以为真。**」

这一句把黄庭经从"求神拜仙"里彻底摘出来：
- 仙人不是"另有一种神异"，是「积精累气」积累出来的结果。
- 「以为真」= 以此为大真。**真在积累，不在神通。**

→ 凡把丹道讲成"求感应、求神通、求见光见佛"的，都不是黄庭经的路子。

### 3.6 沐浴章第三十六：为什么以"沐浴"收尾

内景经以沐浴章终卷。这里的"沐浴"不是洗澡，是**洗心**——以身体层面的洁净喻心层面的涤除。
- 收尾放在"洗"，说明全经的落点不在"得到什么"，而在"去掉什么"。
- 这与下一本《清静经》的"遣欲"是同一条线：**黄庭经以沐浴收，清静经以遣欲起，两本是一口气。**

## 四 · 外景二十四章：更早、更直、更"身体"

外景经比内景经早，文字更朴，讲得更"贴身"：

| 章 | 关键句（原文繁体，逐字照录） | 要点 |
|---|---|---|
| 一 | 上有黃庭下關元，後有幽闕前命門 | 四方定位：上/下/后/前，先给身体装坐标系 |
| 二 | 黃庭中人衣朱衣 | "中人"——内景有"人" |
| 四 | 方寸之中謹蓋藏，精神還歸老復壯 | 方寸=心；"還歸"二字点出这是**返**的功夫 |
| 五 | 至道不煩無旁午，靈臺通天臨中野 | 与内景"至道不烦"呼应 |
| 七 | 絳宮重樓十二級，宮室之中五炁集 | 绛宫=心；十二级=气管/重楼隐喻 |
| 八 | 棄捐淫慾專守精，寸田尺宅可理生 | 「寸田尺宅」= 身；把身当田宅来经营 |
| 十一 | 恬淡無欲游德園，清淨香潔玉女存 | **"德園"** ——外景经已把"德"写进修行，与《感应篇》暗合 |
| 十三 | 五行參差同根節，三五合炁要本一 | 五行归一 |
| 十五 | 魂欲上天魄入泉，還魂返魄道自然 | **魂魄分离是病，还返是道** ——内视的深层标的 |
| 二十 | 璇璣懸珠環無端 | 周天无端，循环不居 |
| 二十四 | 大道蕩蕩心勿煩，被髮行之可長存，吾言畢矣勿妄傳 | **全经收在"勿妄傳"三字上**：这不是给人随便传的东西 |

**内外景的差别（我的判断）**：
- 外景经更像**口诀**：句子短、位置实、讲身体的具体部位。
- 内景经更像**论**：加了章节结构、脏腑系统、果位与戒律。
- 若初读，**先外景后内景**：外景给坐标，内景给体系。

## 五 · 丹道层面：它在整套修行里干什么

| 层面 | 黄庭经的贡献 |
|---|---|
| **理论** | 建立"身中有神、神各有名、名各有职"的内景本体论 |
| **内修观想** | 提供**存思**的对象与坐标（三丹田、五脏神、百节神） |
| **心性** | 「至道不烦」定减法基调；「守灵」定心的职司；「非有神…积精累气」破神通 |
| **实修接口** | 呼吸—庐间—丹田—灵根 的炁机链路（只作理解，不作操作指导） |

### 5.1 存思 ≠ 想象

这是最容易被读错的地方，必须拆开：

```
想象（观其形）              存思（觉其神）
─────────────              ─────────────
有画面                      无画面，有"在"
要用力维持                  不用力，一唤即在
画面越清晰越好              清晰反而是干扰
形象是目的                  名号是锚点
容易走成自我催眠            走到"知"就停
```

黄庭经给了名字（丹元、守灵…）、给了服色（朱衣、锦衣）、给了居所（绛宫、玉房），**这些都是锚点，不是画稿**。
→ 用它们来"定位"，不要用它们来"作画"。

### 5.2 与"内视"心法的接口

视频心法四句，逐句找黄庭经的落点：

| 心法 | 黄庭经依据 | 读法 |
|---|---|---|
| **内视** | 「泥丸百节皆有神」 | 视的对象是"神的存在"，不是"器官的形状" |
| **不是观其形** | 全经用"名/字/服色/居所"而非"尺寸/形状/颜色渐变" | 给你名字不给你画稿，就是在防你观形 |
| **而是觉其神** | 心神「字守灵」 | "守灵"是觉，不是看 |
| **以神驭炁** | 「呼吸庐间入丹田」（息→炁→田） + 「积精累气以为真」 | 神为主、炁为从；神凝则炁聚 |
| **心神若静** | 「至道不烦」 | 不烦 = 静；静不是不动，是不逐 |

## 六 · 争议与不确定（如实标注）

1. **「黄庭」到底在哪** —— 三说并存，历代未定。我不替你择一，读经时按上下文判。
2. **内景经的成书年代** —— 托名魏华存，实际文本层累而成，学界多认为东晋。《正统道藏》本已是整理本，非原刻。
3. **「身神」是实体还是隐喻** —— 道教内部有"存神如存实"的传统，现代读者多作"身心功能的拟人化"。**两读都成立，取决于你是信徒还是研究者**，本库不裁决。
4. **外景/内景先后** —— 传统说法与文本分析结论不完全一致。本库依"外景早于内景"的通行说法，但标注为**倾向**而非定论。
5. **本库无图像** —— 《黄庭经》传统上配有内景图（《性命圭旨》亦然），电子本只有图题，图未收。

## 七 · 一句话带走

> **黄庭经给的不是功法，是一张地图；地图的用法是"认出自己在哪"，不是"照着画一遍"。**
