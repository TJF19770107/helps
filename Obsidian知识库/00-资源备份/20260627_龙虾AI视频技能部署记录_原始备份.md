## 五、故障排除（原始记录）

| 问题 | 解决方案 |
|------|---------|
| npm install 失败 | npm config set registry https://registry.npmmirror.com |
| FFmpeg 不识别 | 检查 PATH: where ffmpeg |
| Manim 渲染报错 | 安装 LaTeX: winget install MiKTeX.MiKTeX |
| OpenMontage 依赖冲突 | 删除 node_modules 重装 |
| Remotion 白屏 | 检查 React 版本兼容性 |
| 磁盘空间不足 | 用 --resolution 720p 降低分辨率 |
