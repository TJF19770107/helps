## 1. 标准化（Standardize）✅ 已落地

### 1.1 目录结构标准
```
豆包主会话全集/
├── raw_original/          # 原始归档(完整不改写)
│   └── images/            # 原图附件
├── extracted_knowledge/   # 萃取精华(衍生副本)
│   ├── _security_red_lines/  # 密钥红线审计(不进git/不进四端)
│   ├── _config_red_lines/    # 配置红线(进git可同步)
│   └── _methodology/         # 元方法论(本文件)
└── .workbuddy/memory/     # 本地日志(不进git/不进四端)
```

### 1.2 笔记模板标准
每份萃取笔记必须含：
- **来源会话日期标签**（如 `2026-08-23`）
- **三分类标记**：`【已验证可行方案】` / `【猜想待验证想法】` / `【明确禁止事项/风险红线】`
- **引用原图** 指向 `raw_original/images/` 相对路径
- 不改写原始事实，只归纳

### 1.3 脱敏标准
- 原始文件（raw_original）**原样保留**密钥
- 萃取版（extracted_knowledge）**脱敏遮蔽**
- 敏感串（sk-xxx）禁止明文出现在任何可同步产物
