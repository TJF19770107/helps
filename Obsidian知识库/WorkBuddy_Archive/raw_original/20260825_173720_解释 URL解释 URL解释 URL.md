## **🤖 助手**

URL 是 “统一资源定位符”（Uniform Resource Locator）的英文缩写，中文通常译为 “网址”，是因特网上用于指定信息位置的表示方法，通过它就能找到网上的某个资源 1 2 。以下是具体介绍： 作用 1 ：URL 是互联网的基础，是浏览器用来检索 web 上公布的任何资源的机制。互联网之所以 “互联”，就是因为网页可以通过 “链接” 包含其他 URL，用户点击即可从一个 URL 跳转到另一个 URL，前往不同网站，获取如网页、图像、音频等各种资源。 组成部分 4 ：URL 的一般语法格式为 “protocol://hostname (:port)/path (;parameters)(?query)#fragment”。 protocol（协议） ：指定使用的传输协议，常用的有 HTTP、HTTPS，还有 FTP、file、mailto 等。 hostname（主机名） ：指存放资源的服务器的域名系统（DNS）主机名或 IP 地址，有时也可包含连接到服务器所需的用户名和密码。 port（端口号） ：为整数，是可选部分，省略时使用方案的默认端口，如 HTTP 的默认端口为 80，HTTPS 为 443。 path（路径） ：由零或多个 “/” 符号隔开的字符串，一般用来表示主机上的一个目录或文件地址。 parameters（参数） ：用于指定特殊参数的可选项，由服务器端程序自行解释。 query（查询） ：也是可选部分，用于给动态网页传递参数，可有多个参数，用 “&” 符号隔开，每个参数的名和值用 “=” 符号隔开。 fragment（信息片断） ：通常是字符串，用于指定网络资源中的片断，如定位网页中的特定位置。 分类 1 ：可分为绝对 URL 和相对 URL。绝对 URL 带有资源的完整信息，包含协议、主机、路径等部分，能独立确定资源位置；相对 URL 不包含资源位置的全部信息，必须结合当前网页的位置才能定位资源。
