## **🤖 助手**

新建飞书多维表格主要有以下几种方法： 通过云空间新建 1 ：登录飞书账号，进入云空间主页，点击右上角的 “新建” 按钮，在弹出的选项中点击 “新建多维表格”。你可以选择新建空白多维表格，也可以从模板库中挑选合适的模板来创建。 在工作台新建 3 ：进入飞书工作台，找到并点击 “多维表格” 应用，然后点击右上角的 “新建” 按钮，选择 “多维表格” 选项，接着为新建的多维表格命名，点击创建后，系统会自动生成一个新的多维表格，并打开编辑界面。 使用智能伙伴新建 2 ：向飞书智能伙伴发送指令，让其根据要求自动创建多维表格。首先需进入数据表页面，可通过点击表格上方工具栏中的智能伙伴标识、单击单元格后出现的智能伙伴标识或空白数据表下方场景推荐中的智能伙伴标识来唤醒智能伙伴，然后输入指令，如创建单张数据表和对应的仪表盘，或创建包含仪表盘、多张数据表、示例数据的业务系统等。 通过 API 新建 4 ：若有一定的开发能力，可使用飞书 API 来创建多维表格。需先在飞书开放平台获取相关权限，配置好文件夹权限等，然后在 API 调试台根据文档说明，传递相应参数（如多维表名称、文件夹 token 等）发起创建请求，即可新建多维表格。此方法适合需要批量创建或与其他系统集成自动化创建等场景。

怎么进入小红书博主笔记

## **🤖 助手**

进入小红书博主笔记主要有以下几种方法： 通过搜索博主账号或昵称进入 1 ：打开小红书 APP，点击首页右上角的搜索选项或顶端的搜索栏，输入博主的小红书号或昵称，点击搜索。在搜索结果中点击 “用户”，找到对应的博主账号，点击进入其主页，即可浏览该博主发布的所有笔记。 从具体笔记进入博主主页查看其他笔记 3 ：若你已看到某篇该博主的笔记，可直接点击笔记页面上方的博主头像或昵称，进入博主主页，下滑页面就能查看其发布的其他笔记。 通过历史记录进入 4 ：点击小红书右下角的 “我”，再点击 “观看历史”，可查看浏览过的所有笔记。若曾浏览过该博主的笔记，就能在此找到相关记录，点击进入笔记后，再按上述方法进入博主主页查看其他笔记。 通过收藏夹进入 4 ：如果之前收藏过该博主的笔记，可点击小红书右下角的 “我”，再点击 “收藏”，在收藏夹中找到相关笔记，进入笔记页面后点击博主头像或昵称，进而进入博主主页查看更多笔记。 通过笔记 ID 查询进入 4 ：每个笔记都有唯一的 ID 号，若知道目标笔记的 ID 号，可在小红书搜索框中输入 “笔记 id:（ID 号）”，即可直接跳转到该笔记。若该笔记是你想找的博主发布的，就能从笔记页面进入博主主页。
