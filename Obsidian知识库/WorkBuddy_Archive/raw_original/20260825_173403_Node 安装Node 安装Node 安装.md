在不同的操作系统上，安装 Node.js 的方式有所不同。下面为你介绍在 Windows、macOS 和 Linux 系统下安装 Node.js 的方法。 Windows 系统安装步骤 下载安装包 ：访问 Node.js 官方下载页面（ https://nodejs.org/ ），选择 LTS 版本的 Windows Installer (.msi) 进行下载。 运行安装程序 ：双击下载的 .msi 文件，按照安装向导的提示进行操作。在安装过程中，可以选择安装路径以及是否安装 npm 包管理器。 验证安装 ：安装完成后，打开命令提示符（CMD）或 PowerShell，输入以下命令检查 Node.js 和 npm 是否安装成功： bash node -v npm -v macOS 系统安装步骤 使用 Homebrew 安装 ：如果你已经安装了 Homebrew，可以直接在终端中运行以下命令进行安装： bash brew install node 下载安装包 ：若未安装 Homebrew，可访问 Node.js 官方下载页面，选择 LTS 版本的 macOS Installer (.pkg) 进行下载，然后双击运行安装程序并按提示操作。 验证安装 ：安装完成后，打开终端，输入以下命令验证安装： bash node -v npm -v Linux 系统安装步骤 以 Ubuntu/Debian 系统为例： 添加 Node.js 仓库 ：打开终端，运行以下命令添加 Node.js 官方仓库： bash curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash - 安装 Node.js ：添加仓库后，运行以下命令安装 Node.js 和 npm： bash sudo apt-get install -y nodejs 验证安装 ：安装完成后，输入以下命令验证： bash node -v npm -v 安装注意事项 版本选择 ：LTS 版本（长期支持版本）稳定性高，适合生产环境；Current 版本包含最新功能，适合开发和测试。 权限问题 ：在 Linux 和 macOS 系统上，使用 sudo 命令安装时需输入管理员密码。 更新 Node.js ：如需更新 Node.js，可以再次运行安装程序或使用包管理器进行更新。 通过以上步骤，你可以在相应的操作系统上成功安装 Node.js 和 npm。安装完成后，就可以开始使用 Node.js 进行开发工作了。
