## 七、核心速查命令（可复制）

### FFmpeg 常用操作
```bash
# 截取片段 (00:01:00 到 00:03:00)
ffmpeg -ss 00:01:00 -to 00:03:00 -i input.mp4 -c copy output.mp4

# 拼接多个视频
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4

# 转码为 H.265
ffmpeg -i input.mp4 -c:v libx265 -crf 23 output.mp4

# 添加字幕
ffmpeg -i video.mp4 -vf "subtitles=sub.srt" output.mp4

# 压缩视频
ffmpeg -i input.mp4 -c:v libx264 -crf 28 -preset fast output.mp4

# 生成缩略图
ffmpeg -i video.mp4 -vf "fps=1" thumb_%04d.png
```

## 八、故障排除

| 问题 | 解决方案 | 严重度 |
|------|---------|--------|
| npm install 失败 | `npm config set registry https://registry.npmmirror.com` | 中 |
| FFmpeg 不识别 | 检查 PATH: `where ffmpeg` | 高 |
| Manim 渲染报错 | 安装 LaTeX: `winget install MiKTeX.MiKTeX` | 中 |
| OpenMontage 依赖冲突 | 删除 `node_modules` 重装: `rm -rf node_modules && npm install` | 低 |
| Remotion 白屏 | 检查 React 版本兼容性 | 低 |
| 磁盘空间不足 | 用 `--resolution 720p` 降低分辨率 | 低 |
| git clone 超时 | 配置代理或使用镜像源 | 中 |
