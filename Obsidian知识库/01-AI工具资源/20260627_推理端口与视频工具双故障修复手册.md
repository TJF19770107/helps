## 故障1：推理端口57321 404断开

### 故障现象

```
unexpected status 404 Not Found: No endpoints found that support image input.
url: http://127.0.0.1:57321/v1/responses
```

连续5轮 Reconnecting 1/5~5/5 全部失败，Codex无法调用图像输入能力。

### 根因定位

| 端口 | 服务 | HTTP状态 | 结论 |
|------|------|---------|------|
| **15721** | CC-Switch 总网关 | **200 OK** | API代理正常工作 |
| **4567** | AI Code Switch | **405** | 备用链路可用 |
| **57321** | Codex++ 管理端口 | **404** | 管理界面，不代理API |

**根因**: config.toml 的 base_url 错误指向 57321（管理端口），正确应指向 **15721**（CC-Switch API代理）。

DualLink Recovery 脚本原文标注：
> 57321返回404=正常, 证明非API代理端口

### 修复操作

#### 步骤1：备份当前配置（已完成）

```powershell
Copy-Item "$env:USERPROFILE\.codex\config.toml" "$env:USERPROFILE\.codex\config.toml.bak" -Force
```

#### 步骤2：修改 config.toml（需管理员权限）

文件路径: `%USERPROFILE%\.codex\config.toml`

修改两处:

```toml
# 修改前（错误配置）
[model_providers.CodexPlusPlus]
wire_api = "responses"
base_url = "http://127.0.0.1:57321/v1"

# 修改后（正确配置）
[model_providers.CodexPlusPlus]
wire_api = "chat_completions"
base_url = "http://127.0.0.1:15721/v1"
```

#### 步骤3：连通校验

```powershell
# 测试 CC-Switch API
curl -s http://127.0.0.1:15721/v1/models

# 测试 MiMO 模型调用
curl -s -X POST http://127.0.0.1:15721/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"mimo-v2.5-pro","messages":[{"role":"user","content":"hi"}],"max_tokens":5}'
```

#### 步骤4：重启 Codex

关闭所有 Codex 会话后重新启动，确认不再出现404错误。

### 兜底方案

| 优先级 | 方案 | 配置 |
|--------|------|------|
| A（主） | CC-Switch 代理 | base_url = "http://127.0.0.1:15721/v1" |
| B（备） | AI Code Switch | base_url = "http://127.0.0.1:4567/v1" |
| C（兜底） | MiMO 云端直连 | base_url = "https://api.xiaomimimo.com/v1" + API Key |
