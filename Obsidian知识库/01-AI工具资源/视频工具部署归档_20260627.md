## 二、场景速查表

需求 -> 推荐工具 -> 做法

1. 从零做一个完整视频 -> OpenMontage -> 自然语言描述脚本需求 (5-15min)
2. 批量生成系列视频 -> Remotion -> 组件化模板+数据JSON (2-5min/个)
3. 做数学/算法动画 -> Manim -> Python脚本定义场景 (3-10min)
4. 做创意动效标题视频 -> HyperFrames -> HTML/CSS+GSAP动画 (5-15min)
5. 剪辑/裁剪/转码视频 -> FFmpeg -> 命令行参数指定操作 (1-5min)
6. 把多段素材混剪成一个 -> Video-Use -> 自然语言描述混剪需求 (3-10min)
7. 视频压缩到指定大小 -> FFmpeg -> ffmpeg -crf 28 调码率 (1-3min)
8. 视频加字幕 -> FFmpeg -> ffmpeg -vf subtitles=sub.srt (1-2min)
9. 视频拼接多个文件 -> FFmpeg -> ffmpeg -f concat (1-3min)
10. 生成函数图像动画 -> Manim -> axes.plot(lambda x: ...) (2-5min)
11. 数据报表可视化视频 -> Remotion -> React组件+数据props (3-8min)
12. 产品宣传动态文字 -> HyperFrames -> GSAP文字动画+CSS (5-15min)
