## 二、补口 ①：事件层 `quant_app/core/events.py`

**问题本质**：回测走 numpy 数组 for 循环，实盘走网关回调 —— **两条路径的撮合/费用/时间推进各写一遍**。
结果：回测赚的钱实盘复现不出来，因为压根不是同一套代码在跑。

**做法**：一套事件类型 + 一个引擎 + 两种驱动模式，业务代码只认 `Event` 和 handler。

| 模式 | 驱动方式 | 用于 |
|---|---|---|
| `sync`（默认） | `put()` 直接同步派发 | 回测：完全确定、可复现 |
| `async` | `put()` 入队，后台线程消费 | 实盘：低延迟、可并发 |

**自测结果**（`python events.py`）：

| 指标 | 值 |
|---|---|
| 喂入 K 线 | 51 根 → **实收 50 根** |
| 未闭合根剔除 | **1 根** ✅（防未来函数） |
| handler 报错 | 0 |
| 事件录制 | 51 条 |
| `same_source_ok` | **true**（同一 handler 在 sync/async 下语义一致） |

**附加资产**：`EventRecorder`（事件溯源）—— 实盘出事可同构重放复现，这是对冲基金的基本纪律。

## 三、补口 ②：风控层 `quant_app/core/risk.py`

**问题本质**：平台此前**可以在没有仓位上限的情况下把全部本金压在一次头肩底信号上，并且亏到爆仓都不停机**。
黑马回测报过 78.11% 最大回撤 —— 那不是策略的极限，是**没有风控闸**的必然。

**第一性原理**：先定义「什么情况下必须停手」，再谈「什么时候该下手」。
**收益是策略给的，活得久是风控给的。**

**六道闸**：

| # | 规则 | 拦什么 |
|---|---|---|
| R1 | 单笔风险上限（按止损距离反推仓位） | 赌徒式满仓 |
| R2 | 单标的仓位上限 | 全仓压一个币 |
| R3 | 组合总敞口上限 | 多标的叠加的隐性满仓 |
| R4 | 单笔名义上限 | 滑点/流动性事故 |
| R5 | 回撤闸（触发即**停机**，不是减仓） | 从峰值回撤 N% |
| R6 | 日亏熔断 / 连亏熔断 | 策略失效的早期信号 |

**自测结果**：**9/9 全通过**（每道闸都构造场景撞了一边）。

### 自测过程抓到的两个真 bug（这才是自测的意义）

**Bug 1｜组合敞口算错标的价格**
R3 用**本笔标的的价格**去估算其它标的的持仓市值 → 敞口恒被低估。
修法：其它标的用**各自的成本价**。

**Bug 2｜停机后连自己的仓都平不掉** ⚠️ 最危险
风控停机后请求平 BTC 多仓，被 R2 按「持仓超 30%」反向裁剪成 **0 张** → **想跑都跑不掉**。
修法：**风控只约束「增大敞口」的方向**；减仓/平仓无条件放行。
> 若没抓到：回撤闸会从「保护机制」变成「爆仓加速器」。

**Bug 3（静默失效）**：`_emit_halt` 用相对导入，独立运行时报 `ImportError` 被 `except` 静默吞掉
→ **停机事件根本没发出去，而报告显示一切正常**。已改为显式加载 + 失败留痕。

## 四、补口 ③：假设台账从「只写不验」到状态机

**新脚本**：`ai_quant_lab/hypothesis_runner.py`
**链路**：读台账 → 自动取数 → 跑回测 → **回写状态机**（待验 → 已验证/已证伪/搁置）

**首次实跑结果**（4 个标的、15m/1h/4h 三档粒度、含手续费）：

| # | 状态 | 结论 |
|---|---|---|
| H-001 | 搁置 | 本地缺 `funding_rate` 历史数据，无法验证（写明缺什么） |
| H-002 | **已验证** | 23824 个样本，信号组收阳率 **45.31%** vs 基准 **50.27%**，优势 **+4.96pp（z=-15.32）**，十分位**单调**（Q1 53.26% → Q10 46.55%）→ **主动买占比是有效的反向因子** |
| H-003 | 搁置 | 前提未出现（本地数据末根本就闭合） |

### ★ 本次最有价值的发现：统计显著 ≠ 能赚钱

H-002 方向预测**极度显著**，但按它做空下一根：
**含成本单笔 -0.1934%、胜率 14.93%** —— 双边手续费 0.20%，**赚的钱全被手续费吃掉**。

> 若只看胜率/显著性，台账会把这**一个亏钱因子标成「已验证」**。
> 所以每条假设现在必须多判一栏「**可交易性**」。

### ★ 第二个发现：粒度绝不能拍脑袋

台账原文写「**4H** 周期，主动买占比 > 0.65」——
15m 粒度有 **6907 个**样本，聚合成 4H **只剩 13 个**（求和把极端占比平滑掉了，阈值落进空集边缘）。
**写假设必须写清因子原生粒度，阈值要基于样本分布定。**

### 判定纪律（已写进技能与模板）

1. **执行失败 ≠ 已证伪** —— 首轮两条回测都 `KeyError` 挂了，笔数差恰好 0，被静默判成「证伪」
2. **前提未出现 = 搁置** —— 末根本就闭合，剔除与否没差别，不是证伪
3. **统计显著 ≠ 可交易** —— 必须看**含成本**收益
4. **认因子原生粒度** —— 聚合周期会让阈值落进空集
