# 清华《高级机器学习》16 周课程总览

> **课程真名**：《**高级机器学习**》（Advanced Machine Learning）
> **不是**"机器学习（大模型全链路）"——那是**内容描述**。对外说课名要说对。
> 授课：清华大学计算机系 唐杰 教授｜2026 年秋季学期，9 月 17 日开课｜16 周

## 一、这门课到底在教什么（一句话）

> 唐杰的判断：**"Chat 这一仗基本打完了，2026 年该干的是把智能往上推，让模型自己记忆、自己进化、自己完成长程任务。"**
> 所以课名还叫机器学习，但**16 周内容全部围绕大模型全链路重新设计**。

**不是**教你调 API、不是教你 prompt，是**让你把大模型的每一段亲手做一遍**。

## 二、课程主线（来自课堂 slide，已确认）

```
2026 年的四条主线
├─ ① 探索智能上界（AGI 最本质的事）
│    ├─ Scaling 已知：基座模型是关键（Coding / Agent / Physics）
│    └─ Scaling 未知：除 o 系列之外的新范式
├─ ② 技术创新
│    ├─ 全新模型架构（解决超长上下文、更高效的知识压缩）
│    ├─ 记忆机理（Memory）与持续学习（Continual Learning）
│    │    → 他的原话：这是"AI 超越人、实现超级智能的关键"
│    └─ 自主学习（AI Train AI）：自主迭代架构、自主合成数据、自主迭代优化
├─ ③ AI Agent（"工人"）
│    ├─ 完成更复杂的长时任务（Long Horizon Task, LHT）→ 形成一个 AI 工种
│    └─ 完全自治的 AI 系统（Autonomous Agent System, AAS）
├─ ④ AI Robotics（AI 进入物理世界）
└─ ⑤ AI4Science —— 可能是爆发年
```

## 四、五个作业（这门课的全部含金量）

| # | 作业 | 要求 | 练的是什么真本事 |
|---|---|---|---|
| **HW1** | 从零写 Tokenizer + Transformer，端到端训一个 **0.1B** 模型 | 不用现成框架的模型层 | 真正理解 attention/embedding 是怎么来的 |
| **HW2** | 从 raw dump **洗语料**，拟合 **scaling law** 再外推 | 数据工程 + 预测能力 | 会算"再给我 10 倍算力能到多少" |
| **HW3** | 手写 **Triton attention kernel**，自测多卡训练与推理增益 | GPU 编程 | 知道性能瓶颈在哪，不被框架黑盒骗 |
| **HW4** | 同一基座上做 **SFT / DPO / RLVR 对照** | 三种对齐路线横向比 | 能回答"我的场景该用哪种对齐" |
| **HW5** | 搭**可验证环境 + harness**，训**长程 Agent**，鼓励 **self-judge loop** | Agent 工程 | 长程任务的评测与自纠，最难的一环 |

**设计逻辑（slide 原话）**：*"Each lands right after its unit — the ladder rehearses the course in miniature."*
→ **每个作业都紧跟在对应知识单元之后，整条作业梯就是整门课的微缩版。**

## 六、这门课为什么值得学（对汤小龙的用法）

1. **它是一份"大模型工程师能力清单"**：五个作业 = 五个能力位（Tokenizer/Transformer、数据+scaling、kernel、对齐、Agent）。评估自己或招人时直接对照。
2. **它给了可验证的验收标准**：不是"学过"，是"能训出 0.1B 并拟合 scaling law 外推"。
3. **它是接单话术的底气**：客户问"你们懂大模型吗"，能说出"从零训过 0.1B、手写过 Triton kernel、做过 SFT/DPO/RLVR 对照"，比"我们用过 GPT"高一个量级。
4. **Final 的四问结构**可直接做交付文档骨架。

## 七、我们做不到的部分（如实说）

- **本机无独立显存** → 0.1B 从零训（约需 8-24GB 显存 + 数天）跑不动；Triton kernel 多卡测试无卡可测
- → 解法见 [[五大作业_家庭版可跑清单]]：**全部降级到 CPU/单卡/租卡三档**，能跑的跑，跑不了的给可验证的降级方案
