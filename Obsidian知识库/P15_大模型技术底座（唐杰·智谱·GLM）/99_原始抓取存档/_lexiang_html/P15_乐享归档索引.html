一、先纠三个最容易说错的事实

常见错误事实
「唐杰是院士」不是院士。他是 ACM / AAAI / IEEE 三 Fellow，清华计算机系教授、KEG 实验室、智谱创始人兼首席科学家、AMiner 之父。2026 胡润榜身家约 275 亿元。
「杨植麟、刘知远是唐杰的学生」错。二人师从孙茂松（同属 KEG 实验室）。唐杰直系可确认的是张鹏（智谱 CEO）。媒体把「KEG 一家人」当成了「唐杰的学生」。
「GLM-5 用 FP8 训练」不准确。论文正文：SFT 阶段用 INT4 QAT，FP8 只用于 RL rollout 推理；中文芯片上 Attention/MLP 用 W8A8，MoE 专家压到 W4A8。没有独立的「FP8 主训练」章节。

三、GLM-5 架构与训练的硬数字（arXiv 2602.15763 全文实读）

项GLM-5
总参数 / 激活744B / 40B（激活占比 5.4%；GLM-4.5 为 9.0%）
专家数 / 层数256 专家 / 80 层（刻意减层以压专家并行通信开销）
预训练28.5T tokens（Base 27T + mid-training 1.55T，早期重代码与推理）
上下文扩展三阶段：32K（1T）→ 128K（500B）→ 200K（50B）
注意力MLA + Muon Split（按头拆 up-projection 分别正交化）+ MLA-256（头维 192→256）
稀疏注意力DSA（DeepSeek Sparse Attention），top-k=2048，内容驱动而非固定窗口，长序列省 1.5~2×
DSA 接入继续预训练：稠密预热 1000 步（14×202,752 token，lr=5e-3）→ 稀疏适配 20B token
MTP3 层参数共享，接受长度 2.76（DeepSeek-V3.2 为 2.55），不加显存不加参数
量化SFT 阶段 INT4 QAT，kernel 与推理同源；原文：「ensures bitwise-identical behavior between training and inference」
后训练Reasoning RL → Agentic RL → General RL + On-Policy 跨阶段蒸馏防遗忘
RL 超参GRPO + IcePop，无 KL，β=2，ε=0.2/0.28，group=32，batch=32
RL 致命坑DSA 必须用确定性 torch.topk，且 RL 期间冻结 indexer，否则熵骤降崩溃
异步框架slime：Multi-Task Rollout Orchestrator 解耦训推，>1k 并发 rollout，TITO 网关，DP-aware routing
关键分数HLE 30.5（w/ tools 50.4）｜SWE-bench Verified 77.8｜Terminal-Bench 2.0 56.2/60.7｜CyberGym 43.2｜Vending-Bench 2 $4,432｜AA Intelligence Index 50（首个达 50 的开放权重模型）
读表要点：GLM-5 在开放权重模型里全面第一，但绝对分数仍落后 Claude Opus 4.5（SWE-bench 80.9）与 Gemini 3 Pro（GPQA 91.9）。真正的领先项是「开放权重」这个属性本身 + CyberGym（43.2 vs DeepSeek-V3.2 的 17.3，接近翻倍）。

四、清华《高级机器学习》16 周

课程真名《高级机器学习》，2026 秋 9/17 开课，16 周，评分 作业 40% + Final 60%（2–3 人组队，W6 提案 / W10 中报 / W16 报告 + 现场 demo，NeurIPS 格式英文）。

主线：数据 → 结构 → 规模 → 对齐 → 做事 → 证明。五个作业串起来就是一个完整的大模型研发闭环。

作业内容本机可跑性
HW1从零写 Tokenizer + Transformer，训 0.1B✅ 已用纯 numpy 跑通（缩到 0.064M）
HW2手写 Triton attention kernel，测多卡增益❌ 需 CUDA，本机无卡
HW3raw dump 洗语料，拟合 scaling law 外推✅ 已跑通
HW4同基座 SFT / DPO / RLVR 三路对照⚠️ 公式与小规模模拟可做
HW5可验证环境 harness 训长程 Agent + self-judge loop✅ 已跑通

三个已跑通的实测结果（不是"看代码觉得对"）

  • HW1：梯度检查 17/17 通过（rel_err ~1e-8）；loss 5.896 → 0.037；能生成正确中文词组。
  • HW3：用已知真参数生成数据再反推 —— α 真值 0.340 → 拟合 0.343，β 真值 0.280 → 拟合 0.271；留一外推误差仅 0.024。
  • HW5：两个 reward hacking 样本（return True / 测试名特判）全部被 judge 抓住。
三个实测挖出的真坑：① BPE 的 vocab_size 必须 > 256；② N 与 D 完全共线时 α、β 不可识别（拟合出的 tokens/param = 0 完全荒谬）；③ 我一个标记为 BUG 的空块除零，在 7 个测试里从未被触发——测试集有盲区，通过了不代表没问题。这就是「Benchmark 不等于体验」的最小复现案例。
