# 杨植麟 · Kimi 技术路线

> **谱系口径（必须说清）**：杨植麟出自清华计算机系 **KEG 知识工程实验室**，与唐杰同实验室体系；媒体普遍把他算作唐杰带出的学生（2026 胡润榜其身家 470 亿，报道原文："他的学生更猛，杨植麟 470 亿"）。
> ⚠️ 严格师承上，杨植麟的博士导师是**孙茂松**教授（同为 KEG）。→ **对外表述统一为"清华 KEG 出身、唐杰实验室体系"最稳妥**，说"唐杰嫡传弟子"会被较真的人挑错。

## 一、Kimi 的四代演进（一张表看完全部）

| 版本 | 时间 | arXiv | 总参/激活 | 上下文 | 关键突破 |
|---|---|---|---|---|---|
| **K2** | 2025-07 | 2507.20534 | ~1T / 32B | 256K | **MuonClip 优化器** + 线性注意力 MoE，奠基 |
| **K2.5** | 2026-01-27 | 2602.02276 | ~1T / 32B | 256K | 原生多模态 agentic；**Agent Swarm 支持 100 个 Agent 协同** |
| **K2.6** | 2026-04 | — | — | — | 多 Agent 编排能力打磨 |
| **K3** | 2026-07-27 | **2607.24653** | **2.8T / 104B** | **1M** | KDA（Kimi Delta Attention）+ AttnRes + Stable LatentMoE；权重全量开源 |

**K3 硬参数**：93 层（K2 约 61 层）；路由专家 **896 个**（K2 约 384），每 token 激活 **16 个** + 共享专家；scaling efficiency 相对 K2 提升 **约 2.5×**。

## 二、三大基础组件（杨植麟在 GTC 2026 系统定调）

### 组件一：MuonClip —— 换掉优化器
- **问题**：万亿参数训练最难的不是算力，是**训练会炸**。注意力 logits（QK 内积）在预训练中持续增长，一旦失控数值爆炸、整个训练崩
- **传统解法**：反复调超参、降学习率、回滚 checkpoint —— 又慢又贵
- **MuonClip 解法**：全新二阶优化器，**首次用于大模型训练**
- **他给的说法**：*"当前全球可用训练数据基本见底，这项技术能让 20T 训练数据跑出 40T 的训练效果，同等性能下训练成本、算力功耗直接减半。"*

### 组件二：线性注意力 —— 换掉注意力
- K2：线性注意力 MoE 架构
- K3：升级为 **Kimi Delta Attention（KDA）**，混合设计——**69 层 KDA + 24 层 Gated MLA**（周期性插 Gated MLA 保留全局交互）
- **解决的问题**：标准 softmax attention 的 KV cache 随序列长度线性增长，1M 上下文不可承受
- **他的说法**：*"行业存在 AI 摩尔定律，AI 可执行任务时长每 7 个月翻 1 倍；这套机制让上下文窗口扩大 10 倍，训练成本仅同步扩大 10 倍。"*
- 系统侧配套：FlashKDA、上下文并行、前缀缓存

### 组件三：Agent Swarm —— 换掉扩展范式
- K2.5：100 个 Agent 协同
- GTC 2026：扩展到 **300+ 并行**
- **本质**：把 test-time scaling 从"顺序推理"推进到"**并行 agent 协作**"
- 配套：事实校验员子 Agent 逐项校验报告与行业数据，压低幻觉

### 额外：Attention Residuals（AttnRes，2026-03 技术报告）
- 传统残差是逐层等权累加；AttnRes 让**深层有选择地回看更早层的表示**
- 治的是"标准残差把所有前序信息压进单一状态、沿深度传递形成类 RNN 瓶颈"
- 效果：2.8T 超大模型**能稳定训完**，推理效率同步 **+25%**

## 三、他的判断框架（比技术更值钱）

### 3.1 大模型演进三段论
```
阶段一（过去）：自然互联网数据 + 少量人工对齐
阶段二（2025） ：大规模强化学习 + 推理能力
阶段三（现在） ：AI 驱动研究 —— 每个研究员配备海量 Token，AI 辅助自动化研发
                 → "研究员 + AI 集群"成为新的生产力单位
```

### 3.2 Token 效率哲学
- 核心命题：**在有限资源下实现智能最大化**
- 三个抓手：**规模化策略下的 Token 效率、长上下文、Agent 集群**
- → 这条和唐杰的"架构自主 + 长程能力"是一脉相承的：**都在用工程效率换规模劣势**

### 3.3 开源 vs 闭源
> 黄震昕（月之暗面）公开表述，代表公司路线：*"二者并非对立竞争，而是企业客户差异化需求的产物。有私有化、微调需求的企业倾向开源，追求稳定托管的选择闭源。开源闭源与 Token 能力、输出质量没有必然绑定。"*
> *"Kimi 自 K2 起坚持开源路线，不会改变，核心底层技术、论文均对外公开。"*

### 3.4 幻觉观（很清醒的一句）
> *"幻觉无法彻底根除。幻觉本质是模型创造力的同源产物。"*
> → 解法不是"消灭幻觉"，是**用 Agent 架构做事后校验**。

## 四、对汤小龙（AI 分身）的用法

1. **技术选型素材**：客户要大上下文 → 讲 K3 的 1M + KDA 混合注意力（69 KDA + 24 Gated MLA）；客户要低成本 → 讲 MuonClip"20T 跑出 40T 效果"。
2. **方案设计原则**：**效率换规模**。我们没有 10 万卡，就学他们"用架构和工程把 1 块钱花出 2 块钱效果"的思路，而不是硬拼参数。
3. **Agent 产品设计**：Agent Swarm 的"并行 + 校验员子 Agent"结构，可直接套到我们的接单流水线（生成 → 校验 → 返修）。
4. **回答"开源还是闭源"**：用 3.3 那段，比站队更有说服力。
5. **不要说的话**：别说"杨植麟是唐杰嫡传弟子"（师承是孙茂松），说"清华 KEG 出身"。
