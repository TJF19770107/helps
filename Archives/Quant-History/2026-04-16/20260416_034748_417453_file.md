# HERMES Workflow

## 1. 双向同步主流程

1. 豆包将指令或规范内容推送到 Hermes。
2. Hermes 写入 `from_doubao` 消息队列。
3. Hermes 根据内容类型执行知识库检索、学习或回复生成。
4. 结果写入 `to_doubao` 队列，并在配置 webhook 时同步回推到外部通道。

## 2. 规范学习流程

1. 接收规范文件或规范链接。
2. 调用 `/hermes/learn` 或 `/hermes/learn/file`。
3. 提炼摘要、标题、标签并写
