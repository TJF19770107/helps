# HERMES Spec

## 1. 目标

- 固化 HERMES 的系统规范、接口边界、配置原则与同步约束。
- 为豆包 <-> Hermes 双向同步提供可回写、可检索、可追踪的规范基线。

## 2. 系统架构

- 主链路：用户 -> 豆包 -> Hermes -> 本地知识库 / LLM -> 豆包。
- 服务层：`核心程序/hermes_lobster_server.py` 提供 Flask API。
- 存储层：`核心程序/hermes_kb.py` 提供 SQLite 文档库与消息队列。
- 数据源层：`核心程序/hermes_sources.py` 负责网页/公众号等来源抓取。
- 推理层：`核心程序/hermes_llm.py` 负责本地与云端后端降级调度。

## 3. 配置原则

- 所有可变配置均通过环境变量注入。
