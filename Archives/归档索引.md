# 归档索引

---

## 按月份归档

### Quant-History 归档文件

```dataview
TABLE 
  length(rows) as "文件数",
  round(sum(rows.file.size) / 1024, 0) as "总大小(KB)"
FROM "Archives/Quant-History"
WHERE file.name != "归档索引"
GROUP BY regexreplace(file.folder, ".*/([0-9-]+)$", "$1") as "日期"
SORT "日期" DESC
```

---

## 归档报告索引

```dataview
TABLE 
  file.name as "报告名称",
  round(file.size / 1024, 1) as "大小(KB)",
  file.mtime as "归档时间"
FROM "Archives/Quant-Reports"
SORT file.mtime DESC
```
