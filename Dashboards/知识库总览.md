# 知识库总览

> 最后刷新: `= dateformat(date(now), "yyyy-MM-dd HH:mm")`

## 各领域知识统计

```dataview
TABLE length(rows) as "笔记数"
FROM "wiki"
GROUP BY split(file.folder, "/")[2] as "领域"
```

## 最近7天新增笔记

```dataview
TABLE file.ctime as "创建时间", file.folder as "目录"
FROM ""
WHERE file.cday >= date(today) - dur(7天)
SORT file.ctime DESC
LIMIT 20
```

## Raw层待处理

```dataview
TABLE source as "来源", date as "日期"
FROM "raw"
WHERE status = "raw"
SORT date DESC
```

## Wiki层知识网络

```dataview
TABLE length(file.outlinks) as "出链数", length(file.inlinks) as "入链数"
FROM "wiki"
WHERE length(file.outlinks) > 0
SORT length(file.inlinks) DESC
LIMIT 20
```
