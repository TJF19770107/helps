# 量化资产总览仪表盘

> 最后刷新: `= dateformat(date(now), "yyyy-MM-dd HH:mm")`

---

## 文件分类统计

```dataview
TABLE 
  length(rows) as "文件数",
  dateformat(max(rows.file.mtime), "yyyy-MM-dd HH:mm") as "最近更新"
FROM ""
WHERE category
GROUP BY category as "分类"
SORT "文件数" DESC
```

---

## 最近7天修改的文件

```dataview
LIST file.mtime
FROM ""
WHERE file.mtime >= date(today) - dur(7 days)
SORT file.mtime DESC
LIMIT 20
```

## 标签云 (按文件数)

```dataview
LIST file.tags
FROM ""
WHERE file.tags
FLATTEN file.tags
GROUP BY tags
SORT length(rows) DESC
LIMIT 15
```
