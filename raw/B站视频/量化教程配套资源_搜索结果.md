## 一、核心框架类仓库

### 1. VeighNa (vnpy) ⭐ 44,086
- **URL**: https://github.com/vnpy/vnpy
- **描述**: 基于Python的开源量化交易平台开发框架，国内最主流的量化平台
- **许可证**: MIT
- **技术栈**: Python 3.10+，事件驱动架构
- **核心模块**:
  - `vnpy.alpha` — AI量化策略模块（4.0新增），支持多因子ML策略开发
  - `vnpy.alpha.dataset` — 因子特征工程，内置Alpha 158因子集
  - `vnpy.alpha.model` — 预测模型训练（Lasso/LightGBM/MLP）
  - `vnpy.alpha.strategy` — 策略投研开发
  - Gateway层 — 支持CTP(期货)、XTP(证券)、IB(海外)等20+接口
- **适用场景**: 国内A股/期货/期权量化交易的完整解决方案
- **安装**:
  ```bash
  pip install vnpy
  # 或下载 VeighNa Studio 集成包
  ```

### 2. Howtrader ⭐ 943
- **URL**: https://github.com/51bitquant/howtrader
- **描述**: 基于VNPY的数字货币量化交易框架，支持TradingView信号集成
- **许可证**: MIT
- **交易所支持**: Binance(现货/USDT合约/币本位合约)、OKEx
- **核心特性**:
  - 使用`Decimal`替代`float`保证精度

- **安装**:
  ```bash

  conda activate mytrader
  pip install git+https://github.com/51bitquant/howtrader.git
  ```
- **适用场景**: 数字货币自动化交易，适合26集教程的AI交易机器人实操
