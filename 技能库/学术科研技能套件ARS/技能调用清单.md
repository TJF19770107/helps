## 三、零积分脚本速查

统一解释器：`G:\g_venv_ars\Scripts\python.exe`（已装 pyyaml / markdown / duckdb）

```bash
# 文献检索（arXiv / CrossRef / OpenAlex / Semantic Scholar，免费无需密钥）
python scripts/ars_lit_search.py --source all --q "关键词" --limit 20 --out refs.json --cache .cache

# SQL 实证分析（duckdb 主路径，失败自动降级 stdlib sqlite）

python scripts/ars_citation_check.py draft.md --verify --upstream
```

## 四、调用纪律（成本红线落地）

1. **先路由后加载**：每次只进一个子技能目录，禁 `Glob` 扫全 `ars/`
2. **免费先用**：检索必先跑脚本，WebSearch 仅作兜底且需报备
3. **结果落盘再回读**：大数据一律 `--out` 落 CSV/JSON，只回读摘要
4. **切换必报 / 付费须确认**：触及软禁大文件或付费模型，先请示汤哥
5. **回答必报**：交付时汇报加载文件数与 token 量级
