## 一、商业模式确认：汤哥的模式本身是合规的

汤哥描述的链路：

```
汤哥方交付辅助产物 → 交第三方/客户 → 第三方润色 → 客户本人成文、署名、投稿
```

**这条链路合规** ✅。关键合规点逐一对上：
- 正文由**客户本人**主导完成并署名 → 满足期刊「作者对内容负全责」
- 客户侧完成润色定稿 → 我方不是「代写成品」交付方
- 我方交付物 = 报告/数据/建议/结构稿 → 属「辅助服务」，不属「学术论文代写」
- 客户投稿时是否披露 AI 辅助 → 由客户决定并担责，我方在合同中尽到提醒义务即可

**要守住的一根线**：不交付「可直接提交的论文全文」。其余全部可以 commercialize。

## 二、「买博主的写论文技能」算不算授权？——判断树

买技能 = 买**那个技能包的使用权**，它**不等于**上游 ARS 的商用授权，也**不等于**「代写合法化」。算不算数，查三点：

| 查验点 | 通过标准 | 不通过的后果 |
|--------|----------|--------------|
| ① 底座来源 | 博主出示技能是自研（自有提示词/脚本），或底座是 MIT/Apache 宽松许可 | 若他套壳转卖别人的 NC 内容 → 你买到的是侵权链一环，随时被溯及 |
| ② 许可条款 | 明确写「可商用 / 可用于交付客户」 | 只写「个人学习使用」→ 商用即违约 |
| ③ 转售权限 | 若你想把他的技能打包进你的产品卖，需明确「可转售/可二次分发」 | 无转售权只能自用，不能进产品 |

**操作**：购买前直接问博主三句话——「底座是什么？许可条款发我看？能不能商用交付客户？」，聊天记录+购买凭证留档。¥几十到几百的技能包，问清楚再买，成本极低。

**对汤哥的启发（重点）**：别人能把「写论文技能」当商品卖，证明这条路**有人跑通了商业化**——卖的就是「提示词工程 + 流程封装」。这正是我们的四化路线：把 ARS 的**方法论思想**蒸馏过来，**表达层全部自研**，做出「龙虾科研辅助技能包」，版权就是自己的，随便商用。

## 三、自有版权技能包：四步自研路线（把"不行"变成"自己的资产"）

| 步骤 | 动作 | 产出 | 版权状态 |
|------|------|------|----------|
| S1 思想蒸馏 | 读 ARS 的流程/评分维度/模式设计，提炼**方法论**（思想不受版权保护） | 《科研辅助方法论笔记》 | ✅ 自由 |
| S2 表达自研 | 提示词、SKILL、脚本、模板**全部自己重写**，零复制原文 | 龙虾科研技能包 v1（可先基于现有 3 个自研脚本） | ✅ 自有版权 |
| S3 合规替换 | 上游引用处（上游 lint 脚本等）逐个自研替代或换宽松许可组件 | 无 NC 组件的纯自有包 | ✅ 可商用可转售 |
| S4 双轨并行 | 同时给上游作者发 Issue 询价双许可（备用路） | 授权谈判记录 | — |

**关键认知**：现在这套件里我们**自己的资产已经有三个脚本**（ars_lit_search / ars_sql_query / ars_citation_check 全部我方原创），缺的只是把 5 个子技能的「表达层」从引用上游 agent 文件改造成自研提示词。做完 S1-S3，NC 授权问题对自研包**不存在**——不需要任何人授权。

## 四、可卖什么：合规产品线 SKU（建议定价，随市场校准）

| SKU | 交付物 | 建议定价 | 合规点 |
|-----|--------|----------|--------|
| 文献检索报告 | 20-50 条真实文献 + 证据分级 + 文献矩阵（Excel） | ¥100-300/课题 | 报告类交付 ✅ |
| 引用校验报告 | 三层校验结果 + 逐条人工复核标记 | ¥50-150/篇 | 报告类 ✅ |
| 数据实跑分析 | SQL/统计脚本 + 结果 CSV + 复现说明 | ¥200-500/次 | 数据服务 ✅ |
| 论文结构诊断 | 大纲问题清单 + 章节重组建议 + 字数分配 | ¥100-200/篇 | 建议类 ✅ |
| 结构稿/骨架稿 | 含过渡句的详细骨架（客户自己填肉） | ¥300-600/篇 | ⚠ 骨架可以，成文不行 |
| 语言润色建议稿 | 标记式修改建议（非直接替换稿） | ¥80-150/千字 | 建议类 ✅ |
| 投稿包裹服务 | 选刊建议 + 格式排版 + AI 披露声明起草 + response letter 框架 | ¥200-400/次 | 流程服务 ✅ |
| ❌ 红线 SKU | 论文全文/整章代写、包过查重、伪造数据 | 不卖 | 学位法 + 期刊政策 |

**对外话术红线**：只说「科研效率辅助 / 文献与数据服务 / 写作辅导」，**永不承诺**「包写包过包发表」。话术即护城河——同行卖「代写」的迟早被处理，卖「辅助」的能长期做。

## 五、合同免责三条款（交付必附）

1. **用途限制**：交付物仅供客户学术研究参考，客户不得将交付物直接作为学位论文或署名投稿成果；由此产生的学术诚信责任由客户承担
2. **AI 披露提醒**：客户如使用 AI 辅助产出内容投稿，应遵循目标期刊/机构的披露要求
3. **核验义务**：文献与统计数据已尽技术核验义务，客户引用前应自行复核原文
