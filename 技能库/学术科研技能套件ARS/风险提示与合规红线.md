## 一、绝对禁止（P0，触碰即停用本套件）

### 1. 禁止学位论文完整代写
- **禁止**生成硕士/博士学位论文的全文、整章、或可拼装为完整章节的连续正文
- **禁止**代写课程论文、作业、毕业设计报告的完整交付稿
- **允许**：大纲建议、结构诊断、逻辑梳理、语言润色建议、写作方法指导
- 判据：若产出物可被直接提交并构成「作者本人的学术成果」，即为越界

### 2. 禁止编造任何学术要素
| 要素 | 禁止行为 |
|------|----------|
| 文献 | 凭记忆或推测生成作者、标题、年份、期刊、卷期页、DOI |
| 数据 | 生成未实际采集/计算的样本量、均值、标准差、相关系数 |
| 统计 | 生成未真实运行的 p 值、t/F/χ² 值、效应量、置信区间 |
| 引文 | 生成「支持某论断」但未核实的引用 |
| 实验 | 声称做了未做的补充实验、访谈、问卷 |

### 3. 禁止用于商业交付的未授权使用
上游许可为 **CC BY-NC 4.0（非商用）**。若本套件产出用于对外收费接单，须另行取得上游授权或改走自有实现。

## 二、AI 幻觉的三类高危场景与本套件对策

| 风险 | 典型表现 | 强制对策 |
|------|----------|----------|
| **幻觉文献** | 模型生成看似规范、实际不存在的论文（含假 DOI） | 定稿前必跑 `ars_citation_check.py --verify`；`✗ 未命中` 条目**逐条人工打开原文确认** |
| **幻觉数据** | 模型「估算」出统计结果 | 论文中每个数字必须能在脚本输出中定位；只引用 `ars_sql_query.py` 实际产出的值 |
| **幻觉引用关系** | 把某结论挂到不支持它的文献上 | 每条论断与文献的对应关系由人工复核，抽查比例 ≥20% |

### 脚本不是万能的（务必知悉）
- `ars_citation_check.py` 为**粗粒度字符串匹配**，存在漏判与误判
- L3 存在性层依赖 CrossRef / OpenAlex 收录情况：**未命中 ≠ 造假**，可能是中文文献、预印本、题名截断，但**保留前必须人工确认**
- 任何校验脚本的输出都不能替代作者的逐条核实责任

## 三、人工核验清单（定稿前逐项打勾）

### 文献类
- [ ] 每条参考文献的标题、作者、年份与原文一致
- [ ] DOI 可真实解析
- [ ] 正文引用 ↔ 参考文献表**双向**一一对应
- [ ] 抽查 ≥20% 条目已人工打开原文/数据库确认

### 数据类
- [ ] 论文中每个统计量都能在脚本输出或原始数据中定位
- [ ] 样本量口径、缺失值/异常值处理规则已由作者确认并记录
- [ ] 显著性检验为真实运行所得，非模型估算
- [ ] 随机种子、数据版本、脚本路径已记录，保证可复现

### 论述类
- [ ] 结论不超出已核验文献与真实数据的支持范围
- [ ] 未出现「AI 作为作者」的实质性代笔
- [ ] 已按目标期刊/学校要求完成 AI 使用披露（AI disclosure）

## 四、学术诚信与披露

1. **作者责任不可转移**：AI 是工具，作者对所有内容的真实性、准确性、原创性负全责
2. **AI 使用披露**：多数期刊（Elsevier / Springer / Wiley / IEEE）与高校已要求声明 AI 辅助写作情况，**必须如实披露**
3. **署名**：AI 不具备作者资格，不得列为作者（COSE / ICMJE 明确立场）
4. **相似性与查重**：AI 生成内容同样会被查重系统检出，不得假定「AI 写的检不出」

---

## 五、数据与隐私红线

- 涉及**人类受试者**的数据，须先通过 IRB/伦理审查（参考 `experiment-agent/references/irb_ethics_checklist.md`）
- 含个人身份信息（PII）、医疗、未公开商业数据，**禁止**上传至任何外部 API
- 本套件脚本仅向公开学术 API 发送**题名/关键词字符串**，不上传原始数据集
- 未发表数据、在审稿件内容，禁止通过联网检索途径外传

## 六、使用边界速查

| 场景 | 允许 | 禁止 |
|------|------|------|
| 文献查找 | 检索真实文献并人工核验 | 凭空编造参考文献 |
| 大纲 | 章节结构与字数分配建议 | 学位论文整章/全文 |
| 数据分析 | 本地脚本实跑并复现 | 模型估算统计量 |
| 审稿回复 | 回应结构与措辞、修改计划 | 虚构「已补充实验」 |
| 语言 | 润色建议、语法改进 | 改变实质结论的改写 |
| 引用 | 格式校对与存在性核对 | 自动生成未核实引文 |

## 七、违规处置

发现以下任一情形，**立即停用本套件并回溯已交付内容**：
1. 出现过编造文献/数据并已进入稿件
2. 被用于学位论文代写
3. 未做人工核验即交付客户或投稿
