## 一、商用授权到底找谁？

**CC BY-NC 4.0 的「NC」= 非商用。要商用，唯一合法路径 = 找版权人单独要一份商用许可。**

| 项 | 内容 |
|----|------|
| 版权人 | ARS 上游作者（GitHub 账号 **Imbad0202**，sponsor 页署名 crucify020v） |
| 渠道 1 | GitHub 仓库开 Issue：https://github.com/Imbad0202/academic-research-skills |
| 渠道 2 | Buy Me a Coffee 页面私信（README 官方赞助入口）：https://buymeacoffee.com/crucify020v |
| ⚠ 注意 | **CC 组织（Creative Commons）本身不授权任何作品**，它只提供许可协议模板。找 CC 没用 |
| 要谈什么 | 双许可（dual licensing）：你付费用换一份商用授权书，写明允许在收费接单中使用、是否要求衍生品继续开源 |
| 备选路线 A | **思想借鉴自研**：版权法保护「表达」不保护「思想/方法/流程」。流程思路可以学，但提示词、脚本、文档必须全部自己写，不复制原文 |
| 备选路线 B | 换 **MIT / Apache-2.0** 许可的开源科研技能做底座（商用免费，只需保留版权声明），避免逐家谈授权 |

> 谈判话术要点：说明使用规模（个人接单、非转售）、请求 commercial license quote、询问 educational discount。

## 二、「把很多开源的融合在一起就变成我的原创」——❌ 不成立，必须纠正

这是**法律上错误的认知**，直接说结论：

1. **许可跟着内容走，不跟仓库走**。把 10 个 CC BY-NC 项目混进一个包，这个包对外的许可仍是 **CC BY-NC（非商用）**，署名义务还在，NC 限制还在。融合得越多，欠的署名链越长。
2. **多个许可混合可能互相冲突**（如 ShareAlike 要求衍生品同许可，与商用目标直接矛盾），结果可能一个都不能商用。
3. 「去除署名 / 改头换面当原创」= **侵权 + 学术不端双重风险**，被上游作者发现可下架索赔，商单客户若被追责会连累信誉。
4. ✅ **合法变成「自己的」只有两条路**：
   - **思想层借鉴**：方法论、流程、评分维度、触发逻辑——这些是「思想」，不受版权保护；**表达层（提示词原文、代码、文档）必须自己重写**；
   - **只融合宽松许可组件**：MIT/Apache/BSD 的技能可以合法合并（保留版权声明），混入一个 NC 组件，整包就被 NC 污染。

> 一句话：**融合开源 ≠ 原创，只等于「合规义务的合并」**。

## 三、这套技能写出的论文，能不能真的发表 / 当毕业论文？

**直说：AI 生成的正文直接投稿或提交，不行；辅助科研全流程，可以。**

### 期刊发表（真实政策，非猜测）
| 事实 | 出处 |
|------|------|
| Elsevier / Springer Nature / IEEE / Wiley 均允许 AI 辅助写作，但**必须在使用处披露** | 各出版社作者指南（AI authorship policies） |
| **AI 不能署名作者**——COPE/ICMJE 标准：作者须对内容担责、能回应审稿，AI 做不到 | COPE 立场声明 |
| 纯 AI 代写被查出 → 拒稿 / 撤稿，并通报所在机构 | 各期刊 ethcis 条款 |
| 人类作者对**全部内容（含 AI 生成部分）的真实性负全责** | 同上 |

### 毕业论文
- 《中华人民共和国学位法》2025-01-01 施行：**代写学位论文、剽窃、伪造数据**属学术不端，可**不授予或撤销学位**
- 多所高校已在盲审环节启用 **AIGC 检测**（检测不过直接打回）
- 结论：学位论文的**正文必须本人撰写**。AI 只能做：查文献、跑数据、改格式、提大纲意见、语言润色建议

### 本套件的安全用途边界（结论表）
| 用途 | 能否商用交付 | 能否用于毕业论文 |
|------|-------------|-----------------|
| 文献检索 + 真实性核验 | ✅（注意 NC：套件本体不直接交付给客户） | ✅ |
| 数据实跑 + 统计（ars_sql_query） | ✅ | ✅ |
| 大纲建议 / 结构诊断 | ✅ | ✅ |
| 引用校验 / 格式校对 | ✅ | ✅ |
| **AI 生成正文交给客户/学校** | ❌ | ❌（学位法风险） |
| AI 生成的英文润色稿直接投刊 | ⚠ 须披露，且作者逐句核定 | ❌ |

> 商单场景的正确姿势：**交付「辅助服务」（检索报告、数据分析、校验报告、辅导），不交付「代写成品」**。这既规避 NC 授权问题，也规避学术不端连带责任。
