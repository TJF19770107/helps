# 企业 AI 陪跑 · 四行判定表

> 用途：客户**签续约前**，或被问「这钱花得值不值」时，四行答完再说。
> 单页，不讨价还价。**答不全，续约就先别签。**

| # | 四个问题 | 答 | 判据 |
|---|---|---|---|
| 1 | **资产现在在谁的账号里？** | | 在客户自己账号/底座 = ✅<br>在服务商后台 = ❌ **那是租用，不是陪跑** |
| 2 | **交付物是一个跑完的周期，还是一份文档？** | | 走过一个完整业务周期（真单进→真单出）= ✅<br>只有方案/PPT/流程图 = ❌ |
| 3 | **九十天里，有没有第二个人独立重跑过？** | | 有，且不求助 = ✅<br>只有交付方跑过 = ❌ |
| 4 | **陪跑的人走了，新来的人照文档能不能接住？** | | 能 = ✅<br>不能 = ❌ |

**四行全 ✅ → 可以续；任何一行 ❌ → 先补，再谈钱。**

---

## 反面案例（必须讲给客户听）

> 一家公司服务商交付得很漂亮，**二十多个智能体全在对方空间里**。
> 合同到期停付，账号一停，东西全没了。
> **那不叫陪跑，那叫租用。**

## 三样交付物（缺一不算交付）

| # | 交付物 | 验收标准（很土但有效） |
|---|---|---|
| 1 | **一条跑通过的流程** | 换个人照文档走一遍能不能走通。用的必须是客户**现在正在跑**的表单/审批/字段，不是样板 |
| 2 | **一套写着客户公司名字的资产** | 技能、规则、知识库条目、模板。关键不在数量，在**归属** |
| 3 | **一张算得清的账** | 见下 |

### 第三样：那张账最少三个数

| 指标 | 项目开始前（基线） | 第 90 天 | 变化 |
|---|---|---|---|
| 端到端时长 | | | |
| 一次通过率 | | | |
| 返工次数 | | | |

> **量不出来，说明这条流程还没被真正改过，只是被演示过。**

## 合同附件模板（直接抄）

```
交付物清单：
  ① 一条流程：________（写明起止：从____单进来，到____单出去）
     验收人：________（是使用这条流程的那个岗位，不是项目负责人）
  ② 一套资产：存放在________（客户方账号/底座名称）
     验收人：________
  ③ 一张账：三个指标基线已量（有记录），第 90 天复测
     验收人：________

验收方式：第 30 / 60 / 90 天各一次「重跑验收」
          —— 由未参与项目的人员照文档独立跑一遍，全程不求助。
验收人未签字的项，不计入交付完成。
```

> 🔴 **验收人必须是「用这条流程的那个岗位」，不是项目负责人。**
> 项目负责人验收自己的项目 = 自证清白。

## 一盆冷水（写在最显眼处）

**陪跑最容易退化成「代做」。**
人来了，干得又快又好，你在旁边看着很满意。三个月后他走了，你的团队还是不会。

> Wilson Learning 九项对比研究：只鼓励经理辅导 +10%；教会辅导方法 +18%；
> **既会辅导、又懂被辅导那门业务 +41%（单项最高 55%）**。
> → **陪你的人得懂你的业务，光懂工具不够。**
