# 企业AI落地诊断与陪跑交付

## 这个技能解决什么

中小企业老板问「我们 AI 怎么起步」时，90% 的人会答「先做个 POC」「先买套系统」「先培训一下」。
**这三种答法全都错**，因为它们都不产出可验收的东西。本技能给的是**能签字、能对数、能验收**的一套。

核心信念（一句话）：
> **表格能证明你想过，系统才能证明你做到了。**

---

## 一、诊断：三级门槛漏斗（先定位卡在哪一关）

97.4% 听过 → 53.2% 试过 → 33% 持续用 → **6% 做成标准化流程**。
每级台阶都在大量掉人。**先判断客户卡在哪一级，再给对应解法。**

| 门槛 | 表象 | 真实病灶 | 解法 |
|---|---|---|---|
| **① 不知道从哪开始** | 「AI 好像都能干，但我们不知道用在哪」 | 目标太笼统，不可计数 | 画出三条线，选**最痛的那一条**（不是最容易展示的那条） |
| **② 没人负责** | 员工偷偷用（影子 AI 65.1%），没人批准也没规则 | 缺「旗手」 | 点一个旗手，给三样东西（见下） |
| **③ 没等到出数就被砍** | 上线一个月很热闹，第三个月没人提 | 时间预期错了 | **30 天看数 / 90 天看流程 / 一年看岗位** |

**三条门槛的共同解**：把含糊的大目标，拆成**一个能被观察、能被计数的环节**。

### 选环节的两个筛子

优先选同时满足三条的环节：
1. **最费人**（每月耗掉最多人工小时）
2. **最重复**（同一动作每天/每周重复）
3. **最容易出错**（出错成本可量化）

> ⚠️ 关键判断：**算清这一环值多少钱再下手**。算不清就换环节。

---

## 二、定人：一个旗手 + 一个外部帮手

**不要招 AI 工程师。** 六十人规模的企业，负责推广 AI 的往往是一个同样迷茫的普通员工。

### 旗手三个硬条件（缺一条就会烂在他手里）
- 有一个**说得清**的场景
- 拿得到这个环节的**真实数据**
- 每周有**固定时间**

### 给旗手的三样东西（是资源不是头衔）
- 明确的时间
- 能拍板的权限
- 每月一次向管理层汇报的**固定会议**

> 数据支撑：从低成本陪跑式咨询起步的公司，成功率约是直接上系统开发的 **3 倍**。

---

## 三、签字：四签名 + 三道刹车 + 三层标签

**这是本技能最值钱的交付物。一张 A3 就够，半小时填完。**

### 四签名（一个智能体一行）

| 行 | 问题 | 谁签 | 必须写清什么 |
|---|---|---|---|
| 1 | **谁批准它上线** | 业务部门负责人（不是 IT） | 读哪些数据、能调哪些工具、一天能花多少钱 |
| 2 | **谁为结果负责** | 平台→IT / 模型→供应商 / 流程结果→业务主管 | 别设「AI 负责人」一个人管三十条流程 |
| 3 | **谁能按下停止** | 值班人 | **必须写人名 + 电话**，不能写「必要时可暂停」 |
| 4 | **谁对外开口** | 一人 + 一备份 | 两人都能开口 = 两人都不用负责 |

**加一列：多久复核一次。建议 90 天**（模型/数据/权限都会变，签名不会自己跟着变）。

### 三道刹车（必须变成能勾的配置项）
- **目标不可自定**
- **权限不可自增**
- **额度不可自扩**
→ 落成：工具白名单 / 金额上限 / 越权审批 / 一键停止开关（写进值班表，**测试一次，确认真停得下来**）

### 三层标签（出事 30 秒定位，只写「AI 客服」要花三天）
1. **产品身份**：哪款模型、哪个版本
2. **运行时身份**：跑在哪台机器、调了什么工具、谁触发的
3. **责任主体**：哪个部门、哪个岗位

### 责任三问（法务口径，来自公安部一所于锐）
身份三层之上再问六件事：**谁控制 / 谁所有 / 谁获利 / 谁有过错 / 谁能制止 / 谁能追溯**。
> 这六问**没有一条在问模型聪不聪明，全在问人有没有安排。**

### 认知底线（必须对客户讲明）
- 最高法 2026-09《关于依法审理涉人工智能纠纷案件的意见》：**不能以「内容由 AI 生成」为由免责**。法律不认这个被告，它找不到机器就一定找到人。
- 智能体造成的损失，**保险赔钱，赔不了「该由谁去交代」**。

## 四、陪跑：三样交付物 + 四行判定表

### 陪跑卖的不是人天，是三样东西（缺一不算交付）

| # | 交付物 | 验收标准（很土但有效） |
|---|---|---|
| 1 | **一条跑通过的流程** | 完整走过一个周期：真实单子进来 → 真实单子出去。用的是客户**现在正在跑的那套**表单/审批/字段，不是样板。**换个人照文档走一遍，能不能走通** |
| 2 | **一套写着客户公司名字的资产** | 技能、规则、知识库条目、模板。关键不在数量，在**归属**——必须建在客户自己的账号和底座里，不在服务商后台 |
| 3 | **一张算得清的账** | 最少三个数：**端到端时长 / 一次通过率 / 返工次数**。开始前量一次，第 90 天再量一次 |

> 🔴 反面案例：服务商交付得很漂亮，二十多个智能体全在**对方空间**里；合同到期停付、账号一停、东西全没。那不叫陪跑，叫**租用**。

### 陪跑排期：九十天，不是九十小时

改一条流程，时间不由课时决定，**由「下一次真实业务什么时候发生」决定**。

- 建议：**六周一个周期，每周一次（90 分钟）**，跨过一个完整业务月
- 理由：要跑过**标准件 / 非标件 / 急单**三种情形，各至少碰到一次，资产才敢说打磨过
- 场地：**工位，不是会议室**。围着本周正在跑的那一单讲，讲完当场改一处，改完立刻用真单子试

### 四行判定表（客户续约前必答，答不全就先别签）

```
第 1 行：资产现在在谁的账号里？
第 2 行：交付物是一个跑完的周期，还是一份文档？
第 3 行：九十天里，有没有第二个人独立重跑过？
第 4 行：陪跑的人走了，新来的人照文档能不能接住？
```

### 一盆冷水：陪跑最容易退化成「代做」

**你干得又快又好，三个月后你走了，客户团队还是不会。**
> Wilson Learning 九项研究综述：只鼓励经理辅导 +10%；教会辅导方法 +18%；**既会辅导又懂被辅导那门业务 +41%（最高 55%）**。
> 翻译：**陪你的人得懂你的业务，光懂工具不够。** 这也是通用讲师讲得再热闹也跑不通你那条流程的原因。

## 五、交付节奏（可直接照抄给客户）

| 时间 | 动作 | 产出 |
|---|---|---|
| 第 1 个月 | 选一个环节，把今天的做法和数据整理出来 | 三条线 + 选中那条的现状基线（**几乎不花钱，但决定后面能不能走**） |
| 第 2 个月 | 旗手用手上工具跑出第一批结果 | 哪怕只有十份报价、二十张工单 |
| 第 3 个月 | 对一次数 | 省了多少小时 / 少了几次返工 / 错了几次 |
| 决策 | 数字好 → 加**第二个环节**；不好 → 换**环节**，**不换人** | — |

**第 30 / 60 / 90 天各做一次「重跑验收」**：让没参与项目的人照文档独立跑一遍，全程不求助。
第一次跑不通正常；**第二次还跑不通，说明资产根本没留下**。

## 六、进阶模型（客户规模大/要方案书时用）

### ORA-KA：权责锚定 + 知识资产化
- **ORA 锚定引擎**：用刚性制度锁定责任归属（四签名是它的最小实现）
- **KA 价值引擎**：用可量化算法激活知识资产
- **三分区**：确权区（绿，负责人确认，责任归岗位）/ 探索区（黄，AI 推理未确认，**附免责声明**）/ 禁区
- **AVS 计酬公式**：`AVS = Σ(Ci × Wi × Qk)`
  - `Ci` 有效调用量（需 UV 过滤 + 反作弊）
  - `Wi` 业务权重（行政类 0.2 / 核心风控类 2.0）
  - `Qk` 质量调节因子（满意度反馈）
- **反作弊四道**：UV 权重衰减 / 跨部门校验系数 / 异常频次熔断 / 纠错负激励（啄木鸟机制）
- **资产退出**：知识半衰期设置 + 强制折旧；所有权明确为职务作品；分红余晖期 3–6 个月

### 胜利模型 V 字闭环（To B 产品/商业模式设计）
```
平权平价（用 AI 把贵服务做成普惠 → 开增量市场）
   ↓
精准匹配（从海量普惠用户中揪出愿多花钱的人 → 抓高价值）
   ↓
超额利润（利润反哺 AI 迭代 → 门槛再降 → 循环）
```
> 判据：**降本增效是从自己口袋抠钱，越做越卷；平权平价是从新市场赚钱，越做越宽。**

## 七、写作/汇报模板（本技能附带）

要把这套说给人听，用这个四段式（原文作者的原型）：

```
① 一个真实老板提问（3 行内出现具体人 + 具体数字）
② 第一笔账 / 第二笔账（每条数据带 机构名 + 年份 + 样本量）
③ 认知转折 → 一句话金句 → 一张能打印的表
④ 「一盆冷水」段（主动写局限）→ 工具/落地路径 → 后续动作
```

**三条硬规矩**：
- 数据**必须**带机构 + 年份 + 样本量，否则删掉
- 必须有**一句独立成行的金句**（短句、无主语、可截图）
- 必须有**「一盆冷水」段**——主动承认边界，比通篇夸自己更有转化

## 八、使用顺序（别搞反）

```
诊断三级门槛 → 定旗手 → 填四签名 → 排 90 天 → 三重跑验收 → 对账
```

**顺序错了会怎样**：先谈工具/预算 → 停在「不知道从哪开始」；
先教工具不给旗手 → 影子 AI；先上图不给签名 → 出事没人认。

> **先定底座，再谈陪跑。底座建在个人账号上，陪跑交付得越多，你被锁得越深。**
