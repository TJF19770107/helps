## 二、双链路传导体系

### 2.1 国内宏观传导链路（A股）

```
CPI/PPI → 通胀预期 → 货币政策松紧 → 利率走廊 → 市场流动性 → 估值中枢
PMI → 经济景气度 → 企业盈利预期 → 业绩驱动/估值驱动切换
LPR → 信贷成本 → 房地产/消费/投资 → 相关行业盈利
汇率(USD/CNY) → 出口竞争力 → 出口链/进口替代 → 行业景气分化
社融/M2 → 信用扩张力度 → 风险资产水位 → 整体仓位基准
```

### 2.2 国际宏观传导链路（双市场）

```
美联储利率决议 → 全球流动性 → 美元强弱 → 新兴市场估值 → A股北向/加密资金
非农就业 → 美国经济韧性 → 降息预期修正 → 美债收益率 → 全球risk-on/off
DXY美元指数 → 大宗商品定价 → 资源股/黄金/加密 → 定价中枢漂移
美债收益率曲线 → 全球无风险利率 → 股权风险溢价 → 成长/价值风格切换
VIX恐慌指数 → 全球风险偏好 → 仓位上限约束 → 杠杆倍数调整
```

## 三、宏观→仓位决策矩阵

| 宏观信号组合 | A股仓位建议 | 加密仓位建议 | 核心逻辑 |
|-------------|-----------|------------|---------|
| 国内松 + 国际松 | 80-90% | 70-80% | 全球流动性共振，risk-on最大化 |
| 国内松 + 国际紧 | 60-70% | 30-40% | 内松托底，外紧压制高风险资产 |
| 国内紧 + 国际松 | 50-60% | 50-60% | 外松提供外部性，内紧限制上限 |
| 国内紧 + 国际紧 | 30-40% | 10-20% | 全球紧缩共振，防御为主 |
| 政策空窗期 | 50-60% | 40-50% | 无明确方向，中性仓位等待信号 |

**执行规则**：
- 上述仓位为基准，叠加 `trading-risk-radar` 风险评分折减（每10分风险降10%仓位）
- 叠加 `position-sizing-engine` 信号强度系数（S级×1.0、A级×0.8、B级×0.6）
- 最终仓位 = 基准仓位 × 风险折减系数 × 信号强度系数

## 四、重大数据发布日三阶段操盘策略

### 4.1 发布前1日（预期管理）

| 数据 | 超预期利多 | 符合预期 | 超预期利空 |
|------|----------|---------|----------|
| 美国CPI | 降息加速→加密/纳指↑ | 按兵不动 | 通胀顽固→美元↑风险资产↓ |
| 美国非农 | 经济韧性→软着陆→美股↑ | 中性 | 衰退恐慌→降息急→美元↓ |
| 中国CPI | 通缩缓解→消费复苏→A股↑ | 中性 | 通缩加深→内需疲弱→防守 |
| 中国PMI | 景气回升→周期股↑ | 中性 | 荣枯线下→经济承压→观望 |
| 美联储决议 | 鸽派→全球risk-on | 中性 | 鹰派→美元↑全球↓ |

**操作**：
1. 查看 `neodata-westock-dual-query` 获取市场预期值（共识）
2. 评估自身持仓与数据方向的敏感度
3. 高敏感方向提前减仓（降低数据日波动伤害）

### 4.2 发布当日（事件交易）

**黄金时段**：
- 美国数据：20:30-21:00（北京时间）
- 中国数据：9:30-10:00（A股开盘前后）

**操作纪律**：
- 数据发布前30分钟：禁止新开仓（已有仓位保留）
- 数据发布后15分钟：观察市场第一反应，不追第一波
- 数据发布后1小时：根据方向确认度决定加仓/减仓
- 若数据方向与预期完全相反：优先止损，不赌反转

### 4.3 发布后1日（趋势确认）

- 确认价格是否突破关键位（日线前高/前低、缠论中枢）
- 检查 `daily-market-dashboard` 中宏观日历是否移除该事件
- 评估是否需要调整下一日仓位基准

## 七、宏观叙事→板块自动匹配引擎

### 7.1 当前叙事识别（输入）

用户输入当前宏观环境描述（如"美联储降息预期升温、国内CPI回暖、人民币升值"），本技能自动解析出：

1. **国际叙事**：降息周期 / 紧缩周期 / 软着陆 / 衰退恐慌
2. **国内叙事**：复苏确认 / 通缩担忧 / 政策发力 / 内生增长
3. **汇率叙事**：升值通道 / 贬值压力 / 双向波动

### 7.2 叙事→板块匹配（输出）

```
国际叙事 = 降息周期 + 国内叙事 = 复苏确认 + 汇率叙事 = 升值通道
↓ 自动匹配 ↓
超配：科技成长（流动性宽松+盈利回升+汇率升值提升估值）
     可选消费（复苏确认+购买力提升）
     航空造纸（升值直接受益）
低配：银行（降息压缩息差）
     出口链（升值削弱竞争力）
     高股息（risk-on环境下吸引力下降）
```

### 7.3 使用示例

```
用户：当前宏观环境是美联储暂停加息、国内PMI重回扩张、人民币贬值到7.3，怎么配板块？

本技能输出：
1. 国际叙事：紧缩暂停（非降息，中性偏松）
2. 国内叙事：复苏确认（PMI>50，景气回升）
3. 汇率叙事：贬值压力（7.3关口，出口受益）

匹配结果：
- 超配：周期股（复苏+贬值→出口竞争力提升）
        资源股（贬值→进口成本上升→国产替代）
        金融（复苏→资产质量改善）
- 低配：航空造纸（贬值受损）
        进口消费（购买力下降）
        纯美元负债企业（偿债压力↑）
```

## 九、使用步骤

1. **每日晨前**：触发"宏观分析"，扫描当日/次日重大数据发布日历
2. **数据发布前1日**：触发对应数据名称（如"CPI"），执行三阶段策略之"预期管理"
3. **数据发布当日**：观察市场反应，15分钟内不操作，1小时后根据方向确认度决策
4. **板块轮动困惑时**：触发"板块轮动"，输入当前宏观环境描述，获取自动匹配结果
5. **政策节点**：触发"政策周期"，查看近期政策节点与措辞变化影响
