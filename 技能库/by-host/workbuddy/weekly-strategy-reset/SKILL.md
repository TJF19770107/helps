# 每周策略复盘与重置 · v2.0

> **定位**：每周一次的策略全面体检，从数据→执行→规则→规划四层穿透，确保交易系统持续进化。不只是"看看这周赚了亏了"，而是"这周我的系统哪里需要修"。
> **核心理念**：策略不是一成不变的——每周重置，保持系统锐度。

---

## 〇、何时启用本技能

- 用户说"做周度复盘"、"每周策略"、"策略重置"、"weekly reset"
- 周末/周一例行复盘
- 周三说"周三检查"、"半周复盘"、"周中检查"
- 月底/季末说"月度汇总"、"季度白皮书"
- 需要调优信号/仓位/风控参数
- 上周留下的行动项需要追踪闭环

## 六、使用示例

### 示例1：标准周度复盘

```
用户：做一下这周的复盘

→ 依次执行：
1. 调用 trading-journal-ai 获取本周交易记录
2. 调用 trading-risk-radar 获取本周风险趋势
3. 汇总模块一（数据快照+宏观+信号统计）
4. 逐笔复盘+策略规则审查+错误分析（模块二）
5. 技能使用审计 + 健康度快照（模块三）
6. 参数调优建议 + 下周计划 + 行动项追踪（模块四）
7. 个人状态检查（模块五）
8. 综合评分 + 五级评级
9. 输出完整策略周报
```

### 示例2：周三快速中转

```
用户：周三检查一下这周情况

→ 执行周三快速中转：
1. 30秒快速扫描（盈亏+仓位+熔断+宏观）
2. 1分钟偏差检查（执行率+纪律+超仓+追单）
3. 1.5分钟快速调整建议
4. 后本周2日策略展望

输出精简版周中报告（<500字）
```

### 示例3：月度汇总

```
用户：这个月整体怎么样？

→ 汇总最近4周周报：
1. 四周数据聚合表
2. 趋势分析（盈亏/胜率/纪律）
3. 月度策略评估（最佳/最差策略）
4. 行动项闭环

输出月度策略汇总报告
```

### 示例4：季度白皮书

```
用户：季度结束了，做个季度白皮书

→ 执行季度策略白皮书：
1. 季度核心数据（收益/回撤/夏普/胜率）
2. 5个核心问题大方向校准
3. 策略参数调整决策
4. 下季度目标设定

输出季度策略白皮书
```

## 七、参数说明

## 九、限制与边界

- 本技能为**复盘框架**，实际数据需从联动Skill汇聚，不直接产生市场数据
- S/A/B/C/D评级为**自评参考**，不代表未来收益保证
- 参数调优建议需人工验证后执行，避免过度拟合
- 季度白皮书涉及策略大方向调整，建议结合盘感综合判断
- 周三检查为快速扫瞄，深度问题留待周末完整复盘
