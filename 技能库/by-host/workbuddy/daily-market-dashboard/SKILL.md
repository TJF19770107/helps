# 大道量化每日操盘决策仪表盘 · v3.2

> **定位**：每日操盘的**中枢入口**，串联信号→数据→仓位→风控→日志→宏观→周策→成本约束全部9个核心技能。  
> **设计理念**：三段闭环（晨前→盘中→收盘），每段3-5分钟完成，不过度分析，聚焦可执行决策；**成本控制置顶**下自动选择最小必要数据查询集。

---

## 〇、何时启用本技能

- 用户说"今日大盘怎么样"、"今天怎么操作"、"盘前分析"、"收盘复盘"
- 每个交易日自然触发（盘前08:30 / 盘中11:30 / 收盘15:30 三段）
- 其他技能（信号/风控/仓位）需要大盘背景时反向调用
- **新增**：用户说"控制成本查大盘"、"便宜点看行情"、"最小数据做决策"

## 〇-A、成本控制感知模式（V3.2新增）

### 为什么需要成本感知

- 每日行情数据查询可能产生多次工具调用与积分消耗
- 不同场景对数据精细度要求不同：盘前需要较全数据，盘中告警只需关键字段
- `cost_mode=true` 时，本技能自动选择**最小必要数据集合**，优先用本地缓存/已下载数据，避免重复查询

### 三档成本模式

| 模式 | 触发条件 | 数据策略 | 估算工具调用 |
|------|---------|---------|------------|
| `cost_mode=strict` | 用户显式要求省积分 | 仅查1个核心指数+持仓标的+风险等级 | ≤3次 |
| `cost_mode=normal` | 默认 | 查大盘+板块+持仓+信号+宏观日历 | 5-8次 |
| `cost_mode=full` | 用户要求完整分析 | 全量数据+多数据源交叉验证 | 8-15次 |

### 最小必要数据集（cost_mode=strict）

| 数据项 | 来源 | 说明 |
|--------|------|------|
| 上证/深证收盘/实时 | neodata-westock-dual-query | 1次调用 |
| 持仓标的最新价 | neodata-westock-dual-query | 与大盘合并查询 |
| 今日宏观风险等级 | macro-market-linkage | 本地日历缓存优先 |
| 综合风控评分 | trading-risk-radar | 仅当分数跨阈值时更新 |

### 与 zero-cost-task-execution 协同

- 调用前询问：`本次查询采用 strict/normal/full？`
- 优先复用上一次查询结果（时效<15分钟）
- 收盘复盘时批量汇总，避免盘中多次小查询

## 二、模块零：盘前风控雷达（V3.1）

> **V3.1核心升级**：在原有宏观日历三色预警基础上，新增与 trading-risk-radar 的盘前联动。

### 0.1 宏观日历三色风险预警

| 风险等级 | 触发条件 | 操盘策略 |
|---------|---------|---------|
| 🔴 高风险 | 美联储利率决议、非农数据、CPI/PPI发布日 | **暂停开新仓**，仅管理已有仓位 |
| 🟡 中风险 | PMI、零售数据、失业金申请、重要财报季 | 减半仓位，收紧止损至1% |
| 🟢 普通 | 无重大数据发布 | 正常执行信号 |

**数据来源**：联动 macro-market-linkage V2.0 获取当日宏观日历。

### 0.2 盘前风控雷达联动（V3.1）

**执行步骤**：
1. 调用 trading-risk-radar V2.0 执行"一键全维度体检"（2min五维扫描）
2. 获取五维风险评分：市场风险(30%) + 仓位风险(25%) + 纪律风险(20%) + 流动性风险(15%) + 黑天鹅风险(10%)
3. 根据综合评分调整当日操盘策略：

| 综合风险评分 | 等级 | 策略调整 |
|------------|------|---------|
| 0-30 | 🟢 安全 | 正常执行信号，仓位100% |
| 31-50 | 🟡 谨慎 | 仓位折减至70%，止损收紧至1.5% |
| 51-70 | 🟠 警戒 | 仓位折减至50%，仅做A级信号 |
| 71-100 | 🔴 危险 | **仅平仓不开仓**，等待风险释放 |

### 0.3 盘前风控决策矩阵

```
宏观风险等级 × 风控评分 → 最终策略

         风控评分 0-30  31-50  51-70  71-100
宏观🟢      正常      谨慎    警戒    仅平仓
宏观🟡      谨慎      警戒    警戒    仅平仓
宏观🔴      警戒      仅平仓  仅平仓  仅平仓

→ 取两者较高等级作为当日操盘基线
```

## 三、第一段：晨前扫盘（08:30-09:15）

### Step 0：成本模式选择（V3.2新增，5秒）

- 默认 `cost_mode=normal`
- 若用户说"省点"、"简单查"、"只看大盘" → `cost_mode=strict`
- 若用户说"详细"、"全量"、"对比" → `cost_mode=full`

### Step 1：宏观环境速览（2min，strict模式下可合并至1min）

- 联动 macro-market-linkage 获取：
  - 昨夜美股收盘涨跌幅（道琼斯/纳斯达克/标普500）
  - 美元指数(DXY)变动、美债10Y收益率
  - 今日宏观日历风险等级（🔴/🟡/🟢）
  - 人民币汇率(CNY/USD)变动
- **strict模式**：仅保留"今日宏观风险等级"一项

### Step 2：盘前风控体检（2min，strict模式下可跳过）

- 执行模块零（V3.1盘前风控雷达联动）
- 确定当日操盘基线策略
- **strict模式**：仅当风险等级跨阈值时重新调用 trading-risk-radar

### Step 3：A股盘前扫描（3min，strict模式1min）

- 联动 neodata-westock-dual-query 获取：
  - 昨日涨停板数量、连板高度
  - 今日新股申购
  - 北向资金昨日净流入/流出
  - 主要指数技术位（上证/深证/创业板）
- 联动 a-stock-black-horse-signal：
  - 检查昨日信号跟踪标的盘前表现
  - 扫描今日候选标的（四要素预筛）
- **strict模式**：仅查"上证/深证实时+持仓标的"

### Step 4：加密市场扫描（2min，strict模式下可选/跳过）

- 联动 crypto-quant-signal：
  - BTC/ETH 4H级别缠论结构
  - 多周期共振信号强度（日线/4H/1H）
  - 全民狂热指标（恐贪指数、资金费率）
- **strict模式**：仅在用户持仓加密时查询

## 四、第二段：实盘监控（11:30 或盘中触发）

### 触发条件
- 定时触发：11:30（午间）、14:00（尾盘前）
- 事件触发：持仓标的大幅波动（±3%）、涨停/跌停、突发新闻

### 监控清单

| 维度 | 检查项 | 数据来源 |
|------|--------|---------|
| 持仓 | 盈亏比、止损距离、浮盈回撤 | neodata实时行情 |
| 信号 | 新触发的买入/卖出信号 | a-stock/crypto信号 |
| 大盘 | 指数分时走势、涨跌家数比 | neodata |
| 资金 | 北向资金实时流向、主力净流入 | neodata |
| 板块 | 板块涨幅排名、轮动阶段 | a-stock-signal |

### 盘中告警规则

| 事件 | 告警级别 | 建议动作 |
|------|---------|---------|
| 持仓跌破止损位 | 🔴即时 | 立即执行止损 |
| 持仓浮盈回撤>3% | 🟡5min | 评估是否移动止盈 |
| 大盘急跌>2% | 🟡5min | 检查持仓相关性 |
- 新信号触发 | 🟢15min | 评估是否纳入 |
| 板块加速见顶信号 | 🟡5min | 检查持仓板块暴露 |

### 成本感知盘中规则（V3.2新增）

- **盘中告警触发时**：先查持仓标的，再查大盘，最后才查板块/资金
- **15分钟非紧急新信号**：延迟到收盘复盘批量处理
- **重复告警去重**：同一标的10分钟内不重复查询

## 五、第三段：收盘复盘（15:30-16:00）

### Step 1：数据汇总（2min）
- A股收盘：上证/深证/创业板涨跌幅、成交额、涨跌家数
- 加密收盘：BTC/ETH日K收盘价、成交量
- 持仓表现：当日盈亏、持仓标的涨跌

### Step 2：信号回顾（2min）
- 今日触发的信号列表（正确/错误）
- 信号执行情况（执行了/错过了/犹豫了）
- 信号质量评分（A级/B级/C级）

### Step 3：操作评估（2min）
- 计划执行率 = 实际执行操作 / 计划操作 × 100%
- 纪律执行评分（10分制）：
  - 止损执行（是/否）：±2分
  - 仓位遵守（是/否）：±2分
  - 信号执行（是/否）：±2分
  - 情绪控制（是/否）：±2分
  - 记录完整（是/否）：±2分
- **新增**：成本控制执行评分（±2分）：是否使用了不必要的数据查询

### Step 4：明日预判（2min）
- 大盘技术面预判（上涨/盘整/下跌概率）
- 重点关注的标的/板块
- 明日计划操作清单
- **新增**：明日建议查询模式（strict/normal/full）

### Step 5：自动联动日志（V3.0）
- 调用 trading-journal-ai V2.0
- 一次描述完成：
  1. 复盘记录（Step 1-4 的数据）
  2. 日志记录（交易明细 + 纪律评分）
  3. 纪律执行质量评分（10分制）
  4. 错误模式识别（E001-E007）
  5. 操盘规则库更新（如发现新规则）
  6. **新增**：成本控制执行回顾（是否超预算查询）

## 九、限制与边界

- 本技能是**决策框架**，不直接产生交易信号（信号由 a-stock/crypto-signal 产生）
- 大盘情绪评分为**辅助参考**，不作为唯一决策依据
- 盘前风控雷达依赖 trading-risk-radar 的五维评分，如该技能不可用则降级为仅使用宏观日历
- 加密市场24小时运行，"收盘"概念不适用，建议每日固定时间（如UTC+8 16:00）做日度复盘
- **成本感知模式不降低决策质量**：strict模式仅减少非必要数据查询，核心风控与信号执行逻辑不变
