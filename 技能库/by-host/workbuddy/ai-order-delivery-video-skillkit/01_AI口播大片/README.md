# 01 · AI 口播大片（接入槽位）

## 一句话
真动态 AI 角色口播，运镜 + 表情 + 配音，对标 Seedance / 即梦 / 可灵同档。

## 候选接入路径（按代价与质量排）
1. **WorkBuddy VideoGen**——一键，最快。代价：50–100 积分/5 秒。
2. **即梦月付 ¥69**——量产性价比之王，无限 10s/条。
3. **Atlas Cloud Seedance API**——按单付费 $0.022/秒，120 秒 ≈ ¥19。
4. **可灵 / 海螺 / Vidu**——各有免费额度 + 付费档。

## 接入标准动作
1. 选定一条路，跑通 1 条 ≥ 30 秒样片（含真动态人像/角色 + 真音轨）
2. 把脚本/样片/资产放进本目录
3. 在 SKILL.md 把 01 改成「✅ 已跑通」，加上成本/触发词
