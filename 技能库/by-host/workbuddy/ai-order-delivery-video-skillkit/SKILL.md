## 2. 已跑通的 00_零成本口播片（默认入口）

> **能覆盖 70% 的企业接单群需求**——培训、盘点、产品介绍、营销矩阵、PPT 风科普。一律 0 积分 / 0 API / 5–10 分钟出片。

**配方**：
```
edge-tts（微软免费 TTS，zh-CN-XiaoxiaoNeural 女声）
  + Pillow（深蓝科技风：垂直渐变 + 粒子光点 + 头像光环 + 字幕条）
  + FFmpeg（zoompan 慢推 + aac 立体声 + +faststart + -shortest 防掐音轨）
  = 任意 5 秒 ~ 60 秒 1920×1080 视频，0 积分、可接单
```

**实测三条样片**（均在 `00_零成本口播片/资产\` 里）：

| 样片 | 时长 | 风格 | 复用切入点 |
|------|------|------|-----------|
| `agent_video_20260826_AI分身首片_有声强封.mp4` | 7.36s | 单段自我介绍 | 改 `make.py` 顶部 `TEXT` |
| `agent_video_enterprise_sample_有声强封.mp4` | 66.88s | 8 段企业培训 | 改 `make_enterprise.py` 顶部 `SEG` |
| `agent_video_koubo_sample3_20260826_有声强封.mp4` | 26.67s | 8 段产品发布会 | 改 `make_koubo_sample3.py` 顶部 `SEGMENTS/TITLE` |

**3 个万能改点**（90% 的活就这三处）：
1. `TEXT` / `SEGMENTS` / `SEG` —— 改文案
2. `TITLE` / `SUB` —— 改主题
3. `TOTAL` / `per` —— 改总时长（写到 60s 上 0 成本拉到任意时长，120s/300s 都行）
