# 03 · 数字人实拍（接入槽位）

## 一句话
真人形象出镜，克隆本人（汤哥）口播，复刻语气/表情。

## 接入路径
1. **HeyGen**——海外，¥/月，支持中文；录 1 分钟样本出 10s 起步。
2. **D-ID**——海外，API 可接；按秒计费。
3. **硅语 / 闪剪 / 蝉镜**——国产，便宜但风格偏电商。

## 接入标准动作
1. 录汤哥 1 分钟口播样本（也可走克隆本人之外的虚拟人）
2. 选定 SaaS 厂商并跑通 1 条样片
3. 把脚本/样本/样片落本目录
