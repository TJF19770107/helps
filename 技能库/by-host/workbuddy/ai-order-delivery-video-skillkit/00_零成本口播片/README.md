# 00 · 零成本口播片（已跑通）

## 一句话
edge-tts（微软免费）+ Pillow + FFmpeg = 任意 5–300 秒 1080P 立体声短视频，0 积分、0 API。

## 资产
- `make.py` —— 单段短片样片脚本
- `make_enterprise.py` —— 8 段企业培训样片
- `make_koubo_sample3.py` —— 8 段产品发布会样片（最新版）
- 三个 `..._有声强封.mp4` 成品
- 两个 waveform 证明音轨满能量

## 改片方法（3 步必会）
1. 打开任意 `make_*.py`，找顶部 `SEGMENTS` / `TEXT` / `TITLE` —— 改文案
2. 改 `TOTAL` / `per` —— 改时长（5s / 30s / 60s / 120s 都行）
3. `python make_xxx.py` —— 出新片

## 触发话术
- "出 30 秒 XX产品 介绍片"
- "出 1 分钟 XX主题 企业培训片"
- "出接单发布会 1 分钟片 主题 XX"

## 已覆盖企业单品类
