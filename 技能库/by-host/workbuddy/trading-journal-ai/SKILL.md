# AI交易日志与自我进化系统 V2.0

> **定位**：交易行为的"黑匣子"记录器 + 纪律执行"CT扫描仪" + 持续进化"引擎"
> **核心价值**：让每一笔交易都有迹可循、每一个错误都被编号、每一次进化都有数据支撑
> **哲学**：不记录的交易等于没做，不复盘的记录等于白记

---

## 一、触发条件

| 触发词 | 场景 |
|--------|------|
| 交易日志 / 操盘记录 | 每日收盘后记录当日交易 |
| 纪律评分 / 交易复盘 | 评估当日纪律执行质量 |
| 错误分析 / 错误识别 | 检查是否触发七大错误模式 |
| 规则库 / 操盘规则 | 查看/更新个人操盘规则 |
| 进化报告 / 周交易总结 | 生成周度交易进化报告 |
| 月交易总结 / 月度复盘 | 生成月度交易进化报告 |
| 超仓检查 / 仓位回顾 | 对比计划仓位 vs 实际仓位 |

## 二、每日交易记录6模块标准格式

### 模块1：基本信息

```markdown
## 交易日志 - YYYY-MM-DD

- **日期**：YYYY-MM-DD
- **市场**：A股 / 加密货币 / 双市场
- **当日大盘**：上证指数 XXXX点（+/-X%）/ BTC $XXXXX（+/-X%）
- **当日情绪**：0-10分（0=极度恐慌，10=极度贪婪）
- **持仓数量**：X只（A股）+ Y个（加密）
- **当日盈亏**：+/- X元（+/- X%）
```

### 模块2：交易明细

```markdown
### 交易明细

| 时间 | 标的 | 方向 | 数量 | 价格 | 理由 | 信号来源 |
|------|------|------|------|------|------|---------|
| 09:35 | 600XXX | 买入 | 1000股 | 15.20 | 缠论三买确认 | a-stock-black-horse-signal |
| 14:20 | BTC | 卖出 | 0.5个 | 68500 | 多周期顶背离 | crypto-quant-signal |

**备注**：任何计划外交易、情绪化交易、冲动交易在此详细说明原因
```

### 模块3：计划执行对比

```markdown
### 计划 vs 实际执行

| 计划项 | 计划内容 | 实际执行 | 偏差说明 | 是否违规 |
|--------|---------|---------|---------|---------|
| 标的范围 | 只买缠论三买+黑马四要素≥80分 | 600XXX（85分） | 无偏差 | ✅合规 |
| 仓位上限 | 单标的不超过总仓位15% | 买入12% | 无偏差 | ✅合规 |
| 止损纪律 | 跌破-5%无条件止损 | 未触发 | 无操作 | ✅合规 |
| 止盈纪律 | 浮盈+20%减半仓 | 未到目标 | 未操作 | ✅合规 |
| 交易时段 | 只开盘前30分钟和收盘前30分钟 | 09:35买入 | 时段内 | ✅合规 |
| 空仓要求 | 风险评分>80时空仓 | 风险评分65 | 无空仓 | ✅合规 |
```

### 模块4：情绪与状态记录

```markdown
### 情绪与状态

- **昨夜睡眠**：X小时（<6=差 / 6-7=一般 / >7=好）
- **开盘前情绪**：平静/焦虑/兴奋/犹豫（圈选）
- **盘中最大浮盈**：+X元（时间点：XX:XX）
- **盘中最大浮亏**：-X元（时间点：XX:XX）
- **是否有FOMO**：是/否（若有，详细描述触发场景）
- **是否有报复性交易**：是/否（若有，详细描述）
- **身体状态**：正常/疲劳/生病（影响决策质量）
```

### 模块5：纪律执行评分

```markdown
### 纪律执行评分（10分制）

| 评分项 | 权重 | 自评分 | 说明 |
|--------|------|--------|------|
| 计划遵循度 | 20% | X/10 | 是否按盘前计划执行，有无计划外交易 |
| 止损执行 | 20% | X/10 | 触发止损时是否果断执行，有无犹豫/扩大止损 |
| 止盈执行 | 15% | X/10 | 是否按止盈规则执行，有无贪婪/过早止盈 |
| 仓位控制 | 20% | X/10 | 是否按仓位管理规则，有无超仓/满仓/梭哈 |
| 情绪管理 | 15% | X/10 | 有无情绪化交易、FOMO、报复性交易 |
| 记录完整 | 10% | X/10 | 本日志是否当日完成、记录是否详尽 |
| **总分** | **100%** | **X/10** | **当日综合纪律评级** |

**评级**：S(9-10) / A(8-8.9) / B(7-7.9) / C(6-6.9) / D(<6)
```

## 三、七大错误模式识别引擎（E001-E007）

### E001 止损钝化

- **症状**：触发止损线后犹豫、找借口、修改止损位、希望回本
- **识别**：实际亏损 > 计划止损亏损，且亏损幅度持续扩大
- **根因**：损失厌恶心理、沉没成本谬误、不愿承认错误
- **处方**：
  1. 触发止损 → 3秒内必须下单（机械执行）
  2. 止损后强制冷却30分钟（禁止任何新操作）
  3. 当日纪律评分中"止损执行"项直接判0分

### E002 盈利变亏损

- **症状**：浮盈XX%未止盈，最终亏损离场
- **识别**：交易记录中"最大浮盈"为正但"最终盈亏"为负
- **根因**：贪婪、缺乏止盈纪律、希望"再多涨一点"
- **处方**：
  1. 浮盈达+15%必须设置移动止盈（回撤50%利润即出）
  2. 任何浮盈超过+20%的持仓，每日检查是否触发移动止盈
  3. 连续3次盈利变亏损 → 强制降低仓位至50%（一周）

### E003 超仓/梭哈

- **症状**：单标的仓位超过15%或总仓位超过上限
- **识别**：实际仓位 > 计划仓位（由position-sizing-engine输出）
- **根因**：FOMO、"这次不一样"、报复性加仓、自信膨胀
- **处方**：
  1. 任何买入前必须先查position-sizing-engine输出
  2. 超仓触发 → 当日纪律评分"仓位控制"判0分
  3. 连续2次超仓 → 下一交易日只允许50%仓位操作

### E004 计划外交易

- **症状**：盘前无计划、盘中临时起意买入、冲动交易
- **识别**：交易明细中"理由"栏填写模糊或"感觉会涨""看别人买了"
- **根因**：情绪驱动、信息过载、社交影响、无聊
- **处方**：
  1. 任何交易必须在盘前计划中有明确记录（除信号突变外）
  2. 计划外交易 → 当日纪律评分"计划遵循度"扣至5分以下
  3. 连续3次计划外交易 → 强制次日空仓（反思日）

### E005 逆势加仓

- **症状**：持仓下跌后不断加仓摊低成本，最终越套越深
- **识别**：同一标的多次买入，且后续买入价低于前次，总持仓亏损扩大
- **根因**：摊平成本谬误、不愿认输、错误信仰"终会涨回来"
- **处方**：
  1. 禁止任何形式的"补仓摊平"（除非符合新信号且独立仓位管理）
  2. 任何加仓必须满足：新信号独立成立 + 新止损位独立设置
  3. 逆势加仓 → 触发E001（止损钝化）双重处罚

### E006 过度交易

- **症状**：交易频率过高，手续费侵蚀利润，决策质量下降
- **识别**：单日交易次数>5次（A股）或周交易次数>10次（加密）
- **根因**：交易成瘾、追求刺激、把交易当娱乐、缺乏耐心
- **处方**：
  1. 设定交易频率上限（A股日≤3次，加密日≤2次）
  2. 超过上限 → 当日纪律评分"情绪管理"扣至5分以下
  3. 周交易次数超上限 → 下周强制降低频率至50%

### E007 空仓焦虑

- **症状**：市场大涨时空仓焦虑、忍不住追涨、空仓即亏损感
- **识别**：空仓状态下进行非计划交易、追买已大幅上涨的标的
- **根因**：错失恐惧(FOMO)、把空仓当错误、缺乏等待的耐心
- **处方**：
  1. 空仓是合法状态（不是错误，是风控的正确选择）
  2. 空仓日纪律评分中"计划遵循度"满分（遵守了空仓规则）
  3. 空仓时若出现FOMO → 记录触发场景，作为下次免疫训练素材

## 四、操盘规则库（15条核心规则，持续迭代）

### 基础规则（不可违背）

1. **止损铁律**：单笔亏损不超过总资金2%，触发后3秒内执行
2. **仓位铁律**：单标的不超过总资金15%，总仓位不超过宏观基准±20%
3. **计划铁律**：任何交易必须在盘前计划中有明确记录（信号+价位+仓位+止损）
4. **空仓铁律**：风险评分>80或情绪评分<4时，必须空仓或≤30%仓位
5. **记录铁律**：当日交易必须当日记录，延迟记录视为当日纪律评分-2分

### 进阶规则（提升质量）

6. **信号规则**：只交易S/A级信号，B级信号需减半仓位，C/D级信号禁止交易
7. **时段规则**：A股只操作开盘前30分钟和收盘前30分钟，加密只操作4H/日线信号
8. **分散规则**：同板块持仓不超过总仓位30%，避免单一风险集中
9. **冷却规则**：单笔止损后冷却30分钟，单日两次止损后停止当日交易
10. **止盈规则**：浮盈+20%减半仓，+30%清仓或设移动止盈，禁止"再看看"

### 心理规则（控制人性）

11. **睡眠规则**：睡眠不足6小时禁止开盘前交易，疲劳状态下只减仓不加仓
12. **FOMO规则**：感到"不买就错过"时，强制等待15分钟后再决策（90%会消失）
13. **盈利规则**：连续3日盈利后第4日降低仓位至70%（防止过度自信）
14. **亏损规则**：连续3日亏损后第4日只允许50%仓位（防止报复性交易）
15. **社交规则**：不因群聊/大V/新闻而临时交易，所有信息必须经过自身信号系统过滤

## 五、仓位执行回顾模块（V2.0新增）

### 5.1 计划仓位 vs 实际仓位对比

```markdown
### 仓位执行回顾

| 标的 | 计划仓位 | 实际仓位 | 偏差 | 偏差原因 | 是否超仓 |
|------|---------|---------|------|---------|---------|
| 600XXX | 12% | 15% | +3% | 买入时追加 | ⚠️是 |
| BTC | 8% | 8% | 0% | 无 | ✅否 |
| 总仓位 | 60% | 75% | +15% | 多标的同时超仓 | 🔴严重超仓 |
```

### 5.2 超仓行为识别

- **轻度超仓（+5%以内）**：黄色警告，记录原因，下次注意
- **中度超仓（+5%~+15%）**：橙色警告，当日纪律评分-3分，次日强制降仓
- **严重超仓（+15%以上）**：红色警告，当日纪律评分-5分，次日只允许50%仓位

### 5.3 与 position-sizing-engine 联动

```
position-sizing-engine 输出：
  今日建议仓位 = 60%（基准）× 0.9（风险折减）× 0.8（A级信号）= 43.2% ≈ 43%

实际仓位：75%
偏差：+32%（严重超仓！）

触发动作：
  1. 本技能记录超仓事件
  2. trading-risk-radar 纪律风险评分+20分
  3. 次日开盘前强制减仓至43%（无论盈亏）
```

## 八、使用步骤

1. **每日收盘后**：触发"交易日志"，填写6模块标准格式（15-20分钟）
2. **填写过程中**：自动触发"错误识别"，检查是否触发E001-E007
3. **填写完成后**：自动计算"纪律评分"，输出当日评级
4. **每周日**：触发"周交易总结"，生成周进化报告
5. **每月最后一个交易日**：触发"月交易总结"，生成月度进化报告
6. **任何时候**：触发"超仓检查"，查看计划vs实际仓位对比
