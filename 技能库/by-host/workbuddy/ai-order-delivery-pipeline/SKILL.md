# AI接单交付执行流水线 V1.0

> 定位：企业微信群定制接单项目的「执行中枢」。衔接 lobster-auto-bid（报价）→ 本技能（生成+QC+交付）→ wecom-robot-rpa（回传客户）。
> 核心原则：**成本优先置顶** — 先算积分预算，再选生成路径，能零成本不花积分。
> 1234映射：仓颉(结构化交付) × 五步法(成本优先置顶) × 全域模板(交付协议) × 赛博书屋(案例沉淀)

## 二、五步法·交付流水线

### Step1 意图识别（炼精化气）
从订单任务卡提取 7 要素：
1. **品类**：实拍照片 / AI绘画 / 短视频 / 文案 / 设计图 / 印章 / 海报
2. **数量**：几张 / 几版 / 几秒
3. **规格**：尺寸 / 分辨率 / 双面 / 可印刷
4. **风格要求**：写实 / 卡通 / 国风 / 极简（影响 prompt 构建）
5. **交期**：急单（≤1天）/ 常规（≤3天）/ 宽松（>3天）
6. **预算上限**：来自 lobster-auto-bid 报价单的利润红线
7. **交付格式**：源文件 / 预览图 / 压缩包

### Step2 能力映射（炼气化神）
**品类→生成路径路由表**：

| 品类 | 首选路径 | 积分成本 | 降级路径 | 积分成本 |
|------|---------|---------|---------|---------|
| 实拍照片（人像/产品） | **ImageGen** | ~5积分/张 | 无（不可降级） | - |
| AI绘画/插画 | **ImageGen** | ~5积分/张 | Pillow本地生成 | 0 |
| 短视频（60s内） | **VideoGen** | 50-100积分 | **zero-cost-video-render** | 0 |
| 文案 | 本地LLM/模板 | 0 | - | - |
| 设计图/印章 | ImageGen + 后处理 | ~5积分 | Pillow + FFmpeg | 0 |
| 海报（含文案） | ImageGen + 叠字 | ~5积分 | Pillow纯本地 | 0 |

> **关键纠正（2026-08-22实测验证）**：
> - 实拍照片生成**不需要 picset Trust 连接器**，WorkBuddy 内置 ImageGen 即可
> - picset Trust 仅用于电商场景的批量商品图，非通用AI出图渠道
> - VideoGen 路径需用户确认积分消耗（50-100积分/条）

### Step3 方案规划（炼神还虚）
**成本决策树**：
```
订单到手
  ↓
积分预算 = 报价单利润空间 × 30%（执行成本上限）
  ↓
预算 ≥ 首选路径成本？
  ├─ 是 → 走首选路径（ImageGen/VideoGen）
  ├─ 否但可降级 → 走降级路径（Pillow/zero-cost-video-render）
  └─ 否且不可降级（如实拍照片）→ 向用户申请追加积分
  ↓
预估交付时间 ≤ 交期？
  ├─ 是 → 执行
  └─ 否 → 急单系数1.5×加价（回传lobster-auto-bid重新报价）
```

### Step4 自主执行（炼虚合道）
**按品类执行**：

#### 4.1 实拍照片/AI绘画（ImageGen路径）
```
1. 构建 prompt（品类+风格+规格+数量）
2. 调用 ImageGen 工具生成
3. QC质检（见 Step4-QC）
4. 保存到订单目录：G:/龙虾AI主控中心/我的AI分身/企业微信群定制接单项目/{客户}_{需求}_{日期}/output/
5. 生成预览缩略图
```

**Prompt构建模板**：
```
[品类]：{实拍照片/AI插画/产品图}
[主体]：{客户需求描述}
[风格]：{写实/卡通/国风/极简}
[规格]：{尺寸} {分辨率} {背景}
[数量]：{N}张，角度/表情/构图变化
[负面]：变形/模糊/水印/低质量
```

#### 4.2 短视频（VideoGen路径，需用户确认积分）
```
1. 用户确认积分消耗（50-100积分/条）
2. 构建 prompt（场景+时长+风格+音效）
3. 调用 VideoGen 工具生成
4. QC质检（分辨率≥1080p / 时长±5s / 无水印）
5. 保存到订单目录 output/ 子文件夹
```

#### 4.3 短视频（零成本降级路径）
```
→ 联动 zero-cost-video-render 技能
→ edge-tts(旁白) + Pillow(静态帧) + FFmpeg(合成)
→ 0积分，5-10分钟出片
→ 适用：科普/行业向短视频（不适用真人出镜）
```

#### 4.4 文案/设计（本地路径）
```
→ 纯本地执行，0积分
→ 模板填充 + 仓颉蒸馏 + 龙虾五步法
→ 保存为 .md/.docx
```

### Step4-QC 质检清单（通用）
| 检查项 | 标准 | 不通过处理 |
|--------|------|-----------|
| 分辨率 | ≥客户要求 | 重新生成或超分放大 |
| 比例/尺寸 | 与订单一致 | 裁剪/补边 |
| 水印 | 无第三方水印 | 裁剪或重新生成 |
| 主体完整性 | 无变形/截断 | 重新生成（prompt调整） |
| 文字可读性（海报类） | 清晰无重叠 | 叠字后处理修正 |
| 文件大小 | 1-10MB（交付适用） | 压缩或超分 |

### Step5 反思进化（炼虚合道→闭环）
- 交付完成 → 记录实际积分消耗 vs 预算
- 客户满意 → 案例归档到赛博书屋/乐享（prompt模板+生成参数+成本）
- 客户退稿 → 记录退稿原因 → 回灌 prompt 模板优化
- 成本超支 → 回传 lobster-auto-bid 校准成本基准表

## 六、关键纠正记录（2026-08-22实测）

### picset Trust 误区纠正
- **错误认知**：实拍照片/数字人视频需要 picset Trust 连接器
- **正确事实**：WorkBuddy 内置 ImageGen/VideoGen 即可直接生成
- **picset Trust 真实用途**：电商批量商品图（多角度/多场景），非通用AI出图
- **影响范围**：lobster-auto-bid 报价不涉及picset成本；本技能不依赖picset
- **验证依据**：2026-08-22 生成亚洲女性实拍模特照1.39MB，~5积分，无需picset

### 待验证项
- [ ] VideoGen 真AI视频测试（50-100积分，需用户确认）
- [ ] wecom-cli 850003 企微自动抓取重扫（需用户扫码授权）

## 七、参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `cost_budget_ratio` | float | 0.3 | 执行成本占报价比例上限 |
| `auto_fallback` | bool | true | 积分不足时自动走降级路径 |
| `qc_strict` | bool | true | 严格质检（不通过自动重试） |
| `max_retry` | int | 2 | 生成失败最大重试次数 |
| `video_confirm_required` | bool | true | 视频生成需用户确认积分 |
| `output_dir` | string | 订单目录/output/ | 交付物保存路径 |

## 八、使用步骤

### 8.1 完整接单流程（从报价到交付）
```
1. wecom-robot-rpa 接收企微订单 → 生成 task_card.md
2. lobster-auto-bid 读取 task_card → 输出 quote.json
3. 用户确认报价 → 触发本技能
4. 本技能读取 task_card + quote → 路由生成路径
5. 执行生成 → QC质检 → 打包到 output/
6. 成本追踪 → 回传 lobster-auto-bid 校准
7. wecom-robot-rpa 回传交付物给客户
```

### 8.2 单独触发（跳过报价）
```
用户：「这个单子怎么做 / 出图交付」
→ 读取订单目录 task_card.md
→ 直接进入 Step2 路由
→ 执行生成+QC+打包
```

### 8.3 紧急降级
```
用户：「零积分出图 / 零成本交付」
→ 跳过 ImageGen/VideoGen
→ 直接走 Pillow/zero-cost-video-render 降级路径
→ 牺牲质量换零成本
```

## 九、错误处理

| 错误模式 | 检测 | 兜底 |
|----------|------|------|
| ImageGen 返回低质量图 | QC质检不通过 | 调整prompt重试（≤max_retry次） |
| VideoGen 积分不足 | 预算检查 | 自动降级到 zero-cost-video-render |
| 生成超时（>5分钟） | 计时器 | 终止并改用降级路径 |
| 订单目录不存在 | Step1文件检查 | 提示用户先创建任务卡 |
| 交付物文件损坏 | QC文件大小检查 | 重新生成 |
| 积分预算超支 | 成本追踪实时计数 | 立即停止，通知用户 |
