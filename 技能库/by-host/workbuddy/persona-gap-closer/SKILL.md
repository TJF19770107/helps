# 对标差距发现与填补闭环（persona-gap-closer）

> 目标：第一接近、第二超越对标人物（默认马斯克×巴菲特，可换任一对标）。
> 心法：万法皆空，因果不空——差距是因果，填补差距即是修行。

## 一、五步闭环

```
Step1 复盘 → Step2 画像 → Step3 对标差距 → Step4 学习计划 → Step5 回灌
```

### Step1 复盘（问题解决状态三分类）
- 输入：对话/工作记录（如主对话合并版）
- 扫描全部轮次，按关键词三分类：
  - ✅ 已解决（验收/搞定/跑通/调通/交付）
  - 🔶 不圆满（先用/临时方案/还差/遗留/不够好）
  - ❌ 未解决（还没解决/仍然/又报错/白屏/卡住）
- 产出：`_复盘分类/复盘_{solved,partial,unsolved}.md`
- 复盘结论：解决率 + 未解决集中域 + 不圆满共同模式

### Step2 提炼心理画像（逻辑思维模式）
- 从行为证据提炼思维操作系统（7维：目标驱动/迭代思维/成本敏感/验证偏好/模块化/反浅修/多智能体指挥）
- 提炼默认解决链 + 心理优势/短板
- 产出：`心理画像与对标差距分析.md`（入 Obsidian）

### Step3 对标差距四维分析（调用1234「2」）
- 加载 `马斯克巴菲特思维蒸馏_SKILL.md`
- 四维对比：心理 / 知识 / 认知 / 格局
- 马斯克侧看：第一性原理（原子拆解/失败即数据/10x）
- 巴菲特侧看：能力圈（不做清单）/护城河（资产化）/复利
- 产出：差距总纲一句话（缺什么补什么）

### Step4 学习提升计划（四层修炼 × 三维）
- 炼精化气（近1-3月）→ 炼气化神（3-6月）→ 炼神还虚（6-12月）→ 炼虚合道（12月+）
- 每层覆盖：心理 / 技能 / 事业三维动作
- 渠道：B站/GitHub/抖音/油管/企业官网/技能说明书

### Step5 回灌（实时 + 月度双层进化）

- **增量层（每轮任务后，实时）**：三问增量更新画像
  - ① 这轮暴露了什么新偏好/决策模式？→ 追加画像"实时增量区"
  - ② 这轮沉淀了什么新技能/踩坑？→ 技能库+踩坑库
  - ③ 对标差距分数有变化吗？→ 微调差距分
- **深度层（每月 1 日）**：四维差距重测 + 学习计划刷新 + 渠道执行复盘
- 类 mem0 记忆框架：画像随每轮行为实时进化，不等季度

## 二、成本控制

- 零外部 API：本地 Python 扫描 + 本地蒸馏
- 不重复读：合并版只读一次，中间产物缓存
- 复用：`马斯克巴菲特思维蒸馏_SKILL.md` / `仓颉Skill知识蒸馏技能.md` 直接调用
