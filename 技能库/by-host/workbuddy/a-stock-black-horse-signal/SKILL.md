## 二、黑马四要素评分系统（核心筛选引擎）

> **设计原理**：真正的黑马龙头必须同时满足四个条件，缺一不可。每要素0-25分，总分100。

### 要素1: 量能突破（25分）

| 评分项 | 分值 | 判定标准 |
|--------|------|---------|
| 放量程度 | 10 | 今日成交量 > 5日均量×2 = 10分; ×1.5-2 = 7分; ×1.2-1.5 = 4分 |
| 量比 | 8 | 量比>3 = 8分; 2-3 = 6分; 1.5-2 = 4分; 1-1.5 = 2分 |
| 换手率 | 7 | 换手率5-15% = 7分; 15-25% = 5分; 3-5%/25%+ = 3分 |

**量能突破合格线**：≥15分（否决项，低于15分直接淘汰）

### 要素2: 价格形态（25分）

| 评分项 | 分值 | 判定标准 |
|--------|------|---------|
| 均线排列 | 10 | 多头排列(5>10>20>60) = 10分; 部分 = 5分; 空头 = 0分 |
| 突破形态 | 8 | 突破平台/箱体/前高 = 8分; 均线金叉 = 5分; 无形态 = 0分 |
| K线质量 | 7 | 大阳线(>5%) + 长下影 = 7分; 普通阳线 = 4分; 十字星 = 2分 |

### 要素3: 题材热度（25分）

| 评分项 | 分值 | 判定标准 |
|--------|------|---------|
| 题材板块 | 10 | 当日板块涨幅前3 = 10分; 前10 = 7分; 前20 = 4分 |
| 板块效应 | 8 | 板块内涨停≥5家 = 8分; 3-4家 = 5分; 1-2家 = 2分 |
| 消息催化 | 7 | 政策级利好 = 7分; 行业利好 = 5分; 个股利好 = 3分 |

### 要素4: 资金共振（25分）

| 评分项 | 分值 | 判定标准 |
|--------|------|---------|
| 主力净流入 | 10 | 净流入>1亿 = 10分; 5000万-1亿 = 7分; 1000-5000万 = 4分 |
| 大单占比 | 8 | 大单占比>30% = 8分; 20-30% = 5分; 10-20% = 3分 |
| 北向资金 | 7 | 北向净买入>5000万 = 7分; 1000-5000万 = 5分; 无数据 = 3分 |

### 综合评级

| 总分 | 评级 | 信号强度 | 操作建议 |
|------|------|---------|---------|
| 85-100 | S级 | ⭐⭐⭐⭐⭐ | 重点关注，准备建仓 |
| 70-84 | A级 | ⭐⭐⭐⭐ | 加入自选，择机介入 |
| 55-69 | B级 | ⭐⭐⭐ | 观察为主，不急于介入 |
| <55 | C级 | ⭐⭐ | 不符合黑马标准，淘汰 |

## 三、涨停板质量四维分析

> 涨停不等于黑马。需判断涨停板的质量和可持续性。

### 维度1: 封板时间

| 封板时间 | 质量评分 | 说明 |
|---------|---------|------|
| 开盘即涨停(9:30) | 10分 | 一字板/秒板，最强 |
| 9:30-10:00 | 8分 | 早盘强势封板 |
| 10:00-13:00 | 6分 | 盘中封板，中等 |
| 13:00-14:30 | 4分 | 午后封板，偏弱 |
| 14:30-15:00 | 2分 | 尾盘封板，最弱（警惕次日低开） |

### 维度2: 封单量

| 封单/流通市值 | 质量评分 | 说明 |
|--------------|---------|------|
| >5% | 10分 | 封单极大，买盘极强 |
| 2-5% | 7分 | 封单充足 |
| 1-2% | 5分 | 封单一般 |
| <1% | 2分 | 封单薄弱（可能开板） |

### 维度3: 涨停原因

| 原因类型 | 质量评分 | 说明 |
|---------|---------|------|
| 政策利好/国家级 | 10分 | 持续性最强 |
| 行业突破/技术革新 | 8分 | 持续性较强 |
| 业绩超预期 | 7分 | 基本面驱动 |
| 板块联动 | 5分 | 跟风性质 |
| 超跌反弹 | 3分 | 持续性最弱 |
| 不明原因 | 2分 | 警惕 |

### 维度4: 涨停历史

| 历史特征 | 质量评分 | 说明 |
|---------|---------|------|
| 首板+底部启动 | 10分 | 最安全，空间大 |
| 2-3连板+放量 | 8分 | 强势确认 |
| 4-5连板 | 5分 | 高位，风险增加 |
| 6连板+ | 2分 | 极高位，随时见顶 |
| 曾涨停→开板→再涨停 | 6分 | 换手洗盘后重新走强 |

### 涨停板质量评级

| 总分 | 评级 | 操作建议 |
|------|------|---------|
| 32-40 | 优质涨停 | 次日可重点关注，有望连板 |
| 24-31 | 合格涨停 | 观察次日开盘强度 |
| 16-23 | 一般涨停 | 谨慎对待，可能冲高回落 |
| <16 | 劣质涨停 | 回避，大概率次日低开 |

## 四、龙虎榜游资追踪

> 通过龙虎榜数据识别游资动向，跟随强势资金。

### 游资席位分类

| 席位类型 | 特征 | 跟随价值 |
|---------|------|---------|
| 顶级游资 | 知名席位(如东方财富拉萨、国泰君安上海江苏路) | ⭐⭐⭐⭐⭐ 高 |
| 活跃游资 | 频繁上榜+胜率高 | ⭐⭐⭐⭐ 较高 |
| 机构专用 | "机构专用"席位 | ⭐⭐⭐⭐ 中高(基本面信号) |
| 一般游资 | 偶尔上榜 | ⭐⭐ 低 |
| 深股通/沪股通 | 北向资金席位 | ⭐⭐⭐ 中(参考价值) |

### 龙虎榜分析要点

1. **买入集中度**：前5买入合计 > 卖出合计 = 净买入，越大越好
2. **席位协同**：多个顶级游资同时买入 = 强共振信号
3. **买入金额**：单席买入>5000万 = 重仓介入
4. **卖出对比**：卖出席位是否有机构出货
5. **连续上榜**：连续多日上榜 = 持续运作

### 龙虎榜信号强度

| 信号组合 | 强度 | 操作建议 |
|---------|------|---------|
| 顶级游资+净买入>1亿+连续上榜 | S级 | 强烈关注 |
| 活跃游资+净买入5000万-1亿 | A级 | 重点关注 |
| 机构+净买入+底部启动 | A级 | 中线关注 |
| 一般游资+小额净买入 | B级 | 观察 |
| 游资净卖出 | ❌ | 回避 |

## 五、A股缠论买点适配

> 将缠论三类买点应用于A股黑马筛选，提升买入精确度。

### 第一类买点（趋势反转）

| 条件 | 判定 |
|------|------|
| 前期下跌趋势明确（至少2个下跌中枢） | ✅ |
| 底部出现背驰（MACD面积/斜率缩小） | ✅ |
| 放量突破最后一跌的起点 | ✅ |
| 当前价格在底部区域（距前高>30%） | ✅ |

**A股适配**：适合底部启动的黑马，但需配合题材热度。纯缠论一买在A股容易抄在半山腰。

### 第二类买点（回踩确认）

| 条件 | 判定 |
|------|------|
| 一买后上涨形成第一个上涨中枢 | ✅ |
| 回踩不破前低（二买不破一买） | ✅ |
| 回踩缩量，放量再上攻 | ✅ |
| 回踩幅度<上涨幅度的50% | ✅ |

**A股适配**：最适合A股黑马的买点。回踩确认后介入，风险收益比最优。

### 第三类买点（突破确认）

| 条件 | 判定 |
|------|------|
| 上涨中枢形成后向上突破 | ✅ |
| 突破时放量（>前5日均量×1.5） | ✅ |
| 突破后回踩不进中枢上沿 | ✅ |
| 均线多头排列确认 | ✅ |

**A股适配**：适合强势黑马追涨。但A股T+1，三买追高需控制仓位。

### 缠论买点与黑马四要素结合

| 买点类型 | 黑马四要素要求 | 仓位建议 |
|---------|--------------|---------|
| 一买 | 四要素≥70分 | 轻仓试探（计划仓位30-50%） |
| 二买 | 四要素≥75分 | 标准仓位（计划仓位70-100%） |
| 三买 | 四要素≥80分 | 中等仓位（计划仓位50-70%） |

## 六、见顶信号三级预警

> 识别黑马见顶信号，及时止盈/止损。

### 一级预警（减仓信号）

| 信号 | 说明 |
|------|------|
| 放量滞涨 | 成交量放大但价格不涨，主力出货 |
| 高位长上影 | 上影线>实体2倍，上方压力大 |
| 连板后首次开板 | 涨停打开又封回，分歧加大 |
| 龙虎榜游资净卖出 | 顶级游资开始出货 |
| 板块涨幅收窄 | 板块整体走弱，龙头难以独立 |

**操作**：减仓50%，保留底仓观察

### 二级预警（清仓信号）

| 信号 | 说明 |
|------|------|
| 跌破5日均线 | 短期趋势破坏 |
| 放量大跌（>5%） | 主力大举出货 |
| 连板断板+次日低开 | 强势格局结束 |
| 涨停→跌停（天地板） | 极端出货信号 |
| 板块集体跌停 | 系统性风险 |

**操作**：清仓，不留底仓

### 三级预警（紧急止损）

| 信号 | 说明 |
|------|------|
| 跌破买入价5% | 触发硬止损 |
| 跌破10日均线+放量 | 中期趋势破坏 |
| 基本面突变（业绩暴雷/ST） | 黑天鹅事件 |
| 市场系统性暴跌（大盘>3%） | 恐慌蔓延 |

**操作**：立即市价卖出，不等反弹

## 七、板块轮动四阶段

> 黑马股往往诞生于热点板块。判断板块所处阶段，提前布局。

### 阶段1: 启动期（布局）

| 特征 | 操作 |
|------|------|
| 板块内1-2只股票涨停 | 关注龙头，轻仓试探 |
| 成交量温和放大 | 研究板块逻辑 |
| 媒体开始报道 | 判断题材持续性 |

### 阶段2: 加速期（主升）

| 特征 | 操作 |
|------|------|
| 板块内3-5只涨停 | 加仓龙头 |
| 板块涨幅前5 | 跟随强势股 |
| 资金大幅流入 | 持有为主，不频繁换股 |

### 阶段3: 扩散期（谨慎）

| 特征 | 操作 |
|------|------|
| 板块内>8只涨停 | 减仓兑现 |
| 跟风股补涨 | 不追跟风股 |
| 全民讨论该板块 | 警惕见顶 |

### 阶段4: 退潮期（回避）

| 特征 | 操作 |
|------|------|
| 龙头股开板/跌停 | 清仓 |
| 板块涨幅收窄/翻绿 | 不抄底 |
| 资金大幅流出 | 等待下一个板块 |

### 板块轮动节奏判断

```
当前热点板块 → 判断阶段 → 操作
  ├─ 启动期 → 布局龙头
  ├─ 加速期 → 持有/加仓
  ├─ 扩散期 → 减仓兑现
  └─ 退潮期 → 回避，找下一个启动板块

预判下一板块：
  ├─ 资金流向：今日资金净流入前5板块
  ├─ 政策日历：近期政策利好方向
  └─ 技术形态：底部放量+均线粘合的板块
```

## 九、时段策略（V2.0新增）

> A股不同时段，黑马股表现不同。按时段选择不同策略。

### 时段1: 开盘竞价（9:15-9:25）

| 策略 | 操作 |
|------|------|
| 观察竞价异动 | 高开>3%+竞价量放大 = 关注 |
| 竞价龙头 | 竞价涨幅板块第一 = 当日龙头候选 |
| 避免操作 | 竞价阶段不下单（信息不充分） |

### 时段2: 早盘强势（9:30-10:00）

| 策略 | 操作 |
|------|------|
| 秒板/快速涨停 | 记录为今日强势候选，不追（T+1无法卖出） |
| 放量突破 | 关注突破前高/平台的股票 |
| 板块定调 | 前30分钟板块涨幅排名 = 当日主线 |

**早盘策略**：观察为主，不急于建仓。记录候选，等回踩确认。

### 时段3: 盘中震荡（10:00-13:00）

| 策略 | 操作 |
|------|------|
| 回踩买入 | 早盘强势股回踩5日线/均价线 = 二买机会 |
| 板块轮动 | 观察资金从早盘板块流向 |
| 避免追高 | 盘中冲高>5%不追 |

**盘中策略**：执行二买操作。回踩缩量+放量再上攻 = 介入点。

### 时段4: 午后选择（13:00-14:00）

| 策略 | 操作 |
|------|------|
| 强势确认 | 午后维持涨幅>3% = 强势确认 |
| 弱势识别 | 午后回落超早盘高点50% = 弱势 |
| 板块二次拉升 | 午后板块再次走强 = 加仓机会 |

### 时段5: 尾盘操作（14:00-15:00）

| 策略 | 操作 |
|------|------|
| 尾盘买入 | 14:30后强势企稳 = 次日溢价概率高 |
| 尾盘拉升警惕 | 14:50突然拉升 = 非主力行为，谨慎 |
| 尾盘跳水 | 14:30后大幅回落 = 次日低开概率高，减仓 |

**尾盘策略**：14:30-14:50是最佳操作窗口。强势股尾盘企稳可买入，弱势股尾盘跳水需减仓。

## 十、全链路联动（V2.0新增）

> 黑马信号不是孤立判断，需与全链路技能协同。

### 联动技能表

| 联动技能 | 数据流方向 | 联动内容 |
|---------|-----------|---------|
| `neodata-westock-dual-query` | ← 输入 | 行情/资金流/龙虎榜/板块数据 |
| `daily-market-dashboard` | → 输出 | 精选标的转入实盘监控 |
| `position-sizing-engine` | → 输出 | 信号强度→仓位计算 |
| `trading-risk-radar` | ← 输入 | 市场风险评分（高风险日减仓） |
| `trading-journal-ai` | → 输出 | 信号记录→交易日志 |
| `macro-market-linkage` | ← 输入 | 宏观周期→板块配置方向 |
| `crypto-quant-signal` | ↔ 平行 | A股/加密双市场信号对照 |

### 联动数据流

```
neodata-westock-dual-query
  │ (行情/资金/龙虎榜数据)
  ▼
a-stock-black-horse-signal (本技能)
  │ (黑马信号+评分+精选标的)
  ├─→ daily-market-dashboard (实盘监控)
  ├─→ position-sizing-engine (仓位计算)
  ├─→ trading-journal-ai (信号记录)
  │
  │ (市场风险评分)
  ←─ trading-risk-radar
  │
  │ (宏观周期+板块方向)
  ←─ macro-market-linkage
```

### 联动优先级规则

1. **风控优先**：trading-risk-radar发出高风险预警时，即使S级信号也暂停建仓
2. **宏观校准**：macro-market-linkage提示的受益板块优先级+5分
3. **仓位约束**：position-sizing-engine计算的仓位为上限，不可超额
4. **日志闭环**：每次信号必须记录到trading-journal-ai，形成回测数据

## 十一、每日盯盘三件套

> 日常使用最高频的三个操作。

### 三件套1: 盘前扫描（9:00-9:15）

```
1. 查看昨日精选标的竞价情况
2. 全市场批量扫描（§八 Step 1粗筛）
3. 检查大盘情绪（daily-market-dashboard 模块零）
→ 输出：今日关注列表（3-5只）
```

### 三件套2: 盘中监控（10:00/13:00/14:00）

```
1. 检查关注列表走势（是否按预期）
2. 时段策略执行（§九 对应时段操作）
3. 见顶信号检查（§六 三级预警）
→ 输出：操作决策（买入/持有/减仓/清仓）
```

### 三件套3: 收盘复盘（15:00后）

```
1. 当日信号回顾（哪些命中/哪些miss）
2. 涨停板质量分析（§三 四维分析）
3. 龙虎榜游资追踪（§四）
4. 板块轮动阶段判断（§七）
5. 信号记录→trading-journal-ai
→ 输出：明日计划
```

## 十二、周期追踪（V2.0新增）

> 黑马信号不是一次性判断，需要持续跟踪信号演进。

### 信号生命周期追踪

| 阶段 | 追踪内容 | 持续时间 |
|------|---------|---------|
| 发现期 | 首次触发评分≥70分 | Day 1 |
| 确认期 | 连续2日评分维持+成交量配合 | Day 2-3 |
| 爆发期 | 涨停/大涨+板块共振 | Day 3-7 |
| 持有期 | 趋势完整+无见顶信号 | 持续 |
| 衰退期 | 见顶信号出现+评分下降 | 退出 |

### 追踪记录表

```markdown
| 股票 | 发现日 | 初始评分 | 当前评分 | 变化 | 阶段 | 操作 |
|------|--------|---------|---------|------|------|------|
| XXX | 7/15 | 82(A级) | 88(S级) | ↑6 | 爆发期 | 持有 |
| YYY | 7/16 | 75(A级) | 68(B级) | ↓7 | 衰退期 | 减仓 |
| ZZZ | 7/18 | 90(S级) | 85(S级) | ↓5 | 确认期 | 观察 |
```

### 评分变化预警

| 变化幅度 | 预警级别 | 操作 |
|---------|---------|------|
| 评分下降>10分 | ⚠️ 高预警 | 检查见顶信号，准备减仓 |
| 评分下降5-10分 | 🟡 中预警 | 密切关注，收紧止损 |
| 评分波动<5分 | 🟢 正常 | 继续持有 |
| 评分上升>5分 | ⬆️ 加仓信号 | 考虑加仓（需风控通过） |
