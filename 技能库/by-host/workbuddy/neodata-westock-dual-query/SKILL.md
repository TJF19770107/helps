# 双数据源金融智能查询 · v2.1

> **定位**：大道量化体系的**数据供给层入口**，统一封装 Neodata 与腾讯自选股（Westock）两个MCP数据连接器，解决"该用哪个数据源、代码怎么写、查错怎么办"三大高频问题。
> **核心价值**：一条命令 → 自动选源 → 标准化代码 → 返回可直接用于信号/决策/日志的数据。

---

## 〇、何时启用本技能

- 用户说"查一下XX股票/基金/指数行情"
- 用户需要A股/港股/美股/加密/宏观数据
- 用户分不清该用 `neodata` 还是 `westock-mcp`
- 其他技能（信号/决策/风控/日志）需要数据但不想直接写MCP调用
- 发现数据异常、需要切换备用源或对齐财年口径

## 一、双数据源定位与路由规则

### 1.1 数据源能力画像

| 能力维度 | Neodata（金融数据MCP） | 腾讯自选股 Westock |
|---------|----------------------|-------------------|
| **优势领域** | A股/港股/美股行情、财务数据、技术指标、板块资金流 | 实时行情、快速报价、新闻/公告、个股资金、A股即时盘面 |
| **实时性** | 行情实时性中高，财务/指标数据丰富 | 行情实时性高，适合盘中盯盘 |

## 四、核心查询逻辑

### 4.1 标准查询流程

```
用户查询
  ↓
Step 1: 解析意图（市场/标的/数据类型/时间维度）
  ↓
Step 2: 根据路由表选择首选数据源
  ↓
Step 3: 标准化代码格式
  ↓
Step 4: 调用对应MCP工具（Neodata / Westock）
  ↓
Step 5: 数据质量检查（完整性/时效性/异常值）
  ↓
Step 6: 格式化输出（统一表格/决策可用格式）
  ↓
Step 7: 记录本次查询供后续技能调用
```

### 4.2 数据质量检查清单

| 检查项 | 通过标准 | 失败处理 |
|--------|---------|---------|
| 代码有效性 | 返回非空且字段完整 | 提示"代码不存在或已退市" |
| 数据时效性 | 行情数据时间戳在5分钟内 | 切换备用数据源 |
| 数值合理性 | 涨跌幅在±20%以内（A股） | 标记异常，请求人工确认 |
| 字段完整性 | 关键字段（价/量/额）不缺失 | 尝试从次选数据源补齐 |
| 跨源一致性 | 双源同一字段偏差<2% | 取主数据源，备注差异 |

### 4.3 财年口径对齐指南

- **A股财报**：自然年财年，Q1=1-3月，Q2=1-6月，Q3=1-9月，年报=1-12月
- **美股财报**：按公司财年，注意部分公司非自然年（如苹果9月财年）
- **港股财报**：多数自然年，部分公司为4月财年
- **统一输出**：所有财报查询默认返回"报告期"字段，标注实际起止日期

## 五、错误处理与联动兜底（V2.1 增强）

### 5.1 常见错误码与处理

| 错误现象 | 可能原因 | 处理策略 |
|---------|---------|---------|
| 返回空值 | 代码格式错误/退市/停牌 | 检查代码格式，尝试纯数字代码 |
| 数据延迟 | 数据源缓存 | 切换备用数据源再查一次 |
| 字段缺失 | 该数据源不支持此指标 | 切换另一数据源补齐 |
| 查询超时 | 网络/服务繁忙 | 重试1次，超时则返回"数据暂不可用" |
| 跨源差异大 | 口径不同（如资金流入） | 备注差异原因，不强制统一 |

### 5.2 联动超时兜底规则

```
当 Neodata 查询超时（>15s）或返回异常：
  1. 自动切换 Westock 重试
  2. Westock 也失败 → 提示用户"数据源暂不可用，请稍后重试"
  3. 记录失败日志到 trading-journal-ai（如可用）

当 Westock 查询失败：
  1. 自动切换 Neodata 重试
  2. Neodata 失败 → 返回缓存数据（如有）+ 风险提示
```

## 六、联动技能表（V2.1 核心升级）

本技能作为数据供给层，为以下6个技能提供双向数据服务：

```
                    neodata-westock-dual-query V2.1
                              （数据层）
                                 |
        ┌────────┬────────┬────┴────┬────────┬────────┐
        ↓        ↓        ↓         ↓        ↓        ↓
   daily-market  a-stock  crypto   position  trading  macro
    -dashboard  -signal  -quant   -sizing  -risk   -market
       V3.1     V2.0    -signal   -engine  -radar  -linkage
                          V2.0     V2.0    V2.0    V2.0
```

| 联动技能 | 数据供给方向 | 交互内容 | 优先级 |
|---------|------------|---------|--------|
| daily-market-dashboard V3.1 | ← 输出 | 大盘/板块/北向/个股实时数据 | P0 |
| a-stock-black-horse-signal V2.0 | ← 输出 | 个股行情、财务、技术指标 | P0 |
| crypto-quant-signal V2.0 | ← 输出 | 加密行情（通过间接数据桥接） | P1 |
| position-sizing-engine V2.0 | ← 输出 | 标的波动率、ATR、止损参考价 | P1 |
| trading-risk-radar V2.0 | ← 输出 | 市场波动率、流动性指标 | P1 |
| macro-market-linkage V2.0 | ← 输出 | 宏观数据（CPI/PMI/利率等） | P0 |

> **双向联动说明**：上述技能调用本技能时，本技能也反向接收它们的"数据需求反馈"（如需要特定字段、特定时间窗口），从而优化后续查询。

## 十、限制与边界

- 本技能**不直接产生交易信号**，仅提供数据供给
- 加密市场数据建议通过 crypto-quant-signal 或专用加密数据源获取，本技能为间接补充
- 数据源可用性受MCP连接器状态影响，调用前需确认 Neodata / Westock 已连接
- 财报数据存在发布滞后，查询最新财报时需标注"报告期"和"发布日期"
