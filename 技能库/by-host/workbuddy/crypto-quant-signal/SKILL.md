# crypto-quant-signal — 加密货币量化信号系统 V2.0

> 缠论三类买卖点 + 黑马四要素 + 全民狂热见顶 + 多周期共振 + 仓位管理

## 1. 适用场景

- 加密货币（BTC/ETH/主流山寨）的买卖信号识别
- 缠论三类买卖点在加密市场的实战应用
- 识别币种是否具备"黑马"爆发特征
- 判断市场是否进入"全民狂热"见顶阶段
- 多周期共振信号确认与仓位分配
- 与 `position-sizing-engine` 联动输出可执行交易指令

## 2. 缠论三类买卖点识别

### 2.1 三类买点

| 买点 | 定义 | 信号强度 | 确认条件 |
|------|------|---------|---------|
| **一买** | 下跌趋势背驰后的第一类买点 | ⭐⭐⭐⭐⭐ | 底分型确认 + MACD底背离 + 成交量放大 |
| **二买** | 一买后的回调不破前低 | ⭐⭐⭐⭐ | 回踩不破一买低点 + 缩量企稳 |
| **三买** | 中枢上沿突破后的回调不破中枢 | ⭐⭐⭐ | 中枢上方缩量回踩 + MACD零轴上金叉 |

### 2.2 三类卖点

| 卖点 | 定义 | 信号强度 | 确认条件 |
|------|------|---------|---------|
| **一卖** | 上涨趋势背驰后的第一类卖点 | ⭐⭐⭐⭐⭐ | 顶分型确认 + MACD顶背离 + 放量滞涨 |
| **二卖** | 一卖后反弹不破前高 | ⭐⭐⭐⭐ | 反弹缩量 + 不破一卖高点 |
| **三卖** | 中枢下沿跌破后的反抽不破中枢 | ⭐⭐⭐ | 中枢下方缩量反弹 + MACD零轴下死叉 |

### 2.3 买卖点执行规则

- **一买/一卖**：核心仓位（50-70%），止损设置在分型低点/高点外侧2%
- **二买/二卖**：加仓/减仓（20-30%），止损设在前低/前高
- **三买/三卖**：轻仓交易（10-20%），快进快出

## 3. 黑马四要素筛选

对候选币种按四要素打分（每项0-25分，满分100分）：

### 3.1 价格行为（25分）
- 近期出现强势突破关键阻力（10分）
- K线形态呈现攻击性（长阳吞没/早晨之星等）（8分）
- 回调幅度浅（< 38.2% 斐波那契）（7分）

### 3.2 成交量异常（25分）
- 成交量较20日均量放大2倍以上（10分）
- 持续放量（连续3天以上）（8分）
- 缩量回调时量能健康（7分）

### 3.3 形态突破（25分）
- 突破长期下降趋势线（10分）
- 突破关键均线（EMA21/EMA55）（8分）
- 形成看涨形态（W底/头肩底/旗形突破）（7分）

### 3.4 市场情绪（25分）
- 资金费率正常偏多（非极端值）（10分）
- 合约持仓量上升但未过热（8分）
- 社交讨论热度上升但未狂热（7分）

### 黑马评级
- **90-100分**：超级黑马，全力出击
- **75-89分**：黑马候选，积极关注
- **60-74分**：潜力股，等待确认
- **< 60分**：普通，暂不参与

## 5. 多周期共振体系

### 5.1 三周期框架

| 周期 | 作用 | K线参考量 |
|------|------|----------|
| 日线（D）| 大趋势方向判断 | 60-120根 |
| 4小时（4H）| 中级波段操作 | 120-200根 |
| 1小时（1H）| 精确入场时机 | 100-150根 |

### 5.2 5级共振信号强度

| 共振级别 | 条件 | 信号强度 | 建议仓位 | 置信度 |
|---------|------|---------|---------|--------|
| **S级**（完美共振） | 3周期同向买卖点 | 100% | 60-80% | 极高 |
| **A级**（强共振） | 日线+4H同向，1H确认 | 80% | 40-60% | 高 |
| **B级**（中等共振） | 日线同向，4H或1H确认 | 60% | 20-40% | 中 |
| **C级**（弱共振） | 仅1H或4H信号 | 40% | 10-20% | 偏低 |
| **D级**（无共振） | 周期矛盾/无信号 | 0% | 0%（观望）| 无 |

### 5.3 周期矛盾处理

当三周期方向不一致时：
- **日线多 + 4H空**：等待4H回调到位后做多（等二买）
- **日线空 + 4H多**：反弹做空（等二卖），不追多
- **日线多 + 4H多 + 1H空**：1H回调是加仓机会

```

信号: S级完美共振（日线一买 + 4H二买 + 1H三买确认）
共振强度: 100%
建议仓位: 65%
买入价: 市场价
止损价: 日线底分型低点 - 2% = $XX,XXX
止盈1: 前中枢上沿 = $XX,XXX（40%仓位）
止盈2: 前高点 = $XX,XXX（30%仓位）
止盈3: 移动止盈（30%仓位）
```
