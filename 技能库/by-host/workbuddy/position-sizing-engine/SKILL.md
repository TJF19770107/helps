# 仓位计算引擎 · v2.0

> **定位**：将宏观判断、情绪状态、风控评分、信号强度转化为**可执行的仓位数字**，输出"买入X股@X元，止损X元"的精确指令。
> **核心理念**：永远先算风险，再算仓位；单笔亏损 ≤ 总资金2%。

---

## 〇、何时启用本技能

- 用户问"这个信号买多少仓位"
- 用户需要计算止损位和止盈位
- 用户准备开仓，但不确定仓位比例
- 需要评估当前持仓组合的整体风险暴露
- 风控雷达提示风险变化，需要动态调整仓位

## 一、仓位计算四维模型

```
仓位系数 = 基础仓位 × 宏观系数 × 情绪系数 × 风险评分系数 × 信号强度系数

基础仓位：信号本身建议仓位（默认10%）
宏观系数：根据宏观风险日历调整（0.5-1.2）
情绪系数：根据交易者情绪状态调整（0.6-1.1）
风险评分系数：根据 trading-risk-radar 综合评分折减（0-1.0）
信号强度系数：A/B/C级信号对应（1.0/0.7/0.4）
```

### 1.1 各维度系数表

| 维度 | 等级 | 系数 | 判定条件 |
|------|------|------|---------|
| **宏观系数** | 低风险 | 1.0 | 无重大宏观事件，市场平稳 |
| | 中风险 | 0.8 | 次要数据发布日（PMI、零售等） |
| | 高风险 | 0.5 | 美联储/CPI/非农等重大事件日 |
| **情绪系数** | 冷静 | 1.0 | 按计划执行，无冲动交易 |
| | 略焦躁 | 0.8 | 有FOMO或犹豫迹象 |
| | 明显情绪化 | 0.6 | 愤怒/恐惧/过度兴奋 |
| **风险评分系数** | 安全(0-30) | 1.0 | 综合风险评分低 |
| | 谨慎(31-50) | 0.7 | 综合风险评分中等 |
| | 警戒(51-70) | 0.5 | 风险偏高 |
| | 危险(71-100) | 0 | 禁止开新仓 |
| **信号强度系数** | A级 | 1.0 | 多周期共振+黑马四要素优秀 |
| | B级 | 0.7 | 单一周期或部分要素满足 |
| | C级 | 0.4 | 弱信号或观察级 |

### 1.2 最终仓位区间控制

```
计算后仓位  ＜ 5%  →  不交易（信号太弱）
计算后仓位 5%-15%  →  轻仓试探
计算后仓位 15%-25%  →  标准仓位
计算后仓位 25%-35%  →  重仓（需A级信号+低风险）
计算后仓位  ＞ 35%  →  强制压缩至35%（单标的上限）
```

## 二、核心公式：凯利公式变体

### 2.1 单笔亏损预算

```
单笔最大亏损 = 总资金 × 2%

例：总资金100万 → 单笔最大亏损 = 2万元
```

### 2.2 止损距离计算

```
止损距离(%) = 买入价 - 止损价 / 买入价 × 100%

或基于ATR：
止损距离 = ATR(14) × N / 买入价 × 100%
（N通常取2-3）
```

### 2.3 仓位数量公式

```
仓位金额 = 单笔最大亏损 / 止损距离(%)
买入股数 = 仓位金额 / 买入价  （A股按100股整数倍取整）

例：
总资金100万，止损距离5%，买入价50元
单笔最大亏损 = 2万
仓位金额 = 2万 / 5% = 40万
买入股数 = 40万 / 50 = 8000股 → 按100股取整 = 8000股
止损价 = 50 × (1 - 5%) = 47.5元

输出：买入8000股@50元，止损47.5元，占用资金40万
```

### 2.4 仓位金额上限控制

```
仓位金额 ≤ min(计算仓位金额, 总资金 × 单标的上限比例)
默认单标的上限比例 = 25%（可根据风险偏好调整至15%-35%）
```

## 四、动态移动止盈（V2.0 新增）

### 4.1 五档浮盈追踪策略

| 浮盈幅度 | 止盈策略 | 追踪止损位 |
|---------|---------|-----------|
| 0%-3% | 不移动止盈，保持原止损 | 初始止损价 |
| 3%-5% | 保本止盈 | 移至成本价 |
| 5%-10% | 半仓锁定利润 | 止盈位 = 成本价 + 50%浮盈 |
| 10%-20% | 趋势跟随 | 止盈位 = 最高价 - 20%回撤 |
| ＞20% | 加速止盈 | 止盈位 = 最高价 - 10%回撤 |

### 4.2 移动止盈执行流程

```
Step 1: 记录初始买入价、初始止损价
Step 2: 每日收盘检查浮盈状态
Step 3: 根据浮盈档位更新止盈位（只上移不下移）
Step 4: 触发止盈位 → 执行减仓/平仓
Step 5: 更新 trading-journal-ai 交易日志
```

## 五、最大回撤熔断（V2.0 新增）

### 5.1 四级熔断机制

| 累计回撤 | 熔断等级 | 触发动作 |
|---------|---------|---------|
| 5% | 一级预警 | 减仓20%，暂停新增仓位 |
| 10% | 二级预警 | 减仓50%，仅保留核心持仓 |
| 15% | 三级熔断 | 减仓80%，仅止损/保本操作 |
| 20% | 四级熔断 | 全部清仓，停止交易1-3天 |

### 5.2 熔断触发条件

```
累计回撤 = (账户最高净值 - 当前净值) / 账户最高净值 × 100%

触发时机：
- 每日收盘结算
- 盘中突发大幅回撤时实时检查
- 连续亏损3笔以上额外检查

熔断执行：
1. 立即按等级减仓
2. 通知 trading-risk-radar 更新风险状态
3. 记录熔断事件到 trading-journal-ai
4. 触发 weekly-strategy-reset 周度复盘（如恰逢周末）
```

## 六、集中度与相关性折减（V2.0 新增）

### 6.1 同板块集中度折减

```
单一板块总仓位 ≤ 35%

若当前持仓 + 新买入仓位 ＞ 板块上限：
  新买入仓位 = 板块上限 - 当前持仓
  若结果 ≤ 0 → 拒绝开仓
```

### 6.2 多仓位相关性调整

| 持仓间相关性 | 调整策略 |
|------------|---------|
| 高度相关（r > 0.7） | 合并计算仓位，避免重复暴露 |
| 中度相关（0.4 < r ≤ 0.7） | 新仓位折减20% |
| 低相关（r ≤ 0.4） | 正常计算 |

### 6.3 组合风险暴露上限

```
总仓位上限 = 80%（常态） / 50%（高风险日） / 0%（熔断状态）
现金比例 ≥ 20%（常态） / 50%（高风险日） / 100%（熔断状态）
```

## 八、使用示例

### 示例1：A股开仓
```
用户：总资金100万，600519出现A级买入信号，现价1500，止损设1450，今天能买多少？
→ 计算：
  止损距离 = (1500-1450)/1500 = 3.33%
  单笔最大亏损 = 100万×2% = 2万
  仓位金额 = 2万/3.33% = 60万
  但单标的上限25% → 压缩为25万
  买入股数 = 25万/1500 = 166.67 → 100股取整 = 1600股
  占用资金 = 1600×1500 = 240万？（错误，超过单标上限）
  重新：100万×25% = 25万，买入1600股，占用24万，止损1450

输出：买入1600股@1500元，止损1450元，占用资金24万，占总资金24%
```

### 示例2：风险日仓位折减
```
用户：今天CPI发布，风险评分65，有个B级信号，怎么买？
→ 计算：
  宏观系数 = 0.5（高风险日）
  风险评分系数 = 0.5（51-70警戒）
  信号强度系数 = 0.7（B级）
  仓位 = 10% × 0.5 × 0.5 × 0.7 = 1.75%
→ 结果：仓位过低，建议观望或仅1%试探
```

### 示例3：持仓组合检查
```
用户：帮我看看当前仓位风险
→ 读取当前持仓
→ 计算板块集中度、相关性、回撤状态
→ 输出组合风险视图 + 调整建议
```

## 十一、限制与边界

- 本技能**不判断信号质量**，信号由 a-stock-black-horse-signal / crypto-quant-signal 提供
- 仓位计算为**建议值**，最终执行需用户确认
- 熔断机制触发后需人工确认是否恢复交易，避免机械执行
- A股买入数量需按100股整数倍取整，本技能输出已自动处理
- 加密市场无涨跌幅限制，止损距离建议更宽（默认ATR倍数更高）
