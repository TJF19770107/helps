## 3. 五维风险监测体系

### 3.1 市场风险（权重30%）

| 子指标 | 安全🟢 | 关注🟡 | 警惕🟠 | 危险🔴 |

| VIX/加密波动率 | < 60 | 60-80 | 80-100 | > 100 |
| 大盘情绪评分 | 7-10 | 4-6 | 2-3 | 0-1 |
| 资金费率(8h) | < 0.03% | 0.03-0.05% | 0.05-0.1% | > 0.1% |
| 多币种相关性 | < 0.5 | 0.5-0.7 | 0.7-0.85 | > 0.85 |
| 24h波动率 | < 3% | 3-5% | 5-10% | > 10% |

| 单一币种集中度 | < 20% | 20-30% | 30-40% | > 40% |

## 4. 综合风险评分

### 4.1 评分公式

```
综合风险分 = 市场风险得分×30% + 仓位风险得分×25% + 纪律风险得分×20% + 流动性风险得分×15% + 黑天鹅风险得分×10%
```

### 4.2 风险等级与操作指引

| 评分 | 等级 | 图标 | 操作指引 |
|------|------|------|---------|
| 0-30 | 安全 | 🟢 | 正常交易，维持当前策略 |
| 31-50 | 关注 | 🟡 | 可以交易，减少仓位20% |
| 51-70 | 警惕 | 🟠 | 减少仓位至50%以下，收紧止损 |
| 71-100 | 危险 | 🔴 | 暂停开新仓，考虑对冲/减仓 |

### 5.1 盘前风控（08:00-09:00）
- 宏观日历检查（今日重大事件）

- 当前持仓风险评估
- 生成当日风控基线

### 5.2 盘中风控（09:00-15:00 / 24h加密）
- 实时三级分级告警（见第6节）

- 风险指标日终快照
- 风险趋势更新
- 联动 `trading-journal-ai` 记录

## 7. 极端行情应急手册（7场景）

### 场景1：闪崩（-15%+/1h）
1. 立即检查是否触发止损 → 若未触发，手动市价减仓50%
2. 检查资金费率是否极端负值 → 判断是恐慌还是爆仓连锁
3. 暂停所有开仓操作
4. 等待波动率回归正常后再评估

### 场景2：暴力拉升（+20%+/1h）
1. 检查是否触发止盈 → 按计划执行
2. 检查资金费率是否极端正值 → 警惕逼空陷阱
3. 不要追高加仓
4. 适当减仓锁定利润

### 场景3：交易所宕机
1. 检查是否已设止损 → 确认止损单状态
2. 如有对冲仓位，检查对冲端交易所状态
3. 监控社交媒体获取恢复时间预估
4. 恢复后立即检查持仓状态

### 场景4：稳定币脱锚
1. USDT/USDC偏离 > 0.5% → 立即将稳定币转为BTC/ETH或法币
2. 减少杠杆至0
3. 暂停所有合约交易
4. 等待锚定恢复

### 场景5：监管黑天鹅
1. 确认影响范围（特定币种/交易所/全域）
2. 受影响资产立即减仓至0或最小
3. 评估连带影响
4. 等待政策明朗后再决策

### 场景6：大户砸盘/爆仓连锁
1. 检查自身仓位杠杆率 → 立即去杠杆
2. 不抄底（爆仓连锁通常还有第二波）
3. 设置更宽的止损容忍
4. 等待清算完成后的企稳信号

### 场景7：技术故障（API断连/交易故障）
1. 切换到备用连接/备用交易所
2. 用市价单处理紧急仓位
3. 确认故障范围（自身/交易所）
4. 恢复正常后补录交易记录

## 8. 风险趋势追踪

### 8.1 日度风险记录
```
日期: YYYY-MM-DD
综合风险分: XX/100 (🟢/🟡/🟠/🔴)
各维度: 市场XX 仓位XX 纪律XX 流动XX 黑天鹅XX
当日触发告警: L1:X次 L2:X次 L3:X次
重大事件: 无/XXX
```

### 8.2 周度风险趋势
- 绘制5日风险分走势
- 识别风险恶化/改善趋势
- 与上周对比变化

### 8.3 趋势联动预警
- 连续3天风险分上升 → 🟠趋势恶化预警
- 任一天风险分 > 70 → 🔴即时危险预警
- 纪律风险连续3天恶化 → 🟠心理状态预警
