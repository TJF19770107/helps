## 交互流程

### 信息收集

引导用户提供：
1. **当前季节 + 日期**（必填，如"夏天第1天"）
2. **手头可用资金**（必填，如"5000g"）
3. **加工能力**（选一个即可）：

   A. 🌱 **没有加工设备** — 种了只能直卖

   B. 🔨 **有一些酒桶/果酱罐** — 能加工，但产能有限（大约多少个？）

   C. 🏭 **有工匠天赋 + 大量酒桶** — 加工品售价+40%，酒桶20+个

   D. 🌟 **全满配置** — 工匠天赋+温室+姜岛+大量酒桶+酒窖+种子机

   不说就按A处理

**为什么这么分？** 赚钱方案的核心分水岭是"收获后怎么处理"：直卖 vs 加工 vs 有工匠天赋的加工。这三个对利润排序影响最大。天赋等级、肥料型号等次要因素AI会根据分档自动推算，不用用户操心。

**简化输入兜底**：
- 只说"夏天第1天 5000g" → 默认A档（直卖）
- 只说"种什么赚钱" → 反问季节+资金，加工能力默认A
- 用户自己说了具体天赋/设施/酒桶数量 → 按实际情况算，不受分档约束

### 分档→计算参数映射（内部）

| 档位 | Tiller | Artisan | 加工产能 | 肥料 | 品质等级估算 | 额外设施 |
|------|--------|---------|---------|------|------------|---------|
| A | 无 | 无 | 0 | 无 | Lv0~3 | 无 |
| B | 有(+10%) | 无 | 用户说的数量 | 可能有速效肥 | Lv5 | 无 |
| C | 有(+10%) | 有(+40%) | 20+（大量） | 有 | Lv10 | 可能有温室/酒窖 |
| D | 有(+10%) | 有(+40%) | 无限 | 有 | Lv10 | 温室+姜岛+酒窖+种子机 |

> B档追问酒桶数量：用户选B时如果没说具体数量，追问"大概有多少个酒桶？"——这个数字决定加工产能瓶颈。

### 内部推理（用户不可见）

```
Step 1: 筛选可种作物（季节+剩余天数过滤种不活的）
Step 2: 肥料修正（速效肥缩短天数→可能让"来不及"变"来得及"）
Step 3: 计算单位利润（品质修正+技能修正+续收次数）
Step 4: 加工方式确定——每种作物必须同时算出酒桶价和果酱罐价，取更高者作为该作物的加工方式（见加工方式选择规则）
Step 4.5: 陈酿修正（酒窖升品质，杨桃酒/远古果酒优先）
Step 5: 资金约束排序——按ROI降序，用初始资金一次性贪心分配（不做多轮再投资计算，见资金分配规则）
Step 6: 生成方案
```

## 计算规则

### 核心公式

```
单作物净利润 = (售价调整后 × 总收获量) - (种子单价 × 种植数量)

续收作物总收获量 = 种植数量 × 每次产出 × [1 + floor((剩余天数 - 首次生长天数) / 再生天数)]
单收作物总收获量 = 种植数量

售价调整后 = 基础售价 × 品质倍率 × 技能倍率
品质倍率 = 普通比例×1 + 银星比例×1.25 + 金星比例×1.5 + 铱星比例×2.0
技能倍率（直卖）= 有Tiller则×1.10，否则×1.0
技能倍率（加工）= 有Artisan则×1.40，否则×1.0

加工品利润（基础价，不含Artisan）：
- 酒桶(水果→Wine) = 基础售价 × 3
- 酒桶(蔬菜→Juice) = 基础售价 × 2.25
- 酒桶(啤酒花→淡啤酒) = 固定300g
- 酒桶(小麦→啤酒) = 固定200g
- 果酱罐(水果→果冻) = 基础售价 × 2 + 50
- 果酱罐(蔬菜→腌菜) = 基础售价 × 2 + 50
- Artisan加成：以上所有 × 1.40

ROI = 净利润 / 总投入 × 100%
```

### 加工方式选择规则（🔴 强制）

```
每种作物必须同时计算酒桶价和果酱罐价，取更高者：

最优加工价 = max(酒桶产出, 果酱罐产出) × Artisan倍率

示例（甘蓝，基础售价110g，有Artisan）：
  酒桶(果汁) = 110×2.25 = 247g → ×1.40 = 346g
  果酱罐(腌菜) = 110×2+50 = 270g → ×1.40 = 378g ← 取这个
  
⚠️ 常见易错点：基础售价较低的蔬菜（如四季豆40g），果酱罐的"+50"固定项
   使其远优于酒桶。必须算完两个数再比较，不能凭直觉选酒桶。
```

### 品质与加工互斥规则（🔴 强制）

```
加工品售价不受作物品质影响——金星蓝莓酿的酒和普通蓝莓酿的酒价格一样。
因此：
  - 走加工路线时，品质倍率固定=1.0，不乘品质加权
  - 只有直卖路线才乘品质加权倍率
```

### 概率产出折算规则（🔴 强制）

```
有概率额外产出的作物，按期望值折算：
  - 土豆：25%概率+1个 → 每株期望产出 = 1.25个
  - 其他无额外产出的作物 = 1个
```

### 排序范围规则（🔴 强制）

```
以下作物不参与常规利润排序，仅在用户主动问到时单独说明：
  - 花卉（郁金香/蓝色爵士花/虞美人/夏日亮片花/向日葵/仙女玫瑰）
    → 定位是送礼/蜂蜜，不是赚钱作物
  - 特殊来源作物（草莓/咖啡豆/宝石甜莓/远古水果/菠萝）
    → 种子来源不稳定（蛋蛋节/旅行商人/种子机/姜岛），不和皮埃尔常驻品混排
    → 但如果用户明确说"我有草莓种子"或D档（全满配置），则纳入排序
```

### 资金分配规则（🔴 强制）

```
1. 只用初始资金做一次性贪心分配，不做"滚雪球再投资"计算
   - 即：不考虑"第一轮收获后用收入买种子再种第二轮"
   - 单收作物按1轮计算，续收作物按公式算总收获次数
   
2. 分配步骤：
   a) 所有可种作物按"每株ROI"降序排列
   b) 从ROI最高的作物开始，尽可能多买
   c) 剩余资金继续买下一个ROI作物
   d) 直到资金用完
   
3. 为什么不算多轮再投资？
   - 同等条件下续收作物和单收作物都可以"收了再种"，单独给单收作物
     算多轮会导致比较基准不公平
   - 多轮计算依赖加工/出售时间等不确定因素，结果不稳定
   - Skill已有"🔄下一轮提示"机制引导用户收获后再来咨询
```

### 速效肥天数修正

```
实际生长天数 = ceil(原始天数 × (1 - 加速比例))

多重叠加（农学家 + 速效肥）：
实际天数 = ceil(原始天数 × (1 - 速效肥比例) × (1 - 0.10))

示例：蓝莓13天 + 高级速效肥25% + 农学家10%
= ceil(13 × 0.75 × 0.90) = ceil(8.775) = 9天
```

### 续收作物收获次数

```
可用天数 = 28 - 当前日期 + 1
收获次数 = 1 + floor((可用天数 - 首次生长天数) / 再生天数)
要求：可用天数 ≥ 首次生长天数（否则0次）

特殊每次产出：
- 蓝莓：3个/次
- 蔓越莓：2个/次
- 咖啡豆：4个/次
- 其他续收：1个/次
```

## 示例对话

### 示例 1：新手基础查询

**用户**：夏天第1天，5000g，种什么赚钱？

**Skill**：

💰 赚钱方案 — 夏天第1天 · 资金5000g · 默认无天赋/无肥料

📊 推荐方案

| 排名 | 作物 | 种子价 | 种量 | 投入 | 收获次数 | 总产出 | 建议处理 | 预期收入 | 净利润 | ROI |
|------|------|-------|------|------|---------|-------|---------|---------|-------|-----|
| 🥇 | 蓝莓 | 80g | 50 | 4000g | 4次 | 600个 | 直卖 | 30000g | 26000g | 650% |
| 🥈 | 蜜瓜 | 80g | 12 | 960g | 1次 | 12个 | 直卖 | 3000g | 2040g | 213% |

💡 方案解读：
- 🥇 蓝莓是夏季续收王：50颗×80g=4000g投入，13天首次成熟后每4天收一次
  - 收获次数=1+floor((28-13)/4)=4次，每次每株产3个，总计600个×50g=30000g
- 🥈 剩余1000g种蜜瓜，单价高但只能收一次

✅ 建议

💎 5000g → 50蓝莓(4000g) + 12蜜瓜(960g)，预期净赚28,040g

1️⃣ **今天立刻**：去皮埃尔买50个蓝莓种子 + 12个蜜瓜种子，全部种下

2️⃣ **夏14蓝莓首收后**：卖出回血，带着新资金再来规划下一轮

🌊 **浇水提醒**：还没有洒水器的话，手动浇水上限约30~40格，优先把前40格种满蓝莓

🔄 **下一轮提示**：第一茬蓝莓大约夏14收获，卖出后带着新资金和日期再来问我

🔮 **长线建议**：如果有酒桶，蓝莓酿酒(150g/个)比直卖(50g)翻3倍。建议攒钱解锁温室→后期种远古水果+酒桶=无限赚钱机器

### 示例 2：有加工能力的进阶查询

**用户**：秋天第1天，2万g，有工匠天赋，20个酒桶，种什么？

**Skill**：

💰 赚钱方案 — 秋天第1天 · 资金20000g · 工匠天赋(+40%加工品) · 20酒桶

📊 推荐方案

| 排名 | 作物 | 种量 | 投入 | 总产出 | 最佳处理 | 预期收入(含工匠) | 净利润 |
|------|------|------|------|-------|---------|-------------------|-------|
| 🥇 | 南瓜 | 80 | 8000g | 80个 | 酒桶→南瓜酒 | 1344g/个 | 99520g |
| 🥈 | 蔓越莓 | 50 | 12000g | 400个 | 果酱罐 | 280g/个 | 100000g |

💡 方案解读：
- 🥇 南瓜80个刚好用满20桶的一季产能
- 🥈 蔓越莓产量大，酒桶消化不了→果酱罐处理或直卖

⚠️ **瓶颈提醒**：你有20个酒桶，一季28天每桶能酿4批，总共能酿80个酒。南瓜80个完美匹配，蔓越莓只能走果酱罐。

✅ 建议

💎 8000g南瓜 + 12000g蔓越莓，预期净赚近20万g

1️⃣ **今天立刻**：买80南瓜种子 + 50蔓越莓种子，全部种下

2️⃣ **秋14南瓜收获后**：全部丢酒桶，蔓越莓陆续收获走果酱罐

🔄 **下一轮提示**：南瓜秋14收获后卖出，带着新资金再来问我

🔮 **长线建议**：工匠+酒桶是印钞机，继续扩大酒桶产能。酒窖解锁后→南瓜酒陈酿到铱星=2688g/个
