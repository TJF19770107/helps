# 限免游戏查询（喜加一速报）

查询 Steam + Epic Games Store 当前限时免费游戏和即将限免游戏。用户经常关心"现在有什么免费游戏"，这个 Skill 通过实时 API 给出准确答案，避免凭记忆回答导致信息过时。

## 工作原理

通过 Python 脚本调用公开 API 获取实时限免数据：
- **Steam 限免**：GamerPower API（主数据源）+ Steam storesearch/appdetails（补充人民币价格和中文支持）
- **Epic 当前限免**：Epic freeGamesPromotions API（discountPercentage=0 的游戏）
- **Epic 即将限免**：同一 API 的 upcomingPromotionalOffers 字段

> 为什么用 GamerPower 而不是 Steam 官方搜索接口？因为 store.steampowered.com/search/results 在国内无加速器环境下经常超时，影响体验。GamerPower 国内可直连，数据经验证与官方一致。

每款游戏返回：游戏名、原价、中文支持情况、限免起止时间、商店链接。

## 使用方式

```bash
python {SKILL_DIR}/scripts/query_free_games.py
```

脚本将格式化的纯文本结果输出到 stdout。

**可选参数：**

| 参数 | 说明 |
|------|------|
| `--steam-only` | 只查询 Steam 限免 |
| `--epic-only` | 只查询 Epic 限免 |

无参数时查询所有平台。

**依赖**：脚本需要 `requests` 库。如果报 `ModuleNotFoundError`，先执行 `pip install -r {SKILL_DIR}/scripts/requirements.txt`。

## 展示润色

脚本输出的是结构化纯数据。直接贴给用户可读性差，润色后体验好很多。以下是润色要点：

### 游戏名加中文译名

对知名游戏，在英文名后加中文译名，帮助用户快速识别：`【Graveyard Keeper】 — 守墓人`。不确定的不加，不要编造。

### 每款游戏加推荐语

在每款游戏末尾加一句简短推荐语，涵盖游戏类型/玩法、中文支持、值不值得领。这能帮用户快速决策，而不是自己去搜。

**Example:**
```
🎯 推荐：像素风经营模拟游戏，类似"星露谷物语"但你经营的是一座墓地。支持中文，原价76块，值得领。
```

### 快速总结表格

所有游戏列完后加一个汇总表格，方便用户一眼看全。列：平台、游戏、原价、中文、截止、建议。

**Example:**
```
💡 快速总结
| 平台 | 游戏 | 原价 | 中文 | 截止 | 建议 |
|------|------|------|------|------|------|
| 🔵 Steam | Graveyard Keeper | ¥76 | ✅ | 4/13 | ⭐ 必领 |
| 🟣 Epic | TOMAK | ¥28 | ❌ | 4/16 | 白嫖不亏 |
```

### 建议标签规则

| 条件 | 建议标签 |
|------|---------|
| 原价 ≥ ¥60 且支持中文 | ⭐ 必领 |
| 原价 ≥ ¥60 但不支持中文 | 值得领 |
| 原价 < ¥60 | 白嫖不亏 |
| 即将限免（还没开始） | 记得回来领 |

### 截止时间口语化

用户最怕错过限免截止。在日期旁加口语化提示能制造紧迫感：
- 不到 1 天：`（最后几小时，速领！）`
- 1~3 天：`（还剩不到X天，抓紧！）`
- 3~7 天：`（还有X天）`

### 末尾总结语

用 1~2 句话总结最值得领的游戏，给用户明确行动指引。用户读完就知道该先领哪个。

**Example:**
```
最值得领的是 Steam 的《守墓人》，支持中文、原价76，而且只剩不到3天截止了。Epic 那两款虽然不支持中文，但反正免费，顺手领了不亏。
```

## 注意事项

- GamerPower 和 Epic API 均国内可直连，无需加速器
- Steam appdetails 偶尔超时不影响主流程（会降级显示美元价格）
- Epic "即将限免"通常是下周预告，提前展示有参考价值
- 脚本报错或无输出时，告知用户"网络可能不稳定，请稍后重试"，不要编造游戏数据
