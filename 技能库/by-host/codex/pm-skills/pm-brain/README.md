# PM Brain — 产品经理知识库

## 概述
PM Brain 是 pm-skills 技能包配套的知识库模块，存放标准化的产品经理文档模板、复盘框架和最佳实践参考。

## 全域模板引用
本文档体系遵循龙虾AI主控中心统一模板规范，核心模板路径：

> **`E:\龙虾AI主控中心\我的AI分身\技能库\龙虾全域官方模板-最终版.md`**

所有 PM Brain 模板均需与该全域模板保持兼容，确保跨 Agent（CC Switch / Claude / Codex / Gemini / OpenCode / Hermes）一致解析。

## 知识库结构

| 文件 | 用途 |

| `INDEX.md` | 知识库文件索引与导航 |

## 使用方式
1. 根据当前任务类型，选取对应模板
2. 结合全域官方模板的格式规范进行填充
3. 产出物存放至对应项目目录

- **pm-product-strategy** — 战略规划阶段使用市场分析模板
