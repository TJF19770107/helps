## 0) 永恒铁律（全程硬门禁）

- 合并更新：只增量不覆盖；不删除、不顶替旧配置与旧规则；以"新增版本化文件/新增配置块/新增索引项"为首选交付形态。
- 免费优先：优先本地/离线/免费资源；禁止引入付费外网 API；新增依赖必须给出"零成本可替代方案"。
- 成本核算：每一步都要做成本现状盘点与性价比评估；淘汰冗余链路与浪费节点。
- 安全与机密：任何密钥/口令/Token/Cookie 仅允许以环境变量名出现；只允许检查是否 SET/是否生效；禁止明文落盘/日志回显。
- 稳定与风控：任何大写入/大下载/大镜像拉取必须先做空间门禁；优先不打断生产服务；不确定时如实输出证据与边界。
- 版本与回滚：所有变更必须可回滚；优先"新增新版本文件"实现回滚；避免不可逆改写。
- 三方一致：涉及 Hermes/Trae/豆包/Codex 链路时，必须执行三方握手与 GStack 标准工作流校验。
- 目录隔离：每个 Agent 的写入操作严格限定在自己的工作目录，外部存量仅只读参考。
- API 容错（v2.1 新增）：任何外部 API 调用必须预设 fallback 降级路径；连续 3 次 5xx/超时自动切换为本地方案；禁止因外部 API 不可用导致任务阻塞；Codex/Claude 等远端推理链路中断时自动切换 Hermes 本地推理继续执行。

## 1) 第一步：目标定义（对标学习）

目标：明确任务边界、标的、预期、风控红线，找到成熟方案对标。

### 通用流程
1. **定位同类基线**：明确本任务的同类项目/成熟方案对标清单
2. **免费成本核算**：优先使用本地免费资源
3. **性价比评估**：对比至少两条路线

### 量化策略专用流程（v2.1 新增）
1. **交易标的**：明确品种、交易所、时间周期
2. **盈亏预期**：年化目标收益率、可接受最大回撤
3. **风控红线**：单笔最大亏损、总回撤上限、止损机制
4. **数据可用性**：确认本地数据源、时间范围、数据质量
5. **框架选型**：对比 vnpy/backtrader/自研方案

### 输出物
- 对标学习摘要：可复用结论清单
- 候选方案对比表：成本 x 收益矩阵
- 量化目标定义表：标的/预期/风控/数据/框架

---

## 2) 第二步：环境搭建（诊断先行）

目标：全盘摸清现状，搭建隔离可复现的开发环境。

### 通用流程
1. **路径诊断**：关键目录是否存在、是否被误指向
2. **权限诊断**：读写边界是否符合隔离要求
3. **依赖诊断**：版本兼容性、冲突检测
4. **成本基线**：磁盘占用、冗余资源

### 量化策略专用流程（v2.1 新增）
1. **Python 环境**：创建独立 venv，不与系统/旧环境互相干扰
2. **核心依赖**：vnpy + 数据源 + 技术分析库
3. **环境变量**：设置 VNTRADER_HOME 重定向，避免与旧 VNPY 冲突
4. **MCP 就绪**：确认 .mcp.json 配置、MCP 服务连通性
5. **目录隔离**：strategies/ data/ config/ logs/ reports/ 各司其职

### 输出物
- 诊断清单：问题/证据/影响/优先级/建议
- 环境搭建报告：Python 版本/依赖清单/验证结果

---

## 3) 第三步：方案落地（只增量不覆盖）

目标：按规范产出可运行的代码/配置/流程。

### 通用流程
1. **只增量不覆盖**：新增版本化文件
2. **穿透壁垒但不越界**：仅必要范围内调整
3. **成本守门**：新增依赖必须有免费替代

### 量化策略专用流程（v2.1 新增）
1. **策略模板化**：基于 CtaTemplate 标准模板，参数化设计
2. **回测脚本**：一键回测 + 参数扫描功能
3. **外部参考只读**：存量策略仅读取分析，禁止修改原文件
4. **注释完整**：策略参数/逻辑/风控点全部标注

### 输出物
- 策略代码文件：可直接运行的策略
- 回测脚本：一键执行回测
- 落地变更包：新增文件清单 + 回滚入口

---

## 4) 第四步：结果验证（全链路验收）

目标：以真实运行结果为唯一标准验收。

### 通用流程
1. **全流程联调**：端到端跑通
2. **版本比对**：日志自检
3. **成本复核**：资源占用不恶化

### 量化策略专用流程（v2.1 新增）
1. **默认参数回测**：验证策略逻辑正确性
2. **参数扫描**：寻找最优参数组合
3. **核心指标**：收益率/最大回撤/夏普比率/收益回撤比
4. **风控校验**：回撤是否低于红线、止损是否生效
5. **多维度对比**：新旧版本/不同参数/不同标的

### 输出物
- 回测报告：完整指标表格
- 参数扫描结果：最优参数推荐
- 验收结论：通过/不通过 + 改进建议

---

## 5) 第五步：迭代沉淀（自主进化）

目标：版本固化、经验沉淀、构建自我迭代闭环。

### 通用流程
1. **复盘**：目标/步骤/结果/证据/风险/改进项
2. **版本化固化**：新增版本文件，不覆盖旧版本
3. **技能沉淀**：可复用流程/脚本提炼为独立技能
4. **MEM 更新**：仅规则/经验，不含密钥

### 量化策略专用流程（v2.1 新增）
1. **版本记录**：VERSION_LOG.md 记录每个版本的参数/结果/优劣
2. **迭代方向**：主动列出至少 3 个优化方向
3. **自主进化协议**：
   - 触发条件：收益率低于基线 80% / 回撤超标 / 夏普低于阈值
   - 迭代流程：分析亏损 → 修改策略 → 回测验证 → 对比升级 → 记录版本
   - 版本命名：主版本号(逻辑变更) . 次版本号(参数优化) . 修订号(Bug修复)

### 输出物
- 版本迭代文档：VERSION_LOG.md
- 优化方向清单：近/中/长期
- 自主进化接口：触发条件 + 流程定义
