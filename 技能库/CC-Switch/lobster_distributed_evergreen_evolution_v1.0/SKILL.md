# 全局分布式龙虾永续进化（合规版）

本技能用于在「三方平等发起」前提下，统一把任务拆解、证据留存、可回滚、可复用沉淀与跨端广播串成一条可执行链路；严格遵守共享技能库、密钥安全与迭代红线等全局规则。

## 重要边界（硬约束）

- 不提供“开启全部权限”“不可篡改永久记忆”“后台无限静默自迭代”这类超出系统与规则边界的承诺
- 不落盘、不输出任何密钥明文；仅允许引用环境变量名或别名
- 不擅自修改全局规则正文；如需变更，仅输出“差异建议”供用户人工更新
- 不进行大写入/大下载；需要时先做空间门禁与风险说明

## 对等分布式共振口径（解释）

- 三方对等：Trae/Hermes/豆包任意一方都可发起、拆解、执行与回流，不固化中心与岗位
- 强者临时主导：以任务证据与验收为准，谁能闭环交付谁临时主导该任务的调度
- 全节点存储：以“共享技能库 + 归档产物 + 可审计索引”为同源口径；不承诺单节点永久持有全量数据副本
- 共振账本：以脱敏摘要为账本内容（新增/变更项、验收口径、回滚点、影响面），避免同步敏感值与冗余大文件

## “强执行”口径（解释）

- 禁止无意义试探与反复确认：默认采用最小合理假设直接推进
- 保留安全小步验证：内部仍按可验证、可回滚的小步拆解执行，避免“不可控的大步强推”

## 适用场景（触发条件）

- 用户要求：三方共振、全网广播、跨端同步、经验/技能增量合并
- 用户要求：每日05:00复盘产出、沉淀可复用技能、更新索引并回流
- 用户要求：对标 OpenClaw/龙虾体系做阶段性复刻、对齐标准、补齐短板

## 输入（建议提供）

- 同步范围：skills（技能索引/技能文档） / knowledge（知识归档） / logs（脱敏证据）
- 同步策略：仅索引 / 索引+产物 / 仅差异建议
- 广播对象：Trae / Hermes / 豆包（可多选）
- 安全门禁：是否要求双重鉴权（HERMES_API_TOKEN + HERMES_LOCAL_KEY）

## 输出（必须交付）

- 一份中文闭环回执：目标 → 步骤 → 结果 → 证据 → 风险 → 回滚点 → 后续动作
- 一条可复用的“最小执行单元”：脚本/配置模板/排障清单（三选一，按需求）
- 一条可广播的增量摘要：新增/变更项列表 + 兼容性说明 + 验收口径

## 执行流程（固定五步，按任务标准工作流）

1. 对齐全局规则与资源红线：确认本次目标、范围、鉴权门禁与写入边界
2. 逆向拆解为可验证小步：每一步都有验收口径与可回滚点
3. 严守执行边界：不泄密、不盲写、不盲删、不虚报；失败给出根因与证据
4. 收尾复盘固化：沉淀复用产物，更新索引（合并更新），清理临时文件
5. 成本管控：优先本地/免费链路，减少重复调用与无效输出

## 常驻运行（实现建议）

- 本技能本身不在后台“无限自迭代”常驻运行；如需定时自检/复盘，使用系统计划任务或容器调度器触发执行
- 推荐触发点：每日固定复盘（如05:00）、关键修复完成、跨端同步完成、关键告警恢复

## 验收口径（通用）

- 产物可被独立复用：在同等环境下可重复执行或复现结论
- 证据可审计且脱敏：仅包含变量名、状态码、路径与摘要，不包含敏感值
- 可回滚：明确说明“撤销/回退”步骤或不变更系统状态
