## 一、概述

飞书CLI（lark-cli）是飞书官方开源的命令行工具（2026-03-28发布v1.0.0），为AI Agent提供操作飞书的标准化执行入口。Codex通过集成飞书CLI，实现自然语言驱动飞书数据与业务流程的自动化。

**核心价值**：补上Agent从"理解"到"执行"的关键一环——AI不再是"给建议的工具"，而是"能直接操控办公系统的数字员工"。

## 二、安装与配置 SOP

### 2.1 三步安装法

```
# 第一步：安装CLI
npm install -g @larksuite/cli

# 第二步：安装AI Skills
npx skills add larksuite/cli -y -g

# 第三步：初始化配置
lark-cli config init --new
```

### 2.2 授权流程

```
# 用户身份模式（推荐，可访问个人数据）
lark-cli auth login --recommend

# 不授权模式（基础操作，无法访问个人日历/私信/邮箱）
lark-cli config set --auth-mode none
```

授权完成后浏览器扫码确认，选择"仅个人使用"以控制权限范围。

### 2.3 验证安装

```
lark-cli auth status
# 预期输出：已登录 + 有可用的 skills
```

**关键注意事项**：配置完成后必须重启Codex终端，否则无法加载新技能。

## 三、三层命令体系

飞书CLI设计了专门针对AI Agent的调用结构：

| 层级 | 前缀 | 说明 | 适用场景 |
|:---:|------|------|------|
| L1 快捷命令 | `+` 前缀 | 智能默认值，日常够用 | `lark-cli +agenda` 查今日日程 |
| L2 API命令 | 无 | 100+条命令，对应飞书开放接口 | `lark-cli im +messages-search` |
| L3 Raw API | `api` | 直接调用飞书全部2500+API | 高级自定义操作 |

**AI Agent默认使用L2层级**，仅在需要深入操作时降级到L3。

## 四、11大业务域核心命令

### 4.1 消息与群组（lark-im）

```
# 搜索聊天记录
lark-cli im +messages-search --query "关键词" --page-size 10 --format pretty

# 发消息到指定群
lark-cli im +messages-send --chat-id "群ID" --text "内容"

# 重要操作预览
lark-cli im +messages-send --chat-id "群ID" --text "内容" --dry-run
```

### 4.2 云文档（lark-doc）

```
# 创建文档
lark-cli docs +create --title "标题" --markdown "内容"

# 读取文档
lark-cli docs +get --doc-id "文档ID" --format markdown

# 更新文档
lark-cli docs +update --doc-id "文档ID" --markdown "新内容"
```

### 4.3 日历（lark-calendar）

```
# 查今日日程
lark-cli calendar +agenda --format pretty

# 创建事件
lark-cli calendar +create-event --summary "会议名" --start "2026-06-12T10:00" --end "2026-06-12T11:00"

# 查忙闲
lark-cli calendar +freebusy --user-id "用户ID"
```

### 4.4 邮件（lark-mail）

```
# 搜未读邮件
lark-cli mail +search --unread --format pretty

# 发邮件
lark-cli mail +send --to "收件人" --subject "主题" --body "内容"

# 读邮件
lark-cli mail +get --mail-id "邮件ID"
```

### 4.5 电子表格（lark-sheets）

```
# 读取单元格
lark-cli sheets +read --spreadsheet-id "表格ID" --range "A1:D10" --format table

# 写入数据
lark-cli sheets +write --spreadsheet-id "表格ID" --range "A1" --data [["值1","值2"]]
```

### 4.6 多维表格（lark-base）

```
# 查询记录
lark-cli base records list --table-id "表格ID" --format table

# 新增记录
lark-cli base records create --table-id "表格ID" --data '[{"字段1":"值1"}]'

# 聚合分析
lark-cli base +aggregate --table-id "表格ID" --field "金额" --group-by "部门"
```

### 4.7 任务（lark-task）

```
# 查未完成任务
lark-cli task +list --status incomplete --format pretty

# 创建任务
lark-cli task +create --title "任务名" --due "2026-06-15" --assignee "用户ID"
```

### 4.8 知识库（lark-wiki）

```
# 浏览节点
lark-cli wiki +browse --space-id "空间ID"

# 创建文档
lark-cli wiki +create --space-id "空间ID" --title "标题" --parent-id "父节点ID"
```

### 4.9 通讯录（lark-contact）

```
# 搜同事
lark-cli contact +search --query "姓名"

# 查部门
lark-cli contact +department --name "部门名"
```

### 4.10 视频会议（lark-vc）

```
# 搜索会议
lark-cli vc +search --query "会议名"

# 获取纪要
lark-cli vc +minutes --meeting-id "会议ID"

# 获取逐字稿
lark-cli vc +transcript --meeting-id "会议ID"
```

### 4.11 搜索（lark-search）

```
# 跨业务域搜索
lark-cli search +all --query "关键词" --types "message,document,calendar"
```

## 六、权限与安全边界

### 6.1 两种权限模式

| 模式 | 能力范围 | 适用场景 |
|------|------|------|
| 不授权 | 发消息、创建文档等基础操作 | 群组通知、公共文档 |
| 用户身份 | 访问日历、私信、邮箱、个人数据 | 个人工作流、自动化 |

### 6.2 安全红线

- 严禁在公开文章/截图/代码中暴露：`chat_id`、`open_id`、`token`、`app_secret`
- 敏感操作前使用 `--dry-run` 预览
- 批量操作设定 `--page-size` 上限
- 授权链接仅在浏览器完成，不通过第三方工具传输

## 七、典型自动化场景

### 7.1 会后自动执行（Wake Word）

**场景**：会议中说"龙虾龙虾，帮我把这个方案整理成文档发给老板"
**实现**：Agent从妙记逐字稿中识别Wake Word指令 → 提取为最高优先级待办 → 自动执行

```
lark-cli vc +transcript --meeting-id "会议ID" | grep "龙虾龙虾"
lark-cli docs +create --title "会议方案整理" --markdown "提取的方案内容"
lark-cli im +messages-send --chat-id "老板群ID" --text "方案已整理完成，文档链接如下"
```

### 7.2 每日SEO/GEO检查提醒

**场景**：每天飞书自动提醒检查博客SEO/GEO状态

```
lark-cli task +create --title "SEO/GEO每日检查" --desc "
1. Google/Bing索引状态
2. 搜索词和点击变化
3. AI搜索是否引用品牌
4. 主站文章标题/摘要/外链
5. 矩阵内容新增入口
"
```

### 7.3 周报自动生成

**场景**：每周五自动汇总飞书文档/任务/邮件生成周报

```
lark-cli task +list --status completed --since "2026-06-09"
lark-cli mail +search --since "2026-06-09" --format summary
lark-cli docs +create --title "周报-20260612" --markdown "汇总数据"
```

### 7.4 多维表格自动化

**场景**：项目进度自动追踪

```
lark-cli base records create --table-id "项目追踪表ID" --data '{"任务名":"Codex集成","状态":"进行中","截止日期":"2026-06-15"}'
lark-cli base records list --table-id "项目追踪表ID" --filter "状态=进行中" --format table
```

### 7.5 会议智能纪要分发

```
lark-cli vc +minutes --meeting-id "会议ID" --format markdown
lark-cli docs +create --title "会议纪要-20260612" --markdown "纪要内容"
lark-cli im +messages-send --chat-id "项目群ID" --text "会议纪要已生成：[链接]"
lark-cli mail +send --to "参会人员" --subject "会议纪要" --body "请查收会议纪要 [链接]"
```

## 八、错误处理与排查

| 错误现象 | 原因 | 解决方案 |
|------|------|------|
| CLI命令无响应 | 未重启Codex | `exit`退出后重新进入 |
| 权限不足 | 未完成用户授权 | `lark-cli auth login --recommend` |
| Skills未加载 | 安装后未重启 | 重启AI Agent工具 |
| 授权链接过期 | 链接有时效性 | 重新执行 `lark-cli auth login` |
| 文档ID找不到 | 需先查文件夹结构 | `lark-cli wiki +browse` 浏览目录 |
| 输出格式混乱 | 未指定format | 添加`--format pretty` 或 `--format table` |
