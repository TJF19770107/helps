# 1. 文献检索（自研）

## 用途
零积分获取真实学术文献，产出可核验的文献清单/矩阵。**只负责找到并核实，不写正文。**

## 触发指令
```
文献检索：大模型在高等教育质量保障中的应用
文献矩阵：近五年 元分析 在线学习成效
```

## 执行步骤
1. **先跑脚本**（零积分，必做）：
   ```bash
   G:/g_venv_ars/Scripts/python.exe scripts/lobster_lit_search.py --source all --q "英文关键词" --limit 20 --out refs.json
   ```
   中文课题中英双语各跑一次。API 已实测直连可达（arXiv/CrossRef/OpenAlex/S2，无密钥）。
2. **粗筛**：近 5–10 年、同行评审优先
3. **证据定级**：循证金字塔（系统综述/Meta分析 > RCT > 队列 > 横断面 > 专家观点）；预印本标注「未经同行评审」
4. **成表**：作者/年份/方法/样本/结论/局限 六列文献矩阵
5. **核验**：抽查 ≥20% 条目，人工打开 DOI 确认标题作者一致
