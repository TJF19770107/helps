## 一、技能概述

豆包Agent是一个具备6大核心能力的自主AI Agent，运行于本地文件系统，能够自主读取本地文件、生成新技能、控制桌面程序、自我唤醒、维护长期记忆并进行自我修正。本技能文件将豆包Agent的核心工作流程提炼为可复用、可迁移的独立技能模块。

## 二、六大核心能力

### C01: 本地文件自主读取 (Local File Reader)

**目标**: 自主读取和解析本地文件系统中的各类文件。

**核心能力**:
- 支持纯文本文件 (.py / .md / .json / .yaml / .txt / .csv / .log)
- 支持复杂文档 (.pdf / .doc / .docx / .ppt / .pptx / .xls / .xlsx)
- 分页读取与续读机制 (offset + limit)
- Excel多Sheet支持与复杂表解析

**执行流程**:
1. 识别文件类型 → 路由到正确的读取工具 (read_text / read_file)
2. 纯文本文件 → read_text 工具
3. 复杂文档 → read_file 工具
4. 内容截断 → 使用 next_offset 续读
5. 汇总分析 → 基于完整内容输出结论

**安全约束**: 禁止读取 .git / .ssh / .aws / .kube / .env 等敏感配置

### C05: 长期记忆系统 (Long-term Memory / Persistent Memory)

**目标**: 维护Agent的执行经验、用户偏好和知识图谱。

**执行流程**:
1. 任务开始时加载相关记忆
2. 执行中记录关键决策和结果
3. 任务结束时持久化新经验
4. 周期性记忆整理与去重

### C06: 自我修正与安全回滚 (Self-Healing Rollback)

**目标**: 检测异常、自动修复并在必要时回滚到稳定检查点。

**核心能力**:
- 操作结果验证与异常检测
- 多级回滚检查点管理
- 双协议安全自进化回滚 (Protocol 187)
- 技能生命周期管理

**执行流程**:
1. 每次关键操作后验证结果
2. 检测到异常 → 自动诊断
3. 可修复 → 执行修正流程
4. 不可修复 → 回滚到最近稳定检查点
5. 记录回滚日志供后续分析
