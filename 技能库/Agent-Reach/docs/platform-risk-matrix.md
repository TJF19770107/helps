## 三、高危平台详情

### 3.1 小红书（🔴 极高风险）

```
风险级别: 🔴 极高
反爬技术: DataDome + 自研 AI 行为分析 + 设备指纹 + 浏览器指纹
风控特点:
  - 严格的请求频率检测（3秒内超过1次即触发）
  - 设备指纹绑定（同一设备多账号会被关联）
  - 行为模式分析（非人类操作模式秒识别）
  - IP 信誉系统（代理 IP 高风险）
配置要求:
  - 必须使用养号 ≥30 天的专用小号 Cookie
  - 请求间隔 ≥5 秒，叠加 1-3 秒随机抖动
  - 模拟真实浏览路径（搜索结果→列表→详情）
  - 被封后同一设备/网络不能再登录
兜底方案: 被封后直接降级 Playwright 无头浏览器 + 正常用户行为模拟
```

### 3.2 抖音（🔴 极高风险）

```
风险级别: 🔴 极高
反爬技术: 字节跳动自研风控系统 + 全链路反爬
风控特点:
  - Cookie 有效期极短（通常数小时）
  - 请求签名机制（X-Bogus / MS_TOKEN）
  - 设备注册机制（device_id 绑定）
  - 行为轨迹分析
配置要求:
  - Cookie 需每日更新
  - 请求间隔 ≥4 秒
  - 尽量使用移动端 API（pc 端反爬更强）
兜底方案: Cookie 过期后通知用户手动更新，或降级 Playwright
```

### 3.3 Twitter/X（🟠 高风险）

```
风险级别: 🟠 高
反爬技术: Cloudflare + Twitter 自研速率限制
风控特点:
  - API 有严格的 Rate Limit（读 150 次/15min 用户级）
  - 登录态检测频率高
  - IP 信誉系统
配置要求:
  - 专用小号 Cookie + auth_token
  - 请求间隔 ≥5 秒
兜底方案: 公开推文可用 Nitter 等第三方前端代替
```

## 五、风险应对速查卡

| 遇到的情况 | 应对措施 |
|------------|----------|
| 突然返回 403 | 立即停止，检查 Cookie，等待 24 小时 |
| 返回 Captcha 页面 | 停止该平台，降级 Playwright |
| 返回 429 | 退避 5 分钟，降低请求频率 |
| Cookie 失效 | 通知用户更新，降级至无需Cookie的替代方案 |
| IP 被封锁 | 切换代理节点 |
| 账号被限制 | 换用备用小号，原号冷却 7 天 |
