```

  → 记录错误日志 → 重试当前步骤（最多2次）→ 仍失败则暂停并通知用户

L2 中度异常（版本号不一致/MD5冲突）：
  → 暂停六步流程 → 生成异常报告 → 垂询用户决策（强制确认/忽略/手动修复）

L3 重度异常（核心文件损坏/生态对齐失效）：
  → 立即暂停所有Agent自进化操作 → 回滚至上一轮可用配置 → 通知用户手动介入
```
