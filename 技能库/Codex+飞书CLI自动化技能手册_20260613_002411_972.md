## 一、飞书CLI概述

飞书于2026年3月底正式开源CLI工具（`@larksuite/cli`），MIT许可证，将飞书12大业务域打包为命令行接口，使AI Agent可以直接操作飞书办公系统。GitHub星标首月破万，版本迭代至v1.0.41+。

### 1.1 核心定位

```
用户自然语言 → AI Agent → 飞书CLI → 飞书开放平台 → 飞书办公系统
```

**不再是生成建议让人复制粘贴，而是AI直接在飞书里完成操作。**

### 1.2 12大业务域覆盖

| 业务域 | 能力 | Agent Skill名称 |
|--------|------|-----------------|
| 即时通讯 | 搜索消息/群聊、发送消息/图片/文件、回复话题、管理成员、表情回应 | `lark-im` |
| 云文档 | 创建/读取/更新/搜索文档、插入图片附件、Markdown导入 | `lark-doc` |
| 云空间 | 上传下载文件、整理目录、管理权限、处理评论 | `lark-drive` |
| 电子表格 | 创建/读写/批量追加/查找替换/筛选/导出 | `lark-sheets` |
| 多维表格 | 管理数据表/字段/记录/视图/表单/仪表盘/自动化 | `lark-base` |
| 日历 | 查日程/约会议/查忙闲/推荐时间/预定会议室 | `lark-calendar` |
| 视频会议 | 搜索会议/获取纪要/逐字稿/关联日程文档 | `lark-meeting` |
| 邮箱 | 搜索/读取/起草/发送/回复/转发/归档邮件 | `lark-mail` |
| 任务 | 创建/更新/拆分子任务/管理清单/协作成员 | `lark-task` |
| 知识库 | 查询空间/管理成员/管理节点和文档层级 | `lark-wiki` |
| 通讯录 | 查询用户/搜索同事/查看部门 | `lark-contact` |
| 妙记 | 搜索妙记/下载音视频/获取总结待办章节 | `lark-minutes` |

| OKR | 查看周期/管理目标/关键结果/对齐关系 | `lark-okr` |

## 二、Codex CLI 接入飞书

### 2.1 安装飞书CLI

#### 方式一：手动安装（推荐Trae用户）

```bash
# 安装
npm install -g @larksuite/cli

# 验证
lark-cli --version
# 期望输出: lark-cli version 1.0.41+
```

#### 方式二：AI Agent自动安装

将以下指令发送给Codex/Claude Code/Trae/Cursor：

```
帮我安装飞书 CLI: https://open.feishu.cn/document/no_class/mcp-archive/feishu-cli-installation-guide.md
```

### 2.2 初始化与授权

```bash
# 步骤1：初始化配置（飞书版）
lark-cli config init --new --brand feishu --lang zh

# 步骤2：登录推荐权限（安全第一：最小权限原则）
lark-cli auth login --recommend

# 步骤3：验证登录状态
lark-cli auth status --verify
# 期望输出: verified: true + 飞书用户名
```

### 2.3 安装Agent Skills

```bash
# 安装飞书CLI的Agent Skills（让Codex自动识别飞书操作）
npx skills add https://github.com/larksuite/cli -y -g

# 重启Codex使Skills生效
```

### 2.4 为特定业务域单独授权

```bash
lark-cli auth login --domain calendar --domain im --domain docs --domain base
```

## 三、核心命令速查

### 3.1 三层命令架构

| 层级 | 格式 | 特点 | 示例 |
|------|------|------|------|
| 快捷命令 | `+` 前缀 | 友好智能默认值、格式化输出 | `lark-cli calendar +agenda` |
| API命令 | 100+端点 | 映射飞书开放平台API | `lark-cli im messages list` |
| 原生API | 2500+ APIs | 直接调用全部飞书API | `lark-cli api GET /open-apis/calendar/v4/calendars` |

### 3.2 即时通讯

```bash
# 查看身份
lark-cli whoami

# 搜索消息
lark-cli im +search --query "关键词" --as user

# 发送文字消息
lark-cli im +send --chat-id "oc_xxx" --text "消息内容"

# 发送图片/文件
lark-cli im +send --chat-id "oc_xxx" --image "/path/to/image.png"
lark-cli im +send --chat-id "oc_xxx" --file "/path/to/file.pdf"

# 创建群组
lark-cli im +create-group --name "项目讨论组" --user-ids "ou_xxx,ou_yyy"

# 添加群成员
lark-cli im +add-members --chat-id "oc_xxx" --user-ids "ou_xxx"
```

### 3.3 云文档

```bash
# 创建文档（Markdown内容）
lark-cli doc +create --title "周报2026-06-13" --folder "folder_xxx" --text "# 本周工作总结\n\n..."

# 搜索文档
lark-cli doc +search --query "关键词" --as user

# 读取文档内容
lark-cli doc +read --doc-id "doc_xxx"

# 更新文档
lark-cli doc +update --doc-id "doc_xxx" --text "追加内容"
```

### 3.4 多维表格

```bash
# 创建表格
lark-cli base +create --name "项目跟踪表"

# 添加记录
lark-cli base +add-record --table-id "tbl_xxx" --fields '{"名称":"任务A","状态":"进行中"}'

# 查询记录
lark-cli base +list-records --table-id "tbl_xxx" --filter '状态 = "完成"'

# 批量追加
lark-cli base +batch-add --table-id "tbl_xxx" --data '[{"名称":"A"},{"名称":"B"}]'
```

### 3.5 日历与会议

```bash
# 查看今日日程
lark-cli calendar +agenda --as user

# 创建日程事件
lark-cli calendar +create --summary "项目评审" --start "2026-06-13T10:00:00+08:00" --end "2026-06-13T11:00:00+08:00"

# 查询成员忙闲
lark-cli calendar +freebusy --user-ids "ou_xxx,ou_yyy" --start "2026-06-13T09:00:00+08:00" --end "2026-06-13T18:00:00+08:00"

# 推荐空闲时段
lark-cli calendar +suggestion --user-ids "ou_xxx,ou_yyy" --duration 60
```

### 3.6 任务管理

```bash
# 创建任务
lark-cli task +create --title "审查PR #42" --due "2026-06-14T18:00:00+08:00"

# 更新任务状态
lark-cli task +update --task-id "task_xxx" --status "completed"

# 创建子任务
lark-cli task +add-subtask --task-id "task_xxx" --title "子任务A"
```

### 3.7 邮箱

```bash
# 搜索邮件
lark-cli mail +search --query "发票" --as user

# 发送邮件
lark-cli mail +send --to "user@example.com" --subject "会议纪要" --body "## 会议纪要\n..."

# 读取收件箱
lark-cli mail +inbox --limit 10 --as user
```

### 3.8 知识库

```bash
# 列出知识库节点
lark-cli wiki +list-nodes --space-id "space_xxx"

# 创建文档
lark-cli wiki +create-doc --space-id "space_xxx" --parent-id "node_xxx" --title "新文章"

# 搜索知识库
lark-cli wiki +search --query "关键词"
```

## 四、Codex + 飞书CLI 实战场景

### 4.1 场景一：每日工作提醒自动化

**需求**：每天固定时间通过飞书推送待办事项到个人消息。

```
Codex提示词：
"帮我在飞书里设置每日提醒：每天早上9点，检查今日日历安排、待办任务，
并将摘要通过飞书消息发送给我自己。使用飞书CLI完成配置。"
```

Codex执行路径：
1. 调用 `lark-cli calendar +agenda --as user` 获取今日日程
2. 调用 `lark-cli task +list --as user` 获取待办任务
3. 组装提醒文本
4. 调用 `lark-cli im +send` 发送给自己

### 4.2 场景二：会议纪要自动生成与分发

**需求**：会议结束后自动获取妙记录音，生成结构化纪要，发送给参会者。

```
Codex提示词：
"帮我从昨天的项目同步会妙记中提取待办事项，
为每位负责人创建飞书任务，并发送提醒消息。"
```

Codex执行路径：
1. `lark-cli meeting +search --query "项目同步会"` 找到会议
2. `lark-cli meeting +minutes --meeting-id "xxx"` 获取纪要
3. 解析待办事项 → 分配负责人
4. `lark-cli task +create --title "..." --assignee "ou_xxx"` 创建任务
5. `lark-cli im +send` 通知各负责人

### 4.3 场景三：文档发布流水线

**需求**：本地Markdown文件一键发布到飞书知识库指定目录。

```
Codex提示词：
"将本地《RAG技术详解.md》发布到飞书知识库「AI通识」目录下，
创建飞书云文档，设置阅读权限为空间成员可见。"
```

Codex执行路径：
1. 读取本地文件内容
2. `lark-cli wiki +list-nodes --space-id "xxx"` 定位目标目录
3. `lark-cli wiki +create-doc --title "RAG技术详解" --parent-id "node_xxx"` 创建文档
4. 返回飞书文档链接

### 4.4 场景四：跨时区智能排期

**需求**：分析多参会者日历和时区，找到最佳会议时间。

```
Codex提示词：
"帮我安排下周的项目评审会，参会者：张三、李四、王五，
时长1小时，避开午餐时段，优先选择所有人空闲的时段。"
```

Codex执行路径：
1. 查询各成员open_id
2. `lark-cli calendar +freebusy` 获取忙闲状态
3. `lark-cli calendar +suggestion` 推荐时段
4. `lark-cli calendar +create` 创建会议并自动发送邀请

### 4.5 场景五：多维表格数据批量操作

**需求**：从外部数据源批量导入到飞书多维表格。

```
Codex提示词：
"将project_tasks.csv中的数据导入飞书多维表格「项目跟踪」，
自动匹配字段对应关系，重复记录跳过。"
```

Codex执行路径：
1. 读取CSV文件
2. `lark-cli base +list-tables` 确认目标表
3. 字段映射分析
4. `lark-cli base +batch-add` 批量导入
5. 返回导入统计（成功/跳过/失败）

## 五、Codex + 飞书 远程桥接方案

### 5.1 Lark Coding Agent Bridge

飞书官方社区成员Zara开发的桥接工具，将Codex/Claude Code接入飞书成为Bot。

```bash
# 一键启动
npx -y lark-channel-bridge@latest start
```

**核心能力**：
- 在手机端与Codex对话
- 群聊中@机器人发起Codex任务
- 飞书卡片交互式操作
- 多Session管理
- 聊天记录永久保存

### 5.2 cc-connect方案

通过长连接将飞书消息直接写入本地Codex终端。

```
架构：飞书消息 → 飞书机器人 → cc-connect → 本地Codex CLI → 本地工作区 → 回复飞书
```

**两种模式**：
- **tui模式**：保持Codex会话上下文连续，体验等同于坐在电脑前
- **exec模式**：一问一答，输出更干净

### 5.3 安全边界（极其重要）

| 场景类型 | 推荐程度 | 说明 |
|----------|---------|------|
| 私聊提醒 | 优先推荐 | 最低风险起点 |
| 个人待办 | 推荐 | 不涉及他人数据 |
| 固定检查清单 | 推荐 | 结果可验证 |
| 只读查询 | 推荐 | 无写入风险 |
| 写入/删除操作 | 谨慎 | 需人工审核 |
| 群聊批量操作 | 避免初期使用 | 影响范围大 |
| 跨团队审批 | 避免初期使用 | 权限链复杂 |

**铁律**：
1. 不在公开材料/截图/日志中暴露 token、secret、chat_id、open_id
2. 授权范围最小化（`--recommend`方式优先）
3. 写入操作前必须有人类确认
4. 敏感操作走二次确认流程

## 六、权限配置与错误处理

### 6.1 常用权限scope

| 业务域 | scope示例 |
|--------|-----------|
| 消息 | `im:message:send_as_bot`, `im:message:read` |
| 日历 | `calendar:calendar:read`, `calendar:calendar:write` |
| 文档 | `doc:document:create`, `doc:document:readonly` |
| 多维表格 | `bitable:app`, `bitable:table:read` |
| 邮箱 | `mail:mail:readonly`, `mail:mail:write` |
| 通讯录 | `contact:contact:readonly` |
| 任务 | `task:task:read`, `task:task:write` |

### 6.2 常见错误与排查

| 错误现象 | 原因 | 解决方案 |
|----------|------|----------|
| `unverified app` | 应用未授权 | 执行 `lark-cli auth login --recommend` 完成授权 |
| `permission denied` | 缺少对应scope | 执行 `lark-cli auth login --domain <domain>` |
| `invalid chat_id` | 机器人未加入会话 | 将机器人添加到对应群聊 |
| `token expired` | 凭证过期 | 执行 `lark-cli auth login` 重新授权 |
| `network error` | 网络连接问题 | 检查防火墙/代理设置 |
| `command not found: lark-cli` | 未安装 | `npm install -g @larksuite/cli` |

### 6.3 调试命令

```bash
# 检查CLI版本
lark-cli --version

# 查看所有可用命令
lark-cli help

# 检查认证状态
lark-cli auth status --verify

# 检查已授权scope
lark-cli auth check

# 查看CLI配置
lark-cli config show

# 切换身份（用户/机器人）
lark-cli whoami --as user   # 以用户身份
lark-cli whoami --as bot    # 以机器人身份
```
