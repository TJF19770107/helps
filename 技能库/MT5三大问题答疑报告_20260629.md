## 问题一：MT5账户区分配置方案

### 背景

当前实盘账户**尚未入金**，存在「实盘无资金如何区分」「两套MCP如何不冲突」的核心难题。

### 解决方案：双环境物理隔离架构

采用**方案A + 方案B 双链路**，通过独立的配置文件路径、独立的进程实例、独立的传输模式实现完全隔离。

| 维度 | 方案A（模拟盘） | 方案B（实盘） |
|------|---------------|--------------|
| **AI引擎** | Claude Code | Codex |
| **MCP传输** | STDIO（stdio） | HTTP API |
| **监听地址** | 本地进程标准输入输出 | 0.0.0.0:8000 |
| **配置路径** | `MT5-MCP-Server/sim/` | `MT5-MCP-Server/real/` |
| **配置文件** | `sim/.env` + `sim/mcp_sim.json` | `real/.env` + `real/mcp_real.json` |
| **账户类型** | 模拟账户（Demo） | 实盘账户（Live） |
| **操作权限** | 完整策略执行 / 模拟开仓平仓 | 仅行情查询 / 回测 / 禁用下单 |
| **风险等级** | 零资金风险 | 实盘资金，硬锁定保护 |

### 文件结构

```
E:\龙虾AI主控中心\MT5-MCP-Server\
├── .env                          ← 原始配置（已备份）
├── sim/
│   ├── .env                      ← 模拟盘环境变量（LOGIN/PASSWORD/SERVER 占位符）
│   ├── mcp_sim.json              ← Claude Code STDIO MCP配置
│   └── README.md                 ← 方案A说明文档
├── real/
│   ├── .env                      ← 实盘环境变量（含 API_HOST/API_PORT）
│   ├── mcp_real.json             ← Codex HTTP API MCP配置
│   └── README.md                 ← 方案B说明文档
├── Codex_MT5_NL_Commands.md     ← Codex自然语言指令清单
└── claude-skill/                 ← Claude Code技能库（已备份）
```

### 安全性保障

1. **路径隔离**：两套 `.env` 和 `mcp*.json` 位于不同子目录，物理不可互相引用
2. **进程隔离**：STDIO 和 HTTP 两种传输模式启动不同的进程实例
3. **权限硬锁定**：实盘环境 `MT5_TRADE_MODE=readonly`，从环境变量层面屏蔽所有下单接口
4. **审计追踪**：所有实盘配置变更纳入 `backup/` 快照管理

### 3.2 境外网络依赖说明

Claude Code核心服务依赖以下境外网络：

| 依赖项 | 域名/IP | 用途 | 不可用影响 |
|--------|---------|------|-----------|
| Anthropic API | `api.anthropic.com` | 模型推理 | Claude Code完全不可用 |
| npm registry | `registry.npmjs.org` | MCP包安装 | `metatrader-mcp-server` 无法安装/更新 |
| GitHub | `github.com` | 源码/更新 | MCP Server版本更新受阻 |

**结论**：Claude Code对境外网络有**硬依赖**，无代理环境下无法运行。

### 3.3 MIMO V2.5 Pro 本地替代方案

当Claude Code不可用时，可降级到以下本地替代链：

| 组件 | Claude Code链路 | MIMO V2.5 替代链路 |
|------|----------------|-------------------|
| AI引擎 | Anthropic Claude | MIMO V2.5 Pro (本地LLM) |
| MCP传输 | STDIO | 本地管道或HTTP localhost |
| MT5连接 | metatrader-mcp-server (npm) | MIMO内置MT5 Connector |
| 策略执行 | Claude Code技能库 | MIMO策略引擎 |
| 网络要求 | 必须境外代理 | **完全离线可用** |

MIMO V2.5 Pro优势：
- 零境外网络依赖
- 全本地推理，数据不出本机
- 内置MT5桥接组件
- 支持Python策略脚本直接执行

### 3.4 4567代理兼容配置脚本

以下为Claude Code配置代理的PowerShell脚本（已写入 `4567_proxy_setup.ps1`）：

```powershell
# 4567端口代理配置脚本
# 适用于Claude Code / npm / git 等境外依赖工具

$proxyHost = "127.0.0.1"
$proxyPort = "4567"
$proxyUrl = "http://${proxyHost}:${proxyPort}"

# 1. 设置系统级HTTP/HTTPS代理（当前会话）
$env:HTTP_PROXY = $proxyUrl
$env:HTTPS_PROXY = $proxyUrl
$env:NO_PROXY = "localhost,127.0.0.1,.local,.cn"

# 2. npm代理
npm config set proxy $proxyUrl
npm config set https-proxy $proxyUrl

# 3. git代理
git config --global http.proxy $proxyUrl
git config --global https.proxy $proxyUrl

# 4. Claude Code代理（环境变量注入）
# 启动Claude Code时：
# $env:HTTP_PROXY=$proxyUrl; $env:HTTPS_PROXY=$proxyUrl; claude

Write-Host "4567代理已配置完成" -ForegroundColor Green
Write-Host "HTTP_PROXY  = $env:HTTP_PROXY" -ForegroundColor Cyan
Write-Host "HTTPS_PROXY = $env:HTTPS_PROXY" -ForegroundColor Cyan
```

> 脚本文件：`E:\龙虾AI主控中心\MT5-MCP-Server\scripts\4567_proxy_setup.ps1`
