### 1.2 视听语言维度 → 分镜设计

- **运镜体系**（来自天锋十大运镜）：

  - 移镜：follow角色/平行位移

  - 旋转镜：眩晕/混乱
  - 变焦推拉(Dolly Zoom)：心理冲击

### 1.3 故事结构维度 → 剧本框架
- **三幕结构**：建置(25%) → 对抗(50%) → 解决(25%)

  2. 冲突Conflict（为什么看下去）
  3. 转折Twist（出人意料）
  4. 高潮Climax（情绪顶点）

### 3.2 提示词原子化原则（天锋核心）

不写「一个全能的提示词」，而是按场景拆分：
- 同一角色 → 角色设定提示词 + 表情提示词 + 动作提示词各独立
- 同一场景 → 场景搭建提示词 + 光影提示词 + 氛围提示词各独立
- 同一镜头 → 构图提示词 + 运镜提示词 + 色彩提示词各独立
