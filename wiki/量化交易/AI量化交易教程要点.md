# AI量化交易教程要点

## 一、量化交易核心概念

### 什么是量化交易
利用数学模型和计算机程序，基于历史数据和统计规律，自动执行交易决策的方式。核心优势：**纪律性、速度、可回测性**。

### 量化交易系统四层架构
```
数据层 → 策略层 → 执行层 → 风控层
```
- **数据层**：行情数据采集、清洗、存储（tushare/akshare/Wind）
- **策略层**：信号生成、特征工程、模型训练
- **执行层**：订单管理、API对接、滑点控制
- **风控层**：止损止盈、仓位限制、VaR计算

### 三大策略类型
| 类型 | 核心思想 | 适用场景 |
|------|---------|---------|
| 趋势跟踪 | 顺势而为，追涨杀跌 | 趋势明显的市场 |
| 均值回归 | 价格偏离均值后回归 | 震荡市场 |
| 统计套利 | 利用价格统计关系获利 | 配对交易、跨期套利 |

### 核心评估指标
- **年化收益率**：策略的盈利能力
- **最大回撤**：最大亏损幅度，衡量风险
- **夏普比率**：风险调整后收益（>1为佳）
- **胜率**：盈利交易占比
- **盈亏比**：平均盈利/平均亏损

## 二、AI/机器学习在量化中的应用

### 机器学习策略建模流程
```
原始数据 → 特征工程 → 模型训练 → 信号生成 → 回测验证 → 实盘部署
```

### 常用模型
| 模型 | 优势 | 适用任务 |
|------|------|---------|
| 线性回归 | 可解释性强 | 简单收益预测 |
| 随机森林 | 抗过拟合 | 分类/回归 |
| SVM | 小样本表现好 | 涨跌分类 |
| LSTM | 捕捉时序依赖 | 价格序列预测 |
| Transformer | 长距离依赖 | 复杂模式识别 |
| 强化学习 | 自适应策略 | 动态交易决策 |

### 特征工程要点
1. **技术指标特征**：MA、MACD、RSI、布林带等
2. **基本面因子**：PE、PB、ROE、营收增长率
3. **滚动统计特征**：滚动均值、标准差、偏度
4. **滞后特征**：过去N天的收益率、成交量
5. **特征组合**：技术面+基本面因子融合
6. **降维方法**：PCA、因子分析

### 多因子模型框架
```
Alpha因子挖掘 → 因子IC分析 → 因子中性化 → 因子组合 → 选股/择时
```
- **IC分析**：因子值与未来收益的相关性
- **中性化**：去除行业和市值的影响
- **因子组合**：等权、IC加权、最优化加权

## 三、Python金融分析方法论

### 核心工具栈
```
数据获取：tushare / akshare / yfinance
数据处理：pandas / numpy
可视化：matplotlib / plotly / mplfinance
机器学习：scikit-learn / xgboost / lightgbm
深度学习：pytorch / tensorflow
回测框架：backtrader / zipline / vnpy
```

### 金融数据分析核心操作
1. **收益率计算**：对数收益率 vs 简单收益率
2. **波动率分析**：历史波动率、EWMA波动率
3. **相关性分析**：资产间相关性矩阵
4. **K线绘制**：OHLC数据可视化
5. **技术指标计算**：pandas-ta / ta-lib

### 回测框架设计
- **向量化回测**：速度快，适合大规模筛选
- **事件驱动回测**：更贴近实盘，支持复杂逻辑
- **关键注意**：避免未来函数、处理幸存者偏差、计入交易成本

### 期权定价方法
- **Black-Scholes模型**：欧式期权定价标准模型
- **二叉树模型**：美式期权、路径依赖期权
- **希腊字母**：Delta(方向风险)、Gamma(Delta变化率)、Theta(时间衰减)、Vega(波动率敏感度)

## 四、常见陷阱与对策

| 陷阱 | 问题描述 | 对策 |
|------|---------|------|
| 过拟合 | 回测收益极高但实盘亏损 | 滚动窗口验证、样本外测试 |
| 未来函数 | 回测中使用了未来信息 | 严格时间戳检查 |
| 幸存者偏差 | 只用现存股票回测 | 使用含退市股票的全量数据 |
| 滑点忽视 | 回测未计入交易成本 | 加入真实滑点和手续费 |
| 相关性崩塌 | 极端行情下相关性突变 | 压力测试、尾部风险控制 |
