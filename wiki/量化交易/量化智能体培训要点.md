# 量化智能体培训要点

## 什么是"量化智能体"

量化智能体 = **AI Agent + 量化交易工作流**。它不是一个单一工具，而是一种将量化交易全流程（数据→策略→回测→实盘）封装为可被AI调度的自动化体系。

## 核心方法论

### 1. 降低门槛：中文Python策略编写
- 用中文关键字和变量名替代英文编程
- 目标用户：有交易经验但无编程基础的散户/分析师
- 本质：在Python基础上做了一层中文DSL（领域特定语言）

### 2. 全流程自动化
```
数据采集 → 策略生成 → 历史回测 → 参数优化 → 实盘接入 → 风控监控
```
- 每个环节都由智能体协调，减少人工干预
- 支持对接主流终端：同花顺、通达信、QMT

### 3. 工具自生成能力
- 智能体可根据用户需求自动生成带GUI的独立工具
- 用户描述功能 → 智能体生成可运行的窗口程序
- 这是一种"元能力"：Agent不只是执行任务，还能创建新的执行工具

### 4. 社群驱动迭代
- 61期持续培训（2025.4 → 2026.2）
- 学员问题直接驱动功能迭代
- 形成"培训-反馈-改进"的飞轮

## 关键技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 语言层 | 中文Python | 降低编程门槛 |
| 智能体层 | 小白量化智能体 | 核心调度引擎 |
| 交易层 | 同花顺/通达信/QMT | 实盘接入 |
| 数据层 | 行情API | 实时/历史数据 |
| 可视化层 | 窗口式工具生成 | GUI自动生成 |

## 对龙虾AI的启示

1. **技能化思路**：将量化工作流封装为Agent可调用的SKILL.md
2. **中文DSL价值**：降低策略编写门槛可大幅扩展用户群体
3. **工具自生成**：Agent生成GUI工具的能力可复用到其他领域
4. **社群飞轮**：持续培训+反馈驱动是工具迭代的最佳模式
