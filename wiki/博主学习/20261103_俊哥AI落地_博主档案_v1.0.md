
## 六、核心方法论资产（已蒸馏为技能）

| 模型 | 出处 | 一句话 |
|---|---|---|
| **三级门槛漏斗** | 第10期 | 不知道从哪开始 → 没人负责 → 没等到出数就被砍。三关同解：把大目标拆成**能被计数的一个环节** |
| **一个旗手 + 一个外部帮手** | 第10期 | 旗手不必懂技术，必须有：说得清的场景 / 拿得到真实数据 / 每周固定时间 |
| **30 天看数 / 90 天看流程 / 一年看岗位** | 第10期 | 定节奏，别定人天 |
| **ORA-KA 模型** | 第78期（万字论文） | 权责锚定（ORA）+ 知识资产化（KA）。三支柱：权责锚定机制 / AVS 计酬 / 作业即资产培训 |
| **AVS 公式** | 第78期 | `AVS = Σ(Ci × Wi × Qk)`，Ci 有效调用量、Wi 业务权重（行政 0.2 / 核心风控 2.0）、Qk 质量因子 |
| **四签名 + 三道刹车 + 三层标签** | 第26期 | 谁批准上线 / 谁为结果负责 / 谁能按停止 / 谁对外开口；目标不可自定、权限不可自增、额度不可自扩 |
| **陪跑三样交付物** | 第20期 | 一条跑通的流程 + 一套写着自己公司名字的资产 + 一张算得清的账（时长/一次通过率/返工次数） |
| **陪跑四行判定表** | 第20期 | 资产在谁账号 / 交付是周期还是文档 / 有没有第二人独立重跑过 / 人走了新人能否接住 |
| **小而精 > 大而全** | AI日记 | 嵌入现有流程的轻量 AI，成本几万，ROI 极高；自上而下 → 自下而上 |
| **胜利模型 V 字闭环** | 第38期 | 平权平价（开增量市场）→ 精准匹配（抓高价值）→ 超额利润（反哺 AI） |

## 七、可直接「借」的三件事（给我们自己用）

1. **「四行判定表」这个交付形态**——不写长方案，给一张能打印、能贴墙、能签字的四行表。比任何 PPT 都值钱。
2. **数据必须带机构+年份+样本量**——他的可信度全在这里。我们写内容/交付报告也该这么做。
3. **「一盆冷水」段**——主动写自己的局限，比通篇夸自己更有转化。这条正好对上我们 SOUL 里的「实事求是」。
