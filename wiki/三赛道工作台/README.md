## 三、跨赛道联动引擎

评分公式：

```
score = 复用增益 − 迁移代价
```

| 分值 | 结论 |
|---|---|
| **≥ 3** | 建议复用 |
| **0 ~ 3** | 谨慎，先小规模验证 |
| **< 0** | 如实说不建议（不硬凑） |
| **保密单** | 一票否决（−99） |

实测样例（4 条）：
- T2 → T1：score **5** → 建议复用 ✅
- T2 → T3：score **3** → 建议复用 ✅
- T1 → T3：score **0** → 谨慎 ⚠️
- 保密单：**−99** → 判死 ❌

## 四、技术底座（零依赖）

- 后端：Python 标准库 `http.server`（无第三方依赖），18 条 API

- 前端：单文件 HTML，`file://` 双击与 `http://` 服务双通道可用
- 成本：零付费 API
