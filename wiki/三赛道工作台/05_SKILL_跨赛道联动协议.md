# 三赛道·跨赛道联动协议 v1.0.0

> 三台分工：**赛道1 产现金流 → 赛道2 做复利 → 赛道3 打底层**。
> 三台**独立运行**，但底层能力**互通、相乘增益**。本协议定义「怎么互通」「什么时候不互通」。

## 一、五条联动总则（底座复制块 E）

1. **产出即评估** —— 任一赛道交付时，附加一行「可复用性评估：能否迁移到赛道 X / 迁移代价 / 预期增益」
2. **接口优先** —— 涉及模型模块的输出，优先按「可被另外两条赛道调用」的接口形态交付
3. **素材回流** —— 多模态产出的图像/视频，标注是否可作世界模型场景训练素材
4. **引擎迁移** —— 量化时序预测模块抽象成**独立可迁移组件**，供具身环境状态预测复用
5. **不强行联动** —— 复用代价高于重做时，如实说「不建议复用」，**不为了联动而联动**

## 二、数据契约（Artifact Contract v1）

三台任一处产出，落一份 `artifact.json` 元数据（可被引擎直接吃）：

```json
{
  "artifact_id": "T2-chart-20261014-001",
  "track": "T2",
  "title": "STRKUSDT 形态检索台行情图",
  "path": "outputs/20261014/strk_chart.svg",
  "type": "chart",
  "bytes": 48213,
  "sha256": "…",
  "tags": ["行情图", "可视化"],
  "reuse_offers": [
    {
      "target": "T1",
      "kind": "material",
      "note": "可做宣传素材包装（加文案/版式/配乐）"
    },
    {
      "target": "T3",
      "kind": "interface",
      "iface": "time_series_forecast",
      "consumes": "state_series[N]",
      "produces": "state_dist[N+k]",
      "note": "时序预测引擎，可用于环境状态预测"
    }
  ]
}
```

**必填**：`artifact_id` / `track` / `path` / `type` / `reuse_offers`
**引擎会按 `reuse_offers` + 代价模型逐条打分**。

## 三、触发规则（什么时候评估）

| 触发点 | 动作 |
|---|---|
| 任一赛道**交付完成** | 生成 `artifact.json` → 跑一次联动引擎 → 输出评估矩阵 |
| **每周**或每 N 次交付 | 汇总所有 artifact，跑全量评估，挑出「复合应用场景」候选 |
| 用户说「**跨赛道联动** / **联动一下**」 | 立即加载本协议 + 跑引擎 |

## 四、迁移代价模型（判「值不值得复用」）

引擎按下式打分，**增益 > 代价才建议复用**：

```
score = 复用增益(0~10) − 迁移代价(0~10) − 适配风险(0~10)
建议复用  ⇔  score ≥ 3
谨慎复用  ⇔  0 ≤ score < 3
不建议复用 ⇔ score < 0     ← 必须如实说「不建议」，禁止硬凑联动
```

**代价三因子**：
- **接口差**：目标侧是否已有对应入口（有→0，需新建→+3）
- **格式差**：产出格式与目标入参差异（同构→0，需转换→+2，需重做→+6）
- **数据/版权**：保密单、受版权约束素材 → 直接判「不可跨台」，不进评估

## 五、三台互为入口/出口速查

| 从 \ 到 | 赛道1 多模态 | 赛道2 量化 | 赛道3 具身 |
|---|---|---|---|
| **赛道1 多模态** | — | 行情图/演示视频→**宣传素材** | 图像/视频→**世界模型场景训练素材** |
| **赛道2 量化** | 可视化需求←素材能力 | — | **时序预测引擎**→环境状态预测 |
| **赛道3 具身** | 生成式场景素材需求 | 状态预测需求 | — |

**已识别的三条真联动链路**：
1. **T2 → T1**：量化行情图 → 多模态包装成对外宣传素材（**最低代价，立即可用**）
2. **T2 → T3**：量化时序预测组件 → 具身环境状态预测（**中代价，需抽象成独立组件**）
3. **T1 → T3**：多模态图像/视频 → 世界模型场景训练集（**中代价，主要卡在标注与版权**）

## 七、红线

- **不做不实联动**：代价高于重做，如实说不建议
- **保密单不出台**：保密单素材直接标记 `不可跨台`
- **联动产物也要过 L4 校验**：复用别人产物前先验字节/哈希，防「合法但全白」
