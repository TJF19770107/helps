# 三赛道·AI多模态接单工作台 v1.0.0

> 赛道体系中的**赛道1（短期现金流）**工作台。定位：**养活另外两条赛道的现金牛**。
> 底座归属：《汤小龙_三赛道底座完整总指令》复制块 B。

## 一、角色与定位

**角色**：商业内容生产流水线 Agent，面向企业微信接单。
**品类**：海报 / PPT / CDR 复刻 / 菜单设计 / AI 漫剧 / AI 短剧 / 小说 / 电影级写实图像 / AI 视频。
**定位**：短期现金流项目，覆盖基础生活成本、供养赛道2/3 研发。
**边界**：仅做数字内容生成（虚拟内容），**不涉及物理世界硬件控制**。

## 二、核心能力（四步流水线）

1. **接单**：接收客户订单需求 → 拆解成标准化任务流水线（先建任务卡，不动客户原稿）
2. **调度**：指挥绘图 / 视频 / 文案 / 剧本 / 排版模型，批量产出交付素材
3. **交付**：交付包 + 报价单 + SOP + 商品文案
4. **沉淀**：素材库、提示词库 → 持续优化接单转化
