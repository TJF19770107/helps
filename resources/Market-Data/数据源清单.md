## 二、数据字段说明

### 2.1 K线数据 (OHLCV)

| 字段 | 说明 | 数据类型 |
|------|------|----------|
| timestamp | 时间戳 (Unix ms) | int64 |
| open | 开盘价 | float64 |
| high | 最高价 | float64 |
| low | 最低价 | float64 |
| close | 收盘价 | float64 |
| volume | 成交量 (基础货币) | float64 |
| volume_quote | 成交量 (计价货币) | float64 |

### 2.2 逐笔成交

| 字段 | 说明 |
|------|------|
| trade_id | 成交ID |
| price | 成交价格 |
| size | 成交数量 |
| side | 方向 (buy/sell) |
| timestamp | 成交时间 |

### 2.3 订单簿深度

| 字段 | 说明 |
|------|------|
| asks | 卖单队列 [[price, size], ...] |
| bids | 买单队列 [[price, size], ...] |
| timestamp | 快照时间 |
